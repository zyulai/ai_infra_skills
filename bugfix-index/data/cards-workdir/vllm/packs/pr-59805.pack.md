## Details

The failure happens while the 2.0 checkpoint's tokenizer is loading, before any model code runs:

```
transformers/tokenization_utils_tokenizers.py:120 in convert_to_native_format
    local_kwargs["tokenizer_object"] = TokenizerFast.from_file(fast_tokenizer_file)
E   Exception: DuplicatePatternError: [225, 131, 156] at line 449472 column 1
```

So the new test case can't run with the tokenizer library in the CI image. Re-landing the `tie_weights()` fix should go together with a working way to load that tokenizer, or without the 2.0 test case. cc @aniskumar-nv
