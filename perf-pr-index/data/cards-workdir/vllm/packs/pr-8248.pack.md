This optimization reduces the number of loads from memory that the awq_gemm and awq_dequantize need to do, resulting in 2x throughput from previous implementation. The following benchmark is attached:

python benchmarks/benchmark_throughput.py --input-len 2048 --output-len 128 --quantization awq --model /models/Qwen/Qwen2-7B-Instruct-AWQ/

Throughput:

AWQ Triton (no optimization):

Throughput: 6.14 requests/s, 13351.06 tokens/s

AWQ Triton (with optimization):

Throughput: 12.77 requests/s, 27783.36 tokens/s

AWQ CUDA:

Throughput: 11.51 requests/s, 25049.29 tokens/s
