## Overview

This PR makes the `latency_specialized` decode from #61868 faster for DeepSeek-V4.1 on NVIDIA GPUs. Most of the work is in the decode step's kernels: larger batches now stay on the low-latency paths, more of each step overlaps, and the indexers split their work across the TP ranks. "What changed" below goes through each part.

On one GB300 tray with DSpark, the decode step takes 5.9–17.0% less time than on `main` at batch 1 to 32, and AgentX P90 interactivity is 4–26% higher at concurrency 1 to 32, with slightly higher throughput.

![Decode step and AgentX, main against this PR](https://raw.githubusercontent.com/yaoyaoding/vllm/93d0aafb7e0d32b440d597fa680476b5de27d5f9/pr3_perf.png)

**Decode top-k.** `decode_topk` against vLLM's opt-in DeepSelect and the stock path (FP32 upcast + `cooperative_topk`), k = 512, µs per call:

Random BF16 logits; "valid" is the share of each row's columns before its end. One GB300, a CUDA graph of 20 back-to-back calls, median of 20 replays. Each cell: `decode_topk` / DeepSelect / stock.

With row sharding, a rank selects 12 rows at batch 8 and 48 rows at batch 32 (6 rows a request, over 4 ranks).

- Up to 12 rows, `decode_topk` is faster than DeepSelect at every shape but two: 65,536 columns with 1/8 valid (7.3–7.7 against 4.2–4.3 µs), and 1,048,576 columns with 1/8 valid at 12 rows (17.1 against 16.5).
- From 24 rows, DeepSelect is faster when 1/8 of the columns are valid (65,536 columns at 48 rows: 17.1 against 4.3 µs) and at 65,536 columns from 48 rows and 524,288 all-valid columns from 48 rows (44.2–44.1 against 46.1–44.7 µs). `decode_topk` stays faster with all 262,144 columns valid (11.8–22.5 against 26.1–26.2 µs).
- Above 12 rows, `decode_topk` does not take 1,048,576-column rows, so they use the stock path (81.7–289.3 µs against DeepSelect's 16.6–76.6).
- In block mode `decode_topk` is faster at every size (5.9–12.7 against 9.3–80.0 µs).
- Against the stock path `decode_topk` is faster at every shape it takes, except 65,536 columns with 1/8 valid (7.3–17.4 against 6.7–12.9 µs; equal at 24 rows).

## Details

**Duplicate-work check.** No open PR extends the DeepSeek-V4.1 specialized decode. Related open PRs:

- #62633 adds a swap-AB CuTe DSL decode attention to the FlashMLA mega-attention layer. This PR's sparse-MLA kernel replaces the TRTLLM-gen decode of the `FLASHINFER_MLA_SPARSE_DSV41` backend, which the specialized decode requires.
- #62172 lets `cooperative_topk` read BF16 logits, and #57109 adds FlashInfer's sampled `gvr_2` as an opt-in indexer top-k. `decode_topk` serves only this model's decode indexers. It also selects the candidate source's blocks, and it covers the 1M-wide rows on 16 CTAs. The comparison with DeepSelect is above.
- #62635 fuses the finalize with the shared-expert add where the fused all-reduce + mHC does not take it. This PR's MoE finalize stays deferred into that fused kernel.

+"""The specialized decode's TP all-gather (``LamportAllGather``) at TP4.
+
+* ``accepts`` by size: 16-byte multiples up to the capacity.
+* Eager gathers of int32, BF16 and FP32 tensors whose sizes grow and shrink
+  from call to call (1 pack to the full capacity), one rank late each call,
+  bitwise against NCCL.
+* The Lamport sentinel word (FP32 negative zero, INT32_MIN) arrives as 0 on
+  every rank, the sending rank included.
+* CUDA graphs of three gathers of different sizes each, some with the ranks
+  skewed, replayed in a seeded random order with new contents every replay;
+  a device-side count of words that differ from the expected concatenation
+  must stay 0. A word left in the mailbox by an earlier call of another size
+  would show up here as a mismatch.
+
+Needs four SM100-family GPUs with NVLink multicast; about a minute. For a
+stress run, run this file as a module
+(``python -m tests.models.deepseek_v41.nvidia.specialized_decode.test_all_gather``)
+with ``--replays 2000000``. With ``--custom-all-gather`` it replays the same
+graphs on vLLM's custom all-gather (``CustomAllreduce.custom_all_gather``, the
+MNNVL Lamport kernel) instead and only counts the mismatched words: that
+kernel never waits for a rank's own multicast copy, and words of an earlier
+call can reach a later one.
+"""
+

+import pytest

+TP = 4
+CAPACITY = 4 << 20  # bytes a rank, as the executor builds it
+REPLAYS = 2000
+LATE_CYCLES = 20_000
+SENTINEL = -(2**31)
+# Pack counts (16 bytes each) of the eager sequence: growing, shrinking, a
+# partial last CTA, one pack and the full capacity.
+EAGER_PACKS = (1, 37, 389, 128, 5000, 3, CAPACITY // 16, 2, 777, 1)
+# Words a rank of each graph's three gathers.
+GRAPH_WORDS = (
+    (4, 2800, 148),
+    (20000, 12, 2048),
+    (512, 8192, 4),
+    (CAPACITY // 4, 4, 64),
+)

+def _late(rank: int, step: int) -> None:
+    """Delay one rank per step, a different one each step."""
+    if rank == step % TP:
+        torch.cuda._sleep(LATE_CYCLES)
+
+
+def _random_words(generator, words: int) -> torch.Tensor:
+    """Random int32 words, none of them the sentinel."""
+    x = torch.randint(
+        -(2**31),
+        2**31 - 1,
+        (words,),
+        generator=generator,
+        device="cuda",
+        dtype=torch.int64,
+    ).to(torch.int32)
+    return torch.where(x == SENTINEL, 1, x)
+
+
+def _check_accepts(all_gather):
+    assert not all_gather.accepts(torch.empty(0, device="cuda"))
+    assert not all_gather.accepts(torch.empty(2, device="cuda"))  # 8 bytes
+    assert all_gather.accepts(torch.empty(4, device="cuda"))
+    assert all_gather.accepts(torch.empty(CAPACITY // 4, device="cuda"))
+    assert not all_gather.accepts(torch.empty(CAPACITY // 4 + 4, device="cuda"))
+    with pytest.raises(ValueError):
+        all_gather(torch.empty(2, device="cuda"))
+
+
+def _check_eager(all_gather, rank):
+    from vllm.distributed import get_tp_group
+
+    group = get_tp_group()
+    generator = torch.Generator(device="cuda").manual_seed(rank)
+    for step, packs in enumerate(EAGER_PACKS):
+        words = _random_words(generator, packs * 4)
+        for dtype in (torch.int32, torch.bfloat16, torch.float32):
+            # One 16-byte pack a row.
+            x = words.view(dtype).view(packs, -1)
+            _late(rank, step)
+            got = all_gather(x)
+            want = group.all_gather(x, 0)
+            assert got.dtype == dtype and got.shape == want.shape, (packs, dtype)
+            assert torch.equal(got.view(torch.int32), want.view(torch.int32)), (
+                packs,
+                dtype,
+            )

+
+def _check_sentinel(all_gather, rank):
+    from vllm.distributed import get_tp_group
+
+    generator = torch.Generator(device="cuda").manual_seed(100 + rank)
+    x = _random_words(generator, 64)
+    x[rank::7] = SENTINEL
+    got = all_gather(x)
+    want = get_tp_group().all_gather(x, 0)
+    want = torch.where(want == SENTINEL, 0, want)
+    assert torch.equal(got, want)
+    negative_zero = torch.full((8,), -0.0, device="cuda")
+    gathered = all_gather(negative_zero)
+    assert torch.equal(gathered.view(torch.int32), torch.zeros_like(gathered).int())

+def _pattern(rank: int, kind: int, words: int) -> torch.Tensor:
+    """(rank, kind, index) as int32 bits, never the sentinel; the replay
+    counter goes into bits 20-25."""
+    index = torch.arange(words, dtype=torch.int32, device="cuda") & 0xFFFFF
+    return (rank << 28) | (kind << 26) | index
+

+def _check_replays(all_gather, rank, replays, stop=True):
+    """Gather graphs replayed in a random order; returns the mismatch count,
+    after the first 1000 replays with a mismatch if ``stop``."""
+    from vllm.distributed.parallel_state import graph_capture
+
+    counter = torch.zeros(1, dtype=torch.int32, device="cuda")
+    errors = torch.zeros(1, dtype=torch.int64, device="cuda")
+    graphs = []
+    with graph_capture(device=torch.device("cuda")) as context:
+        for sizes in GRAPH_WORDS:
+            mine = [_pattern(rank, k, n) for k, n in enumerate(sizes)]
+            want = [
+                torch.cat([_pattern(r, k, n) for r in range(TP)])
+                for k, n in enumerate(sizes)
+            ]
+            inputs = [torch.empty_like(m) for m in mine]
+            for skew in (False, True):
+
+                def body(mine=mine, want=want, inputs=inputs, skew=skew):
+                    counter.add_(1)
+                    bits = (counter & 0x3F) << 20
+                    outs = []
+                    for kind in range(3):
+                        torch.add(mine[kind], bits, out=inputs[kind])
+                        if skew:
+                            torch.cuda._sleep(LATE_CYCLES * ((rank + kind) % TP))
+                        outs.append(all_gather(inputs[kind]))
+                    for kind in range(3):
+                        errors.add_((outs[kind] != want[kind] + bits).sum())
+
+                body()
+                graph = torch.cuda.CUDAGraph()
+                with torch.cuda.graph(graph, stream=context.stream):
+                    body()
+                # The graph keeps raw pointers: keep its tensors alive too.
+                graphs.append((graph, (mine, want, inputs)))
+    torch.accelerator.synchronize()
+    assert not stop or errors.item() == 0, "eager warm-up"
+    order = random.Random(1234)
+    for start in range(0, replays, 1000):
+        for _ in range(min(1000, replays - start)):
+            graphs[order.randrange(len(graphs))][0].replay()
+        torch.accelerator.synchronize()
+        if stop and errors.item():
+            break
+    return int(errors.item())
+

+            _check_accepts(all_gather)

+            f"words here, {int(total.item())} on all ranks",

+        torch.accelerator.synchronize()
+        cleanup_dist_env_and_memory()

+Token mode: each row's output must be an exact top-k of its BF16 logits in
+the kernel's key order (every index whose key exceeds the k-th largest key,
+then indices whose key equals it), or ``0 .. n-1`` and -1 for rows of at most
+k values. Rows cover the sampled path, short rows (the direct path), crowded

+def order_keys(values: torch.Tensor) -> torch.Tensor:
+    """The kernel's order-preserving key of each BF16 value, as int32."""
+    bits = values.view(torch.int16).int() & 0xFFFF
+    return torch.where(bits >= 0x8000, bits ^ 0xFFFF, bits ^ 0x8000)
+
+
+def make_logits(rows: int, kind: str, seed: int) -> torch.Tensor:
+    """[rows, WIDTH] BF16 logits of one distribution."""
+    g = torch.Generator(device=DEVICE).manual_seed(seed)
+    x = torch.randn(rows, WIDTH, device=DEVICE, generator=g)
+    if kind == "crowded":  # few distinct values: long exact ties
+        x = torch.randint(0, 6, (rows, WIDTH), device=DEVICE, generator=g).float()
+    elif kind == "constant":
+        x = torch.full((rows, WIDTH), 3.0, device=DEVICE)
+    elif kind == "rising":  # the largest values at the row's end
+        x = x * 0.1 + torch.linspace(0, 8, WIDTH, device=DEVICE)
+    elif kind == "special":
+        x[:, 7] = float("nan")
+        x[:, 1000::977] = float("inf")
+        x[:, 2000::991] = float("-inf")
+    return x.bfloat16()
+

+def check_tokens(logits: torch.Tensor, lengths: list[int], out: torch.Tensor, k: int):
+    """Assert each row's output is an exact top-k (module docstring)."""
+    for r, n in enumerate(lengths):
+        got = out[r]
+        if n <= k:
+            want = torch.arange(k, device=DEVICE, dtype=torch.int32)
+            want[n:] = -1
+            assert torch.equal(got, want), f"row {r} (n {n})"
+            continue
+        assert int((got < 0).sum()) == 0 and int(got.max()) < n, (
+            f"row {r}: ids out of range"
+        )
+        assert got.unique().numel() == k, f"row {r}: repeated ids"
+        keys = order_keys(logits[r, :n])
+        kth = keys.topk(k).values[-1]
+        chosen = keys[got.long()]
+        assert int((chosen < kth).sum()) == 0, f"row {r}: a key below the k-th"
+        assert int((chosen > kth).sum()) == int((keys > kth).sum()), (
+            f"row {r}: missed a key above"
+        )

+def block_keys(logits: torch.Tensor, end: int) -> torch.Tensor:
+    """Keys of a row's valid 8-token block maxima, the newest pinned at +inf."""
+    nblocks = (end + 7) // 8
+    padded = torch.full((nblocks * 8,), float("-inf"), device=DEVICE)
+    padded[:end] = logits[:end].float()
+    scores = padded.view(nblocks, 8).amax(dim=1)
+    scores[nblocks - 1] = float("inf")
+    return order_keys(scores.bfloat16())

+def selected_keys(ids: torch.Tensor, keys: torch.Tensor) -> torch.Tensor:
+    """Sorted keys of a candidate row's selected blocks, -1 slots as -inf."""
+    assert int(ids.max()) < keys.numel()
+    valid = ids[ids >= 0]
+    assert valid.unique().numel() == valid.numel(), "repeated ids"
+    chosen = torch.full_like(ids, NEG_INF_KEY)
+    chosen[ids >= 0] = keys[valid.long()]
+    return chosen.sort().values
