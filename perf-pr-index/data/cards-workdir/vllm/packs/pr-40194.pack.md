## PR body
```markdown
## Summary

- **Remove per-layer random sign flips** from the Hadamard rotation. The Hadamard signs should have no effect on Lloyd-Max quantization quality; first, because the quantizer is symmetric around zero, and second because the randomness will add variance. In this PR, all layers now share the same pure Hadamard matrix, removing the `_tq_signs` buffer, `generate_wht_signs()`, the per-layer seed logic, and the `seed` field from `TurboQuantConfig`.

- **Added historical attribution** noting that the technique (Hadamard rotation + optimized scalar grids + optional re-normalization) is the scalar case of HIGGS (Malinovskii et al., NAACL 2025; arXiv:2411.17525), first applied to KV-cache compression in "Cache Me If You Must" (Shutova et al., ICML 2025; arXiv:2501.19392). Both pre-date the TurboQuant (TQ) paper. The JL improvements from the TQ paper may improve theoretical guarantees, but were not found to be practically impactful by the original PR.

## Verification

**Empirical verification (synthetic):** Tested across 5 source distributions (Gaussian, sparse, heavy-tailed, correlated, uniform), 3 bit widths (2/3/4-bit), 5 random seeds. Angular error, relative MSE, and inner product correlation are identical to 6+ decimal places between pure and randomized Hadamard.

**Wikitext-2 PPL (Llama-3.2-3B):**

| Config | PPL | Δ baseline |
|---|---|---|
| Baseline (FP16 KV) | 6.947 | — |
| TQ 4bit+NC pure Hadamard | 7.074 | +1.83% |
| TQ 4bit+NC randomized Hadamard | 7.082 | +1.94% |
| TQ 3bit+NC pure Hadamard | 7.376 | +6.17% |
| TQ 3bit+NC randomized Hadamard | 7.368 | +6.06% |

Pure and randomized Hadamard are within noise (~0.1% PPL), so no regression.

## Test plan

- [ ] Existing TurboQuant unit tests pass (updated to remove sign-related tests, added Hadamard orthonormality and symmetry tests)
- [ ] Store→decode round-trip test passes with pure Hadamard
- [ ] Verified no remaining references to `_tq_signs` or `generate_wht_signs` in codebase
```
