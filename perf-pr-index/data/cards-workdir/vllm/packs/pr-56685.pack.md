## PR body
```markdown

This PR expands Humming quantization support and integrates a unified input processing kernel.

#### 1. Hadamard transforms for online quantization

Enable Hadamard transforms by setting `hadamard_block_size` in `VLLM_HUMMING_ONLINE_QUANT_CONFIG`.

#### 2. SM120/SM121 support

Add support for NVFP4, MXFP4, and MXFP8, including the non-public `float4e0m3` and `float8e3m4` data types, see https://github.com/vllm-project/humming/pull/41 .

#### 3. Additional input quantization modes

Support `static_per_tensor`, `static_tensor_dynamic_group`, and `dynamic_group_tensor`. The latter two primarily serve NVFP4 quantization.

#### 4. Checkpoint quantization and input schema fallback

Honor checkpoint input quantization settings and automatically fall back to a higher-precision input schema when the device does not support the configured activation quantization type.

To retain the original WNA16 behavior, set:

```bash
export VLLM_HUMMING_INPUT_QUANT_CONFIG='{"dtype":"bfloat16"}'
```

Input schemas explicitly specified through `VLLM_HUMMING_INPUT_QUANT_CONFIG` disable fallback by default. Unsupported configurations raise an error unless `"allow_fallback": true` is explicitly specified.

#### 5. Unified `process_input` kernel

Support fused combinations of optional activation function, Hadamard transforms, and input quantization across multiple layouts.

Custom activations support `unary`, `binary_split`, and `binary_interleaved` modes, with implementations supplied as CUDA C++ expressions.

| Path | Gemm Type | Fused operations | Padding handling |
|---|---|---|---|
| Dense | `dense` | Optional Hadamard transform and input quantization | — |
| MoE gate/up | `indexed` | Optional Hadamard transform and input quantization | — |
| MoE gate/up | `grouped_contiguous` | MoE permutation, optional Hadamard transform and input quantization | Skip invalid padding tokens in EP |
| MoE gate/up | `grouped_mask` | Optional Hadamard transform and input quantization | Skip invalid padding tokens |
| MoE down | `indexed` | Activation, optional Hadamard transform and input quantization | Skip invalid padding tokens in EP |
| MoE down | `grouped_contiguous` | Activation, optional Hadamard transform and input quantization | Skip invalid padding tokens in EP |
| MoE down | `grouped_mask` | Activation, optional Hadamard transform and input quantization | Skip invalid padding tokens |

#### 6. Additional scatter indices

Extend `moe_permute` and `moe_align_block_size` to return the `scatter_idx` required by `process_input`.

#### 7. Humming mxfp6 backend

Add `HummingMxFp6LinearKernel`.

#### 8. Humming utility refactoring

Refactor `humming_utils.py`, moving some validation and conversion logic into the Humming library.

#### 9. Type annotations

Add type annotations to `vllm/utils/humming.py`.

```
