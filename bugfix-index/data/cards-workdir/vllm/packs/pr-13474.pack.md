## 正文(PR 描述)

Fix the logic in grouped topk computation of fused moe. 

There is a slight difference between vllm grouped_topk and the official code. When the newly-introduced bias term (e_score_correction_bias in vllm) is not None, we should firstly get the top-2 scores of each group, and use the summation to get top-k groups. You can also check the compute logic in DeepSeek v3's [official inference code](https://github.com/deepseek-ai/DeepSeek-V3/blob/main/inference/model.py#L583-L586)

The mask scores are set to 0. This configuration may result in the selection of experts in masked groups if the scores in the unmasked groups are negative. This behavior can lead to incorrect or suboptimal selections in certain scenarios. [DeepSeek v3](https://github.com/deepseek-ai/DeepSeek-V3/blob/main/inference/model.py#L589) also reset masked scores to -inf.
