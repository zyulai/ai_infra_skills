## Motivation

Single-token BF16 Qwen3.8-Flash-Next decode launches separate HC combine/norm and MoE shared-gate/finalize/collective work, while the packed GDN value tile leaves substantial register pressure at this shape. On four B200 GPUs, this patch raises the measured 8k-input/1k-output decode rate from fresh stock **242.443** to **270.982–271.759 token/s**, preserving the sampled stock accuracy in four native runs.

## Modifications

- Overlap the HC gate with block computation, fuse HC apply with grouped Gemma RMSNorm, and pass the prepared norm tensors explicitly across layers. PLE and PP boundaries retain the normal handoff.
- Extend the existing collective with an FP32 shared gate, preserving routed BF16 rounding before the shared-expert FMA. Defer BF16 MoE finalize and overlap the shared branch through a guarded single-token TP4/EP1 path with its own communication buffer.
- Use the smaller GDN value tile for the packed single-token BF16/FP32-state Blackwell shape, preserving the one-warp reduction order. Existing dispatch remains for unsupported shapes.

The MoE specialization requires hidden size 2560, 512 experts/top-10, BF16, SM10, TP4/EP1, attention DP1, with LoRA, speculative decoding and two-batch overlap disabled. No extra command-line switch enables the kernels. The benchmark selects the existing faster custom-all-reduce deployment option for both stock and candidate.

## Accuracy Tests

Stock and all four native candidate runs score **126/128 GSM8K, zero invalid answers, zero truncations**. These use identical frozen tokenized prompts, normal EOS and the same 2,048-token cap. All 128 per-question correctness and finish-reason verdicts match the fresh stock run.

Historical GPU validation before the standalone test cleanup: 6 HC unit configurations; 12 independent torch-reference GDN configurations; 6 collective configurations on each of 4 ranks, including the original ungated API; 90 trained HC-chain comparisons; 324 changed-input trained collective graph comparisons; 192 seeded GDN output/state bit comparisons. Isolated HC memcheck: zero errors. Full-stack communicator checks have the same handled PyTorch FABRIC capability API errors in stock and candidate, so they are not claimed as clean full-stack sanitizer runs. Pre-commit passes.

+__launch_bounds__(160) void hc_combine_norm_decode_kernel(const HcCombineNormDecodeParams __grid_constant__ params) {
+  using namespace device;
+  using BFloat16x2 = packed_t<bf16_t>;
+  using Storage = AlignedVector<BFloat16x2, 8>;
+  constexpr uint32_t kThreads = 160;
+  constexpr uint32_t kWarps = 5;
+  static_assert(kThreads % kParts == 0);
+  const uint32_t row = blockIdx.x / (4 * kParts);
+  const uint32_t branch = (blockIdx.x / kParts) % 4;
+  const uint32_t part = blockIdx.x % kParts;
+  const uint32_t tid = threadIdx.x;
+  const auto gmem = tile::Memory<Storage>::cta(kThreads);
+  const auto residual = params.residual + (row * 4 + branch) * 2560;
+  const auto block_output = params.block + row * 2560;
+  const auto norm_weight = params.weight + branch * 2560;
+  __shared__ float warp_sums[kWarpThreads];
+  PDLWaitPrimary<true>();
+  float total = 0.0f;
+#pragma unroll
+  for (uint32_t split = 0; split < 8; ++split)
+    total += params.partials[(row * 8 + split) * 4 + branch];
+  const float gate = 2.0f / (1.0f + math::exp(-total / 4));
+  const auto residual_values = gmem.load(residual, 0);
+  const auto block_values = gmem.load(block_output, 0);
+  const auto weight_values = gmem.load(norm_weight, 0);
+  Storage combined;
+#pragma unroll
+  for (uint32_t i = 0; i < 8; ++i) {
+    const auto [rx, ry] = cast<fp32x2_t>(residual_values[i]);
+    const auto [yx, yy] = cast<fp32x2_t>(block_values[i]);
+    // Match the stock apply's FMA and its BF16 store before normalization.
+    combined[i] = cast<BFloat16x2>(fp32x2_t{rx + gate * yx, ry + gate * yy});
+  }
+  float sum = 0.0f;
+#pragma unroll
+  for (uint32_t i = 0; i < 8; ++i) {
+    const auto [x, y] = cast<fp32x2_t>(combined[i]);
+    sum += x * x + y * y;
+  }
+  sum = warp::reduce_sum(sum);
+  const auto warp_id = tid / kWarpThreads;
+  warp_sums[warp_id] = sum;
+  __syncthreads();
+  if (warp_id == 0) {
+    const auto local_sum = tid < kWarps ? warp_sums[tid] : 0.0f;
+    sum = warp::reduce_sum(local_sum);
+    warp_sums[tid] = math::rsqrt(sum / 2560 + params.eps);
+  }
+  __syncthreads();
+  const float inv_rms = warp_sums[warp_id];
+  if (tid >= part * (kThreads / kParts) && tid < (part + 1) * (kThreads / kParts)) {
+    Storage normalized;
+#pragma unroll
+    for (uint32_t i = 0; i < 8; ++i) {
+      const auto [x, y] = cast<fp32x2_t>(combined[i]);
+      const auto [wx, wy] = cast<fp32x2_t>(weight_values[i]);
+      normalized[i] = cast<BFloat16x2>(fp32x2_t{x * inv_rms * (1.0f + wx), y * inv_rms * (1.0f + wy)});
+    }
+    gmem.store(params.combined + (row * 4 + branch) * 2560, combined, 0);
+    gmem.store(params.normalized + (row * 4 + branch) * 2560, normalized, 0);
+  }
+  PDLTriggerSecondary<true>();
+}
