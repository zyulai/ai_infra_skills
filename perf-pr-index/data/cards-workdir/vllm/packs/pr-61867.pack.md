## Overview

(this PR description was manually written by me)

This is an NVIDIA-developed specialized implementation of Kimi K3 for GB300 that achieves 1.5-2x decode speedups. It supports:
- TP8 and TP16 on GB300
- NoSpec (up to B64) and DSpark verification with 3-7 draft tokens (up to 64 tokens -- B8 for DL7, B16 for DL3)
- Decode context parallelism with DCP=TP (DCP-off also supported)

It is enabled opt-in via `--additional-config '{"decode_backend": "latency_specialized"}'`. All changes are localized to `vllm/models/kimi_k3/nvidia/`.

## Claims

With FP8 KV Cache, FP32 SSM Cache, and model-provider weights:
- TP16, ISL 1, no speculation: decode step **1.79-1.92x faster than stock at B1-B8** (3.90 vs 7.38 ms at B1).
- TP16, DSpark DL7, synthetic acceptance 6: **1.53-1.71x decode tok/s at B1-B8**.
- DL7, ISL 32k, DCP on: **1.36-1.50x (TP8)** and **1.53-1.75x (TP16)** decode tok/s.
- AIME25, GPQA-Diamond and MRCR v2 8-needle match stock within about one standard error, with and without speculation.

## Details

### vLLM Integration

No weight changes were made in this model implementation: it is fully compatible with Aggregated vLLM serving, and falls back to the default implementation for prefills, mixed batches, and large batches.

The specialized decode runtime is implemented via _composition_: a SpecializedDecode object owned by the Kimi LLM model, built when supported (see `unsupported(...)`), and called during forward(). The runtime can opt-out of a batch (e.g. when it has too many tokens) by checking `decode.plan(...) is None`, and fall back to stock forward.

I considered a few alternate designs but ultimately feel like this is the cleanest integration. It uses the ModelState protocol to build the runtime object and hook into initialize_kv_cache().

The rest of the integration is organized into subfolders, e.g. `vllm/models/kimi_k3/specialized_decode/nvidia/cutedsl/kda/` with the specialized implementation(s) for each component.

+"""Seven-CTA cluster AttnRes: one cluster per token, 1024 hidden columns per CTA.

+@cute.jit
+def round_pair(t, row: cutlass.Constexpr, j: cutlass.Constexpr):
+    word = bf16x2(t[row, 2 * j], t[row, 2 * j + 1])
+    t[row, 2 * j], t[row, 2 * j + 1] = bf16(word, 0), bf16(word, 1)
+
+
+@cute.jit
+def unpack(words, out, row: cutlass.Constexpr):
+    for i in cutlass.range_constexpr(8):
+        out[row, i] = bf16(words[i // 2], i % 2)
+

+def block_ptr(blocks, token, block, col):
+    """``&blocks[token, block, col]`` from the tensor's strides."""
+    return blocks.iterator + token * blocks.stride[0] + block * blocks.stride[1] + col
+
+
+@cute.jit
+def rstd(sum_sq, eps):
+    """Reciprocal RMS of a 7168-wide row from its sum of squares."""
+    return cute.math.rsqrt(fma(sum_sq, Float32(1 / 7168), eps), fastmath=True)
+
+
+@cute.jit
+def dot8(a, ar: cutlass.Constexpr, b, br: cutlass.Constexpr):
+    return dot((a[ar, i] for i in range(8)), (b[br, i] for i in range(8)), Float32(0))
+

+@cute.jit

+    """Thread 0 arms barrier ``r`` for ``counts[r]`` FP32 pushes from each of 7 CTAs."""
+    if cute.arch.thread_idx()[0] == 0:

+                cute.arch.mbarrier_arrive_and_expect_tx(bars.iterator + r, 28 * count)
+        cute.arch.mbarrier_init_fence()

+def tensor_maps(specs, device):
+    """TMA descriptors (128 B each) in one device tensor.
+    Each spec: (pointer, dtype, dims, strides, box, swizzle, l2 promotion).
+
+    The bytes are uploaded with a copy on the current stream: the new tensor may
+    reuse a block freed by a kernel still pending on that stream (e.g. a warmup
+    launch's output), which a copy outside the stream would race with."""
+    encoded = bytearray()
+    with torch.accelerator.device_index(torch.device(device).index):
+        for pointer, dtype, dims, strides, box, swizzle, l2 in specs:
+            u64 = ([cuda.cuuint64_t(v) for v in values] for values in (dims, strides))
+            u32 = ([cuda.cuuint32_t(v) for v in box], [cuda.cuuint32_t(1)] * len(dims))
+            interleave = cuda.CUtensorMapInterleave.CU_TENSOR_MAP_INTERLEAVE_NONE
+            fill = cuda.CUtensorMapFloatOOBfill.CU_TENSOR_MAP_FLOAT_OOB_FILL_NONE
+            status, tensor_map = cuda.cuTensorMapEncodeTiled(
+                dtype, len(dims), pointer, *u64, *u32, interleave, swizzle, l2, fill
+            )
+            if status != cuda.CUresult.CUDA_SUCCESS:
+                raise RuntimeError(f"cuTensorMapEncodeTiled failed: {status}")
+            encoded += (ctypes.c_ubyte * 128).from_address(tensor_map.getPtr())
+    return torch.frombuffer(encoded, dtype=torch.uint8).to(device)

+    """Load fragment ``i`` into ``values[i]``; returns its dirty flag at bit ``i``."""
+    got = load_words(pointer, count=4, volatile=True)

+def poll(base, stride, count: cutlass.Constexpr[int]):
+    """Lamport-poll ``count`` 16-byte fragments at base + i*stride (elements); all
+    loads issue before any check and only dirty fragments re-poll."""
+    values = cute.make_rmem_tensor((count, 4), Uint32)
+    pending = Uint32(0)
+    for i in cutlass.range_constexpr(count):
+        pending = pending | fetch(values, i, base + i * stride)
+    while pending != 0:
+        again = Uint32(0)
+        for i in cutlass.range_constexpr(count):
+            if (pending >> i) & 1:
+                again = again | fetch(values, i, base + i * stride)
+        pending = again
+    return values

+"""L2 weight prefetch: each warp walks a persistent device table of (address, bytes),
+spreading 16-KiB chunks over the grid in table order. The owner retains the weights
+and table through graph replay; activations and mutable caches may not be ranges
+before their producer completes."""
+
+import functools
+
+import cutlass
+import cutlass.cute as cute
+import torch
+from cutlass.cute.runtime import make_fake_stream
+
+from .host import fake
+from .primitives import launch, prefetch_bulk, thread
+
+
+class L2Prefetch:
+    def __init__(self, grid, carveout):
+        self.grid, self.carveout = grid, carveout
+
+    @cute.jit
+    def __call__(self, *args):
+        options = dict(pdl=False, preferred_smem_carveout=self.carveout)
+        launch(self.kernel, args, self.grid, 32, **options)
+
+    @cute.kernel
+    def kernel(self, args):
+        (ranges,) = args
+        cute.arch.griddepcontrol_launch_dependents()
+        tid, _, _, block = thread()
+        worker = cutlass.Int64(block * 32 + tid)
+        workers = cutlass.Int64(self.grid * 32)
+        phase, row = cutlass.Int64(0), cutlass.Int32(0)
+        while row < ranges.shape[0]:
+            base, nbytes = ranges[row, 0], ranges[row, 1]
+            if (base != 0) & (nbytes > 0):
+                chunks = (nbytes + 16384 - 1) // 16384
+                index = worker - phase % workers
+                if index < 0:
+                    index += workers
+                while index < chunks:
+                    offset = index * 16384
+                    size = nbytes - offset
+                    if size > 16384:
+                        size = cutlass.Int64(16384)
+                    size = size & cutlass.Int64(-16)
+                    if size > 0:
+                        address = (base + offset) & cutlass.Int64(-16)
+                        prefetch_bulk(address, size.to(cutlass.Int32))
+                    index += workers
+                phase += chunks
+            row += 1
+        # Early exit must not let a later grid bypass its producer.
+        cute.arch.griddepcontrol_wait()
+
+
+@functools.cache
+def compile_kernel(count, grid, carveout, device_index):
+    ranges = fake((count, 2), None, torch.int64)
+    with torch.accelerator.device_index(device_index):
+        return cute.compile(L2Prefetch(grid, carveout), ranges, make_fake_stream())
