## Motivation
Current slicing strategy in `init_forward_metadata_replay_cuda_graph` will create an intermediate tensor of size [total_requests, max_seq_pages]. 

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->

## Modifications
- Replace the broadcasting approach that created a full [total_requests, max_seq_pages] intermediate tensor with a two-step indexing strategy that only allocates memory for the required batch elements
