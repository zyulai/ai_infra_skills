## 正文(PR 描述)

## Purpose

Mono audio with an explicit channel dimension can fail in Whisper preprocessing.
For example, passing a `(1, 16000)` waveform at 16 kHz through the offline audio
tuple path raises `ValueError: Failed to apply WhisperProcessor`, while the same
samples in a `(16000,)` array work.

`normalize_audio` returns early when the input channel count already matches
the target, leaving a 2D array for mono input. This also makes
`AudioProcessorItems.get_audio_length()` report 1 instead of 16000.

Return the only channel as a 1D waveform when the target is mono. Extend the
existing NumPy, Torch and parser tests to cover both channel layouts and the
single-sample case.

This reproduces without resampling. #47693 changes the order of normalization
and resampling, #56023 addresses unsupported multi-channel reduction, and
#51022 optimizes downmixing. Their current patches leave this early return
unchanged.

Also compare the same one-second WAV in `(16000,)`, `(1, 16000)` and `(16000, 1)`
layouts through vLLM's Whisper multimodal processor, using the official
`openai/whisper-tiny` configuration, tokenizer and feature extractor.

## Test Result

- Focused regression cases: **8 failed, 3 passed before; 11 passed after**.
- Audio and parser selection on main `fa1b3b1922` plus this patch:
  **71 passed, 1 skipped, 8 deselected**.
- Whisper preprocessing: both 2D layouts failed before. After the fix, all
  three layouts produce exactly equal features, prompt tokens and placeholder
  ranges. Feature shape is `(1, 80, 3000)` and parsed audio length is 16000.
- Applicable pre-commit hooks passed. Actionlint was skipped; no workflows changed.

The local environment has no matching torchaudio build. An earlier full audio
test run had 55 passes and 7 failures due to that missing dependency; the
filtered run excludes those cases and the default-backend assertion. The
skipped parser test requires CUDA. Whisper validation covers CPU preprocessing;
model generation and accuracy evaluation have not been run.

AI assistance was used, and I reviewed all the changes and tests.
