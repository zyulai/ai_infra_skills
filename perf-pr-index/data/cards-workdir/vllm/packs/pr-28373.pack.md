## Purpose
This PR add following support for Qwen3-Omni series models: [Qwen/Qwen3-Omni-30B-A3B-Thinking](https://huggingface.co/Qwen/Qwen3-Omni-30B-A3B-Thinking), [Qwen/Qwen3-Omni-30B-A3B-Instruct](https://huggingface.co/Qwen/Qwen3-Omni-30B-A3B-Instruct), [Qwen/Qwen3-Omni-30B-A3B-Captioner](https://huggingface.co/Qwen/Qwen3-Omni-30B-A3B-Captioner)

- Add triton moe kernel tunning support for Qwen3-Omni models
- Extend `waves_per_eu_range` in `get_rocm_tuning_space` based on: https://rocm.docs.amd.com/en/latest/how-to/rocm-for-ai/inference-optimization/workload.html#auto-tunable-kernel-configurations
- Add tuned optimized fused MoE config on 1xMI308X (TP=1) with rocm 7.0.0 on MI308X.  This was generated by running `python3 benchmarks/kernels/benchmark_moe.py --model /models/Qwen3-Omni-30B-A3B-Thinking --tp-size 1 --dtype auto --tune`

Consistent and significant performance improvements across all metrics
This tuned configuration significantly improves the performance of Qwen3-Omni-30B-A3B-Thinking on AMD MI300X GPUs with tensor parallelism of 1, and it can also bring performance improvement for `Qwen3-30B-A3B*` and `Qwen3-Omni-30B-A3B*` series models.
