## Purpose

#51794 enabled multi-stream overlap for CSA layers on ROCm but left HCA layers (main compressor present, no indexer) single-stream, because the ROCm attention subclass dropped its aux streams whenever no indexer exists. On `gfx950` the HCA main compressor is a large fraction of the attention-layer decode time and is fully independent of the query/KV chain: both branches only read the layer input (`hidden_states`) plus their own weights and state, and nothing on the default-stream chain consumes the compressor's outputs until the sparse attention.

For HCA layers the attention forward now forks inside the gated region:

- **Default stream:** fused wqa/wkv GEMM → q/kv RMSNorm → wq_b → qnorm/RoPE → SWA KV insert.
- **Aux stream 0:** HCA main compressor (fused wkv/wgate score GEMM + DeepseekCompressor).

The streams join before the sparse MLA attention, which reads the compressed KV cache and the SWA window. The serial MHC fused post+pre prelude keeps running on the default stream ahead of the fork; the fork's start event orders the aux chain after it.
