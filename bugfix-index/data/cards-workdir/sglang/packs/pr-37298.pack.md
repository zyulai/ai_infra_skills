## 正文(PR 描述)

## Summary

Follow-up fixes for failures observed in the post-rebase CI of #36507:

- make MTP IndexShare seed-width calculation architecture-neutral: GLM includes `index_kpool` tail slots, while DeepSeek-V4 C4 retains its unpooled `index_topk` width
- preserve Lean Attention workspaces in multi-step draft CUDA graph metadata
- update scheduler, HiSparse, MLX, FlashInfer hybrid, and TRTLLM graph test fakes for current request/backend contracts
- migrate stale Lean/MLA paged-KV tests to the dense 3-D views required by unified memory
- place the GSM8K threshold on both concrete GLM-5.3 classes (the mixin shadows values inherited from the server base)
- stabilize the tight 0.93 accuracy gate with the established DSA+MTP 500-question, 20-shot workload
- add regression coverage for GLM pooled DSA seed width, non-index-share EAGLE, and draft graph Lean metadata
