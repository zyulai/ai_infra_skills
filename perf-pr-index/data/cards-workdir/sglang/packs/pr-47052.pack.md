## Motivation

On ROCm, Qwen3 prefill runs QK-norm and RoPE as five launches per layer: `apply_qk_norm` copies the strided q and k views of the packed qkv to contiguous tensors, runs two aiter RMSNorms, then `rotary_emb` launches `rotary_embedding`. The fused path in `apply_qk_norm` is CUDA-only. In a Qwen3-8B prefill profile on MI355X (batch 1/8, input 2048/8192, main `7fe5b127e4`) these kernels take 4.8% to 6.8% of GPU kernel time.

The diffusion JIT kernel `fused_inplace_qknorm_rope` already does this in one in-place launch (strided q/k, GQA, fp32 cos/sin cache table), but it does not compile on HIP: bare `__shfl_sync` with a 32-bit mask hits HIP's 64-bit-mask static_assert. So the ROCm path enabled in #35573 silently falls back to the unfused ops; the kernel's tests are registered for CUDA CI only. #40585 fixes the same shuffles for MiniMax-H3; this PR carries an equivalent fix so it does not depend on it. #47001 (open) adds the same in-place fusion for XPU through sgl-kernel-xpu, and #47785 (open) a CUDA prefill fusion; all three change `forward_prepare_native`, so whichever lands later needs a small rebase.

## Modifications

Scope: ROCm only. On HIP the kernel's NeoX variants with `round_norm_before_rope=True` now build. Two ROCm callers request them: Qwen3 attention, which also serves the models built on `Qwen3Model` (such as Qwen3-Embedding and InternVL) when the gate below accepts them, and ERNIE-Image, which keeps the fused kernel only if its first call matches its reference bit for bit. NeoX with `round_norm_before_rope=False` and KV packing stay off on HIP, so their callers, such as Cosmos3 video, keep the separate ops as on main. GPT-J variants, CUDA, XPU, NPU, and the aiter decode fusion are unchanged.

- `qknorm_rope.cuh`: on HIP, shuffle with `__shfl` / `__shfl_xor` at width 32 (the kernel's logical warp on wave64). CUDA builds are unchanged.
- `qknorm_rope_jit.py`: on HIP, `can_use_fused_inplace_qknorm_rope` returns False and a direct call raises `NotImplementedError` for the two variants without AMD numerical coverage, KV packing and NeoX with `round_norm_before_rope=False`.
- `models/utils.py`: add `can_use_jit_qk_norm_rope`, which gates on HIP, `--enable-fused-qk-norm-rope` not set to off, plain `RotaryEmbedding` with an fp32 cache, plain `RMSNorm` weights in the activation dtype, and no deterministic / on-policy / inductor prefill mode, and builds the kernel at init so it is never first built during graph capture; add `apply_qk_norm_rope`, which runs the kernel in place with `round_norm_before_rope=True` or falls back to `apply_qk_norm` + `rotary_emb`.
- `qwen3.py`: outside the CUDA decode branch from #46908, `forward_prepare_native` calls `apply_qk_norm_rope`. On ROCm it serves prefill / extend, and decode when the aiter decode fusion from #44267 does not apply.
- `test_qk_norm_rope_hip.py` (new, AMD CI): fused vs unfused path on strided views over head/rotary dims, GQA ratios, neox and GPT-J, 0 to 4096 tokens, fp16, int32 positions; the fused result must be no farther from an fp64 reference than the unfused one; the kernel gate rejects the two variants above on HIP; YaRN, mRoPE, eps mismatch, fp32 norm weights, deterministic, on-policy, inductor and `--no-enable-fused-qk-norm-rope` fall back.
- `test_qknorm_rope_out_of_place.py`: register for AMD CI; skip the two-rows-per-warp comparison on HIP, which builds only the one-row-per-warp kernel.

+def can_use_jit_qk_norm_rope(
+    q_norm: RMSNorm,
+    k_norm: RMSNorm,
+    rotary_emb: torch.nn.Module,
+    head_dim: int,
+    dtype: torch.dtype,
+) -> bool:
+    """Whether ``apply_qk_norm_rope`` may fuse QK-norm and RoPE into the JIT
+    qknorm_rope kernel (ROCm only). Call it at init: it builds the kernel, which
+    must not happen for the first time inside CUDA graph capture."""
+    from sglang.srt.layers.layernorm import RMSNorm
+    from sglang.srt.layers.rotary_embedding import RotaryEmbedding
+
+    if not (
+        _is_hip
+        # None (unset) keeps it on; only --no-enable-fused-qk-norm-rope opts out.
+        and get_exec().kernel.enable_fused_qk_norm_rope is not False
+        and not envs.SGLANG_ENABLE_DETERMINISTIC_INFERENCE.get()
+        and get_exec().deterministic.rl_on_policy_target is None
+        and get_exec().graph.cuda_graph_config.prefill.tc_compiler != "inductor"
+        and dtype in (torch.bfloat16, torch.float16)
+        # Scaled-RoPE subclasses (YaRN, Llama3, MRoPE, ...) stay on the unfused path.
+        and type(rotary_emb) is RotaryEmbedding
+        and not rotary_emb._force_native
+        and rotary_emb.head_size == head_dim
+        and rotary_emb.cos_sin_cache.dtype == torch.float32
+        and type(q_norm) is RMSNorm
+        and type(k_norm) is RMSNorm
+        and q_norm.variance_epsilon == k_norm.variance_epsilon
+    ):
+        return False
+    for norm in (q_norm, k_norm):
+        if (
+            not norm.has_weight
+            or norm.cast_x_before_out_mul
+            or norm.variance_size_override is not None
+            or norm.weight.dtype != dtype
+        ):
+            return False
+
+    from sglang.kernels.ops.diffusion.rope.qknorm_rope_jit import (
+        can_use_fused_inplace_qknorm_rope,
+    )
+
+    return can_use_fused_inplace_qknorm_rope(
+        head_dim,
+        rotary_emb.rotary_dim,
+        rotary_emb.is_neox_style,
+        dtype,
+        torch.float32,
+        round_norm_before_rope=True,
+    )

+def apply_qk_norm_rope(
+    q: torch.Tensor,
+    k: torch.Tensor,
+    q_norm: RMSNorm,
+    k_norm: RMSNorm,
+    rotary_emb: torch.nn.Module,
+    positions: torch.Tensor,
+    head_dim: int,
+    alt_stream: Optional[torch.cuda.Stream] = None,
+    use_jit: bool = False,
+) -> Tuple[torch.Tensor, torch.Tensor]:
+    """QK-norm followed by RoPE. With ``use_jit`` (from ``can_use_jit_qk_norm_rope``)
+    both run in place as one kernel; otherwise ``apply_qk_norm`` then ``rotary_emb``."""

+    if (
+        use_jit
+        and positions.dim() == 1
+        # A dtype other than the one checked at init would build a new kernel here.
+        and q.dtype == q_norm.weight.dtype

+            # HIP rejects a zero-size grid.
+            return q, k
+        from sglang.kernels.ops.diffusion.rope.qknorm_rope_jit import (
+            fused_inplace_qknorm_rope,
+        )
+
+        rotary_emb._match_cos_sin_cache_dtype(q)
+        fused_inplace_qknorm_rope(
+            q.view(num_tokens, -1, head_dim),
+            k.view(num_tokens, -1, head_dim),

+            k_norm.weight,
+            rotary_emb.cos_sin_cache,
+            positions,

+            eps=q_norm.variance_epsilon,
+            head_dim=head_dim,
+            rope_dim=rotary_emb.rotary_dim,
+            round_norm_before_rope=True,
+        )
+        return q, k
+
+    q, k = apply_qk_norm(
+        q=q,
+        k=k,
+        q_norm=q_norm,
+        k_norm=k_norm,
+        head_dim=head_dim,
+        alt_stream=alt_stream,
+    )
+    return rotary_emb(positions, q, k)

+def _fp64_reference(x, weight, positions, eps, head_dim, rotary_dim, is_neox):
+    x = x.double().view(x.size(0), -1, head_dim)
+    x = x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + eps) * weight.double()
+    inv_freq = BASE ** (
+        -torch.arange(0, rotary_dim, 2, device=x.device, dtype=torch.float64)
+        / rotary_dim
+    )
+    freqs = positions.double()[:, None] * inv_freq[None, :]
+    cos, sin = freqs.cos()[:, None, :], freqs.sin()[:, None, :]
+    rot = x[..., :rotary_dim]
+    if is_neox:
+        x1, x2 = rot.chunk(2, dim=-1)
+        rot = torch.cat((x1 * cos - x2 * sin, x2 * cos + x1 * sin), dim=-1)
+    else:

+        rot = torch.stack((x1 * cos - x2 * sin, x2 * cos + x1 * sin), dim=-1)
+        rot = rot.flatten(-2)
