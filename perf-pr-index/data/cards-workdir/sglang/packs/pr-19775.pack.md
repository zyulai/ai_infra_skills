## Motivation

<!-- Describe the purpose and goals of this pull request. -->

There are three key kernels in GDN. This PR is concerned with the last kernel.
- for extend
- for decode
- for verify_target

Currently in GDN, verify path uses fused_gdn_gating + fused_recurrent_gated_delta_rule_update. Our goal is to fuse them into one kernel, so as to improve performance. (reduce kernel launch time, reduce register usage)

Our first approach is to directly leverage `fused_sigmoid_gating_delta_rule_update`. Then we encountered the obstacle that this kernel is a simple kernel designed for decode (single-step update) and does not have the state control (write-back prohibition), intermediate state caching, and tree attention support required by target verification. The cumulative effect of these three deficiencies has led to a collapse in accuracy from 0.83 to 0.35. (See the first commit of this PR)

Given the background, in this PR we introduced a new kernel `fused_sigmoid_gating_delta_rule_update_mtp` which does not write-back state, it has tree attention to support target verification and provides intermediate state caching.

[Update] After refactoring based on @kaixih 's comments, reused `fused_sigmoid_gating_delta_rule_update` and added new logic inside this kernel, so as in the future when KDA support MTP, it can also leverage this feature.

For seq-lens 8k input 1.5k output, TTFT improved 11%.

gsm8k has no drop.
