## 正文(PR 描述)

## Motivation

I am learning core parts of SGLang and spent some time in the detokenizer and tokenizer managers. A few these are small changes which are more idiomatic / improve memory or compute, but the big change is moving non streaming request processing to be more efficient and avoid O(N^2) operations.

## Modifications


* `async_dynamic_batch_tokenizer.py` 
   - kwargs batch check: Replace set(str(sorted(kw.items()))) with direct all(kw == first_kw ...) to avoid string serialization overhead
* `detokenizer_manager.py`
    - batch_decode fast-path: Merge two separate all(...) passes over skip_list/space_list into one zipped pass
    - streaming chunk update: len(new_text) > 0 → new_text, s.decoded_text = s.decoded_text + new_text → +=
* `tokenizer_manager.py`
    - Further honors `stream_output` (default in `server_args` is False).
    - ReqState buffer mode implementation + helper to improve non streaming request processing without affecting streaming mode
    - _wait_one_response now checks self.server_args.stream_output. I believe this should be checked
    - added dump when we fail as we are changing intermediate state processing
    - disconnect if there are request issues

## Accuracy Tests

This should not affect accuracy.
