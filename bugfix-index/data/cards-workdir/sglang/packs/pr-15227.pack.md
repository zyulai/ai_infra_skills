## 正文(PR 描述)

## Motivation

Fix issue [15132](https://github.com/sgl-project/sglang/issues/15132)

Fix batch_size mismatch error in DP Attention IDLE mode with NSA Indexer.

In DP Attention, when some DP ranks have no actual requests, they enter IDLE mode. After `prepare_mlp_sync_batch`, these IDLE batches are padded (batch_size > 0) to participate in MLP sync. However, `forward_idle` did not reinitialize the attention metadata, causing stale metadata from the previous batch (with a different batch_size) to be used. This led to assertion failures in attention kernels like `deep_gemm.fp8_paged_mqa_logits`.

Error example:
```
RuntimeError: Assertion error (attention.hpp:160): batch_size == batch_size_ and batch_size == batch_size__
```

## Modifications

- Add `init_forward_metadata` call in `forward_idle` when `batch_size > 0` to ensure metadata is consistent with the current padded IDLE batch.
