## Motivation

The new arguments of vllm::fused_add_rms_norm() were introduced only in the ROCm/vllm 355_wip development branch but are not present in the vllm-project/vllm or ROCm/vllm main branches.
Currently, the rocm.Dockerfile uses vllm, which still only has 4 arguments. https://github.com/ROCm/vllm/blob/9f6b92db47c3444b7a7d67451ba0c3a2d6af4c2c/vllm/_custom_ops.py

## Modifications

Revert the code changes from PR #10032.
