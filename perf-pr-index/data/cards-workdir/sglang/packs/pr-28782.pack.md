## PR body
```markdown
## Summary
- Run the EAGLE draft-extend forward as a captured CUDA graph for FlashInfer (add `FlashInferAttnBackend` to the draft-extend graph whitelist), replacing eager per-layer launches.
- ~10% online median E2E latency improvement (request-rate 8, Llama-2-7B EAGLE topk=4); accept length unchanged.

## Changes
- **Graph capture**: add `is_draft_extend_v2()` branches to `_prepare_cuda_graph_metadata` / `init_forward_metadata_out_graph` so the draft-extend forward replays as a causal paged-prefill graph.
- **Fixed qo layout**: `EagleDraftExtendInput.generate_attn_arg_prefill` uses a constant `num_draft_tokens` qo layout (required for graph capture/replay), matching the padded draft-extend input.
- **Drop a per-step D2H**: pass host-known `extend_prefix_lens_cpu` into `FlashInferIndicesUpdaterPrefill.update`, replacing `paged_kernel_lens.sum().item()` with a host-side sum.

## Notes
- FR-Spec (`speculative_token_map`) falls back to eager: the draft-extend graph buffers are sized to the full draft vocab and are incompatible with the reduced (hot) vocab head.
```
