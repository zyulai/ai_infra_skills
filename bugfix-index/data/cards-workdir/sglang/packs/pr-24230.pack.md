## Motivation
https://github.com/sgl-project/sglang/pull/19746 introduces radix tree on pd-decode side;

In PD disaggregation with radix cache enabled on the decode side, `_pre_alloc()` writes `req_to_token_pool` as `[prefix_locs (0..pre_len) | delta_locs (pre_len..seq_len)]`. When there is a prefix hit (`pre_len > 0`), `prepare_for_prebuilt()` incorrectly slices from index 0 (`[:extend_input_len]`), reading prefix locations instead of the delta region. This fix offsets the slice by `pre_len` (`[pre_len : pre_len + extend_input_len]`) to read the correct range.、
