## 正文(PR 描述)

1. The version of `pixel_shuffle` used in `intern-s1` is incorrect and the `ps_version` parameter needs to be removed
2. The image processing models in `intern-s1` and `internv1` do not support passing `input_ids` through the generation interface, which needs to be fixed.
3. In the RL scenario, weight updates are incremental, and the `weight update` code for interns1 and internvl needs to be fixed.
