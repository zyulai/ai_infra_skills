## Motivation

When overlap scheduling is enabled, the last_batch needs to wait for the curr_batch to finish launching before output processing can begin. However, if both last_batch and curr_batch are in extend mode for forward_mode, last_batch may have to wait for a longer period, resulting in a longer TTFT.

## Modifications

When both last_batch and curr_batch are in extend mode for forward_mode, prioritize the output processing of last_batch.
