## PR body
```markdown
1. Cache character counts in NodeText struct to avoid O(n) chars().count() calls on every operation - eliminates repeated UTF-8 character counting
2. Intern tenant IDs using Arc<str> instead of String - reduces memory allocations and enables cheap cloning/comparison
3. Replace slice_by_chars() with NodeText::split_at_char() - computes both prefix and suffix in a single pass with cached char counts
4. Add batched timestamp updates with 5ms staleness threshold - reduces syscall overhead while maintaining accuracy for LRU eviction
5. Use custom CharHasher for single-char keys in children DashMap -  optimized hashing for common char-indexed lookups
6. Add graceful shutdown for eviction thread - uses AtomicBool flag to cleanly stop background thread on Drop
```
