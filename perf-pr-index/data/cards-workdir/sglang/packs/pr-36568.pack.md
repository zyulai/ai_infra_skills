## Motivation

When the attention DP size is 1, scheduler metadata is already local and rank-invariant. Gathering the same batch mode, graph eligibility, and token counts across the TP schedulers adds a device collective and host synchronization without reconciling any cross-DP state.

SGLang already exposes `SGLANG_SCHEDULER_SKIP_ALL_GATHER` as a manual override. This PR makes the skip the default for DP1 while preserving the existing opt-in behavior for larger DP sizes.

## Modifications

- Skip the scheduler metadata all-gather automatically when `dp_size == 1`.
- Preserve the existing environment override for deployments that explicitly skip the gather with multiple DP ranks.
- Finalize the single-rank metadata locally so TBO split metadata, global/recv forward mode, token counts, graph eligibility, and optional DP metrics remain available without the collective.
- Keep the existing multi-DP no-override path unchanged.
- Add registered CPU unit coverage for the skip policy and the DP1 local-metadata/TBO path.
