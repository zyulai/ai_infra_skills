## 正文(PR 描述)

Reverts sgl-project/sglang#27529, since it cause
- kernel perf regression issue noted here: https://github.com/sgl-project/sglang/pull/27529#pullrequestreview-4469436235
- cuda graph launch error has been solved by https://github.com/sgl-project/sglang/pull/27380, and it's logic also conflict with  sgl-project/sglang#27529 which will cause crush issue again.
