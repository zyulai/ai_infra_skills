## Overview

Pending on vllm-xpu-kernels PR [#616](https://github.com/vllm-project/vllm-xpu-kernels/pull/616). This PR uses refined `multimodal_rotary_embedding` xpu kernel to replace triton kernel path, getting ~13% throughput improvement. It also unifies the XPU path with the CUDA implementation and avoids maintaining divergent dispatch behavior.
