## 正文(PR 描述)

## Purpose
After this PR: https://github.com/vllm-project/vllm/pull/42076, during running of Qwen3.5-9B model that uses GDN triton kernel on RDNA GPUs, warmup time went from ~150s to ~2400s. The problem was that operands of tl.dot() were casted to fp32, so that operation lowered to software fp32 matmul instead of wmma instuction.
These changes are modifying kernel only for RDNA GPUs, while they are untouched for all other GPUs.

## Test Plan
Tests were performed on qwen3.5-9b model. After proposed changes are applied warmup time goes back to ~150s. 
Also, tests on gsm8k benchmark were done, and correctness is preserved on RDNA GPUs, while kernel is untouched for all other GPUs. 
After detailed testing of IRs and compilation times for each stage, regression happens in amdgcn stage where the difference is about 190x.
