## Motivation

On NPU, the shared expert and routed expert in MoE models are executed sequentially on the same stream, leaving compute resources underutilized. This PR introduces a dual stream optimization that overlaps shared expert computation with routed expert computation on independent NPU streams.

## Modifications

- Added `shared_expert_on_independent_stream` in `cmo.py` to offload shared expert computation to independent NPU streams with dedicated core allocation (8 cores).
- Modified `Qwen2MoeModel._forward_deepep` to execute shared expert and routed expert on separate streams in parallel when `SGLANG_NPU_USE_MULTI_STREAM` is enabled during CUDA graph mode.
