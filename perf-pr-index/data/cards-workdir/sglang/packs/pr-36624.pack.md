## Summary

Three changes, all SM10X.

**One stream, not one per layer.** `Cohere2MoeSparseMoeBlock.__init__` called `torch.cuda.Stream()`, so the model built 32 of them. The caching allocator segments its pool per stream, and prefill capture then ran to 19.02 GiB of graph pool plus 23.83 GiB stranded as reserved-but-unallocated, past the ~45.7 GiB of headroom. It OOM'd, which is why the breakable CUDA graph (BCG) prefill backend was unusable here. Leasing the shared `get_stream("alt")` cuts capture to 5.34 GB and puts the arch on the breakable allowlist.

**Overlap the parallel block.** `y = x + attn(norm(x)) + mlp(norm(x))` makes the two halves independent, but they ran back to back on one stream, and at decode neither fills the GPU. The MLP moves to a second side stream, giving three concurrent chains. Two things come with that. `FusedMoE` takes `inplace=False`, since the default aliases the routed-expert output onto its input and would overwrite the post-layernorm buffer while `qkv_proj` still reads it on the other stream. And the fork/join runs only under `forward_mode.is_decode()`, since `get_is_capture_mode()` covers prefill chunks too.

**Pin the MoE runner.** `auto` emits routing, `expandInputRows`, activation and finalize as separate kernels around the expert GEMM, all of which trtllm-gen folds into one. The gate fires only on unquantized or positively-NVFP4 checkpoints — compressed-tensors FP8 stays on `auto`, since `CompressedTensorsW8A8Fp8MoE` hands trtllm-gen a `TritonMoeQuantInfo` it rejects at the first forward.

## Results

4x GB300 (SM103), tp=4, random 8192-in / 1024-out, `--num-prompts 4*C`, `--warmup-requests 2*C`.

Both sides run `--mem-fraction-static 0.75` and `--cuda-graph-backend-prefill breakable`, so the tables measure this change rather than the backend switch. That framing is generous to the baseline: at the default mem-fraction there is no before column at all, because capture OOMs, and 0.75 only buys it back by giving up ~10% of the KV cache (6,362,112 -> 5,710,976 tokens).
