## Motivation

https://github.com/sgl-project/sglang/pull/10749
This PR fixes an issue in Qwen3-MOE where `fused_set_kv_buffer_arg` was passed to `q, k = self.rotary_emb`, but only `RotaryEmbedding` accepts this argument.

When Qwen3-VL is launched, it calls the Qwen3-MOE interface but actually uses `MRotaryEmbedding` instead of `RotaryEmbedding`, which caused the model to fail to launch.

This PR resolves the problem.
