## Summary
- remove `torch.inference_mode()` from the FlashInfer autotune context and shared dummy warmup forward without adding an explicit `torch.no_grad()` context
- avoid creating inference tensors for lazily allocated workspaces that eager serving and CUDA graph capture later update in place
