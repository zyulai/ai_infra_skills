## Motivation

LongLive 2's lossless Wan VAE decoder executes five separate FP32 pointwise passes after normalization. In the native I2V profile, the 464 norm/SiLU scopes take **690.82 ms across 3248 kernels**. Keeping Torch's reduction and fusing only the exact post-ops reduces that to **275.26 ms / 1834 kernels**, including first-sight reference checks and fallback calls.

On **one H200**, final-source I2V A–B–B–A groups reduce worker E2E by **5.53–5.88%**. The representative final group reduces client E2E including video save from **5.980 to 5.665 s (5.27%)**. All lossless before/after videos are byte-identical. T2V worker latency improves, but retained client outliers prevent a T2V client E2E speed claim.

## Modifications

- Keep native autocast-aware L2 normalization and epsilon clamp, then fuse divide, scale, affine multiplication, bias addition and SiLU into one JIT CUDA kernel. Inputs/gamma may be BF16, while the normalized intermediates and output remain FP32.
- Use explicit FP32 round-to-nearest operations and `expf`, with FMA contraction disabled and no fast math. Support dense NCDHW and channels-last-3D layouts through the existing JIT utilities.
- Integrate through the shared Wan VAE wrapper with per-signature integer-bit verification and permanent fallback on mismatch. Unsupported dtype/layout, gradient-enabled, compiled and unverified-capture calls retain the native path. Unsupported post-op inputs reuse the already-computed denominator.
- Preserve the existing high-quality full RMSNorm+SiLU dispatch. Keep three focused tests for autocast/layout/affine behavior, numerical boundaries and graph replay, and update fusion-coverage documentation.

The existing Wan full-norm fusion (#33546, #35981) and the open conv-bias/full-norm tiling work in #38650 are distinct from this lossless post-only path. The shared wrapper also serves other Wan/Qwen VAEs; this PR's native model evidence covers LongLive 2 T2V and I2V. Other model families are protected by the first-sight exactness gate but are not claimed as benchmarked here.

[Source review and execution flow](https://github.com/BBuf/sglang/blob/5af31ea3b6b434c21b2014ea2834876317818058/diffusion-prs/longlive2-wan-norm-post-h200/source-review.md). FLASHINFER_DISABLE_VERSION_CHECK=1 SGLANG_DIFFUSION_SYNC_STAGE_PROFILING=1 \
sglang generate --backend=sglang \

  --image-path=/path/to/input-cat.png --seed=42 \

  --num-inference-steps=4 --guidance-scale=1.0 \
  --num-gpus=1 --tp-size=1 --enable-torch-compile=false \

  --quality=lossless --save-output --warmup-mode=request \
  --perf-dump-path=/tmp/longlive2-i2v.json \
  --output-path=/tmp/longlive2-i2v --output-file-name=longlive2-i2v

+/// \brief Fuse FP32 divide, scale, affine, and SiLU without changing aten's L2 reduction.
+template <typename X, typename A, bool kChannelsLast>
+__global__ void wan_norm_silu_post_kernel(
+    const X* __restrict__ input,
+    const float* __restrict__ denominator,
+    const A* __restrict__ gamma,
+    const A* __restrict__ bias,
+    float* __restrict__ output,
+    int64_t num_vecs,
+    int64_t channels,
+    int64_t spatial,
+    float scale,
+    bool has_bias) {
+  constexpr int kVec = 4;
+  const int64_t step = static_cast<int64_t>(blockDim.x) * gridDim.x;
+  for (int64_t vec = static_cast<int64_t>(blockIdx.x) * blockDim.x + threadIdx.x; vec < num_vecs; vec += step) {
+    device::AlignedVector<X, kVec> x;
+    device::AlignedVector<float, kVec> d;
+    device::AlignedVector<A, kVec> g;
+    device::AlignedVector<A, kVec> b;
+    device::AlignedVector<float, kVec> result;
+    x.load(input, vec);
+    float shared_d = 0.f, shared_g = 0.f, shared_b = 0.f;
+    if constexpr (kChannelsLast) {
+      const int64_t channel = vec * kVec % channels;
+      shared_d = denominator[vec * kVec / channels];
+      g.load(gamma, channel / kVec);
+      if (has_bias) b.load(bias, channel / kVec);
+    } else {
+      const int64_t channel = vec * kVec / spatial % channels;
+      const int64_t batch = vec * kVec / (spatial * channels);
+      const int64_t pixel = vec * kVec % spatial;
+      d.load(denominator, (batch * spatial + pixel) / kVec);
+      shared_g = device::cast<float>(gamma[channel]);
+      if (has_bias) shared_b = device::cast<float>(bias[channel]);
+    }
+#pragma unroll
+    for (int i = 0; i < kVec; ++i) {
+      const float denom = kChannelsLast ? shared_d : d[i];
+      const float weight = kChannelsLast ? device::cast<float>(g[i]) : shared_g;
+      const float offset = has_bias ? (kChannelsLast ? device::cast<float>(b[i]) : shared_b) : 0.f;
+      float y = __fdiv_rn(device::cast<float>(x[i]), denom);
+      y = __fmul_rn(y, scale);
+      y = __fmul_rn(y, weight);
+      y = __fadd_rn(y, offset);
+      result[i] = __fdiv_rn(y, __fadd_rn(1.f, expf(-y)));
+    }
+    result.store(output, vec);
+  }
