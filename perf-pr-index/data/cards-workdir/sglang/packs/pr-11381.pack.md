## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The All-Reduce in VL model inference has a high proportion.
<img width="2946" height="1594" alt="image" src="https://github.com/user-attachments/assets/34fd7698-a81c-443e-a02e-8ec54b68d88f" />

Qwen2.5-VL-72B uses inplace all-reduce, by default is NCCL AR which is inefficient.

<img width="2976" height="1490" alt="image" src="https://github.com/user-attachments/assets/5ac2c56a-61cb-4e32-88d7-2f40bad08bbe" />

This PR introduces in-place Symm Mem All-Reduce for Qwen2.5-VL model. (Literally for any other models using in-place AR) Improved 2% e2e input throughput. Single AR latency drops from 446.9us to 209.1us.
For Qwen3-VL model, improved 3.9% e2e input throughput.

```
python -m sglang.launch_server \
  --model-path /home/admin/Qwen2.5-VL-7B-Instruct \
  --host 0.0.0.0 --port 30000 --trust-remote-code \
  --tp-size 4 --enable-cache-report  --log-level info \
  --max-running-requests 64 --mem-fraction-static 0.65 \
  --chunked-prefill-size 8192  --attention-backend fa3 \
  --chat-template qwen2-vl --mm-attention-backend fa3 
  --enable-torch-symm-mem
```
