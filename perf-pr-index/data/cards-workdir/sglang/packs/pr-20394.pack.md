## Modifications

* The kernel will always output in bf16, so we might have to cast it back to the hidden states dtype.
* Enable align_fp8_moe_weights_for_flashinfer_trtllm for the routed version
* Use same fused_func as non-routed and just use topk output checker to determine which one to run.
* Fix issue where `getattr` doesn't use the default value when the attr is set to none.
* Add comments to enable autotune, remove copy when flashinfer bugs are fixed.

## Issues

* There is a flashinfer bug preventing autotuning, so we just skip it. I was able to work around it but the perf isn't any different. https://github.com/flashinfer-ai/flashinfer/issues/2749
* Passing output tensor to the fp8 kernel doesn't work https://github.com/flashinfer-ai/flashinfer/issues/2703
* The monolithic kernel would be faster if possible, so I opened a feature request to support Minimax's routing method https://github.com/flashinfer-ai/flashinfer/issues/2736
