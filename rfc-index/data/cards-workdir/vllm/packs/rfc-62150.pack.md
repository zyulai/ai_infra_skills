## 正文(PRD / 提案全文)

### Motivation.

RL training on PD disaggregation pauses, sleeps, aborts and resets the cache around every weight update. On main (`ce49c47`), only 8 of 27 lifecycle cases pass with MooncakeConnector on GB300. The rest block a pause for 480 s, wedge D, or return 500.

**Tracker:** https://claude.ai/artifact/5yU9HihNDSW86B1oZFL2mc


### Proposed Change.

Merge in this order:

- [x] #59625 Mooncake sleep mode
- [x] #60572 Drain async KV loads in a wait pause
- [ ] aoshen02/vllm#86 Answer every pull and free dropped transfers promptly (R1–R3)
- [ ] aoshen02/vllm#87 Release transfer-held KV before a cache reset (R4)
- [ ] aoshen02/vllm#88 Stop the decode stream when its prefill fails (R5)
- [ ] aoshen02/vllm#104 Let P recompute KV that a cache reset dropped (optional, like SGLang's rebootstrap)

The fork PRs will be opened here one at a time. With all of them, the matrix passes 27 of 27.

Related: #59055 (sleep-mode memory).
