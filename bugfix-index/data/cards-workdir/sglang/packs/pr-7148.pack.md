## Motivation
This PR fixes: https://github.com/sgl-project/sglang/issues/5651

I attempted to deploy an R1 model using the FA3 backend with FP8 KV cache quantization, but encountered an initial error related to type mismatches.
![image](https://github.com/user-attachments/assets/ba9c415e-13a3-4d27-b703-3f96029d594e)

After resolving the type mismatch issue, a new error emerged during execution:
![image](https://github.com/user-attachments/assets/068aa24e-d6a2-443e-89af-6f264f872649)

This PR addresses both of the aforementioned problems. As a result, we can now successfully utilize FP8 KV cache with the FA3 backend, effectively doubling the available KV cache capacity.

This PR also fixes a small bug that while setting `SGLANG_LOG_EXPERT_LOCATION_METADATA=1`.
![image](https://github.com/user-attachments/assets/22ea088d-5708-4647-92ae-e96ed6c5a566)
