## Motivation
Follow https://github.com/sgl-project/sglang/pull/13731. The MXFP8 Group Quant Kernel uses a group-wise schedule. This scheduling strategy sometimes results in an unbalanced load. In this PR, we use a flatten schedule. Let's illustrate this with a concrete example:
Group-wise Schedule:
```
Group 0: CTA 0-> Tile 0, CTA 1-> Tile 1, ..., CTA N0 -> Tile N0
Group 1: CTA 0-> Tile 0, CTA 1-> Tile 1, ..., CTA N1 -> Tile N1
...
```
Flatten Schedule:
```
Group 0: CTA 0-> Tile 0, CTA 1-> Tile 1, ..., CTA N0 -> Tile N0
Group 1: CTA (N0+1)-> Tile 0, CTA (N0+2)-> Tile 1, ..., CTA (N0+1+N1) -> Tile N1
...
Group X: ..., CTA N_MAX -> Tile M, CTA 0 -> Tile (M+1), ...
```
