## Motivation

Optimize the CPU GDN (Gated Delta Network) kernels in fla.cpp to better match the fused Triton pipeline and improve prefill/decode performance on AVX512/AMX CPUs. Achieve ~1.5x speedup against current implementation.

## Modifications

change in `fla.cpp`.

* Fuse intra-chunk stages: KKT + lower-tri solve + recompute w/u without materializing A
* Fuse inter-chunk stages: state update + output without materializing h / v_new
* AVX512 kernels for decay mask, tril solve, and beta/g masking; brgemm + VNNI2 packing for matmul-heavy paths
