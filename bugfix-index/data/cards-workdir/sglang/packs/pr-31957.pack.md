## 正文(PR 描述)

## Summary

- require Moss-VL vision frame metadata to map one-to-one to image tokens
- reject mismatches instead of silently truncating both sides with `min(...)`
- cover metadata-more, token-more, and either-side-empty mismatches, plus a valid matching case

## Root cause

`_compute_vision_position_ids` previously used the smaller of the metadata and token counts. If either side was missing, it returned early. Both paths could silently build partial or empty vision position metadata while accepting the request.

The processor now fails closed with a count-specific `ValueError`; valid equal-count inputs retain the same position calculation.
