## Purpose

This PR add swap AB optimization to `fused_moe_kernel` to make better use of WGMMA. Similar as #20396.

For small BLOCK_SIZE_M cases (BLOCK_SIZE_M < 64), change the gemm from `a[M, K] @ b[K, N]-> c[M, N]` to `b[N, K] @ a[K, M] -> c[N, M]`.

2% to 4% e2e output token throughput improvement.

## Test Plan
```
pytest -s -v tests/kernels/moe/test_moe.py
```

## Test Result

Unit tests passed.

## Micro bench

Micro bench on H200 shows improvements for BLOCK_SIZE_M 16, and no degradation for BLOCK_SIZE_M 64.
