## PR body
```markdown
## Motivation

SGLang now publishes `sgl-deep-ep` wheels, so CUDA CI should consume the released wheel instead of rebuilding DeepEP from source in dedicated runner configurations and test suites.

## Modifications

- Add the pinned `sgl-deep-ep==0.1.0` Python dependency.
- Install GDRCopy and its system dependencies from the common CUDA dependency installer, while keeping GDRCopy optional on runners that do not need it.
- Use PyPI for CUDA 13 wheels and the SGLang cu129 wheel index for CUDA 12 runners.
- Remove the DeepEP source-build installer and its CI rollout controls.
- Merge all `*-deepep` registered tests into their matching standard hardware suites without changing `base`/`extra` stage metadata.
- Remove the dedicated DeepEP runner configurations and workflow jobs.
- Keep the separate NPU DeepEP installation path unchanged.

## Accuracy Tests

No model code is changed. This PR is intended to run the transferred tests through the standard base and extra hardware suites.

## Speed Tests and Profiling

Dependency Installation time: **4min -> 30sec**
```
