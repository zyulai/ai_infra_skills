## Summary

- Add a decode-only `update_token_table_decode` kernel for ngram embedding token-table updates.
- Route `ModelRunner.maybe_update_ngram_token_table` to the decode fast path.
- Keep the existing general `update_token_table` path for prefill / variable request lengths.
- Add correctness coverage and a benchmark for general vs decode update.
