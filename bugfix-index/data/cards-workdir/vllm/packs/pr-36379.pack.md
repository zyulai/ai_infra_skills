## Purpose

Fix the bug where usage information is incorrectly returned when `stream_options` is passed as an empty object in streaming requests.

### Problem Description

According to the OpenAI API specification and #7179, usage information should only be returned in streaming mode when `stream_options={"include_usage": True}` is explicitly set. However, vLLM incorrectly returns usage in the following scenarios:

| Request | Expected | Actual (Before Fix) |
|---------|----------|---------------------|
| No `stream_options` | No usage | ✅ No usage |
| `stream_options={}` (empty) | No usage | ❌ Returns usage |
