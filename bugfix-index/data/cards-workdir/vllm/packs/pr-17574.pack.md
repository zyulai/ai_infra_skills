## 正文(PR 描述)

The FA3 update to use a AOT scheduler (https://github.com/vllm-project/vllm/pull/13111) did not properly handle sliding window attention. FIX https://github.com/vllm-project/vllm/issues/17476

Tested using:
```
python -m pytest -vs tests/v1/e2e/test_correctness_sliding_window.py
```
