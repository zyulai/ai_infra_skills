```markdown
## What                                                                                                                                                                                     
                                                                
  Adds `slots=True` to the `KVCacheBlock` dataclass. One-line change.                                                                                                                         
                                                                                   
  ## Why                                                                                                                                                                                      
                                                                                   
  This is the most-allocated object in the KV cache path — one per
  block, 100K+ in a typical deployment. Each instance currently
  carries a `__dict__` hash table it doesn't need. Slots eliminate
  that, dropping instance size from 344 to 80 bytes and cutting
  allocation time by ~35%.

  No code dynamically sets attributes on these objects, nothing
  subclasses them, and they're never pickled — so this is a safe,
  free win.

  ## Numbers

  Measured with a standalone benchmark allocating 100K blocks:

  - **77% smaller** per instance (344 → 80 bytes)
  - **~25 MB saved** at 100K blocks
  - **1.54x faster** allocation

  ## Test

  Added a test that asserts `KVCacheBlock` has no `__dict__` and
  rejects dynamic attribute assignment. Existing tests cover all
  field access and linked list operations.

```
