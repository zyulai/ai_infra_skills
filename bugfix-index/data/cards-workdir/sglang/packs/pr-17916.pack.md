## Motivation
This pull request introduces a targeted fix to the `for_module_type` function in `component_loader.py`. The main change ensures that when the `module_type` is `"scheduler"` and the backend is `"mova.diffusion.schedulers.flow_match_pair"`, the backend is correctly mapped to `"diffusers"` for consistent module loading.

## Modifications

Loader backend mapping fix:

* Ensures that if `module_type` is `"scheduler"` and `transformers_or_diffusers` is `"mova.diffusion.schedulers.flow_match_pair"`, it is remapped to `"diffusers"` to maintain compatibility with the rest of the loader logic.
