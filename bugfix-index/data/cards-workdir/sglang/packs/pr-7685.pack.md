## Motivation

Fixes crash noted on https://github.com/sgl-project/sglang/issues/7585 race condition causing crashes when some penalties are applied, due to logit bias not being set in correct place. It can be replicated by having high batchsize of requests that have frequency/repetition penalty. 

The PR is tested and resolves the bug given same conditions as above. 

## Modifications

We need to set logit bias before temperature etc gets updated (as per the note in the code). 

Additionally, checks within EAGLE verification to make sure batchsize is up to date.
