## 正文(PR 描述)

## Summary
- add staged HiCache write-back support to MHA host pools with asymmetric K/V head dimensions
- allocate distinct K/V staging buffers and dispatch the single-buffer staged kernel once per buffer, preserving each native stride
- retain CPU host indices for the shared target and DFLASH draft write-back path
- add an exact asymmetric K/V staged-write-back round-trip accuracy test

## Motivation
`AsymmetricMHATokenToKVPoolHost` has separate K and V buffers with different strides. During the staged write-back refactor it continued using the non-staged split K/V fallback, even though the controller correctly retains host indices on CPU for staged write-back. This adds the missing per-buffer staged path instead of disabling the optimization.
