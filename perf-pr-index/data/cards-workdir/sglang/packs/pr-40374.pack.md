## Motivation

SenseNova-U1.5 eagerly applies three-axis RoPE using separate multiply, negate, concatenate and add kernels. Reusing the existing lossless bf16 rotate-half kernel reduces native 2048×2048/50-step **worker request E2E by 5.17% on one H200**, with byte-identical PNGs. Client E2E, including PNG save, improves 5.13% in the repeated isolated comparison.

## Modifications

- Route eligible bf16 CUDA Q/K tensors through the existing `fused_rope_rotate_half_bitexact`; preserve the original bf16 rounding after each product. Materialize the spatial head slices in BSHD layout, then return BHSD views to the existing attention path.
- Keep eager fallback for short prefixes, unsupported shapes/dtypes/table broadcasting, gradients and compilation. No normalization reduction, RoPE table computation, weights or attention backend changes.
- Forward the standard profiling/perf fields through SenseNova's sampling whitelist. Previously `--profile` was silently dropped, and stage timings were absent. Both benchmark arms contain this instrumentation-only fix.

This follows the shared-kernel reuse/rounding approach in #34004 and #38530. It is independent of the open RoPE-table reuse (#38927), RMSNorm dispatch (#39705), and host-sync (#38905) changes.
