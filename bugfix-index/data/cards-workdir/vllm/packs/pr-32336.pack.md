## 正文(PR 描述)

## Purpose
This PR resolves a significant performance regression for models using non-standard block sizes (specifically block size 544, such as Qwen3-Next-80B-A3B-Thinking) under the ROCM_ATTN backend.

Background: Recently, PR #31712 restricted the supported kernel block sizes for ROCM_ATTN to only 16 and 32. While this was intended to prevent unsupported configurations, it inadvertently throttled models that rely on larger, non-standard block sizes (previously optimized in PR #31380). This led to a massive degradation in TTFT and overall throughput for these models.

This PR ensures that ROCM_ATTN correctly recognizes and supports these specialized block sizes again, restoring the optimized performance path for Qwen3-Next and similar architectures.


## Test Plan
We conducted comprehensive benchmarks on AMD GPUs with tensor_parallel_size=2 to verify the fix and ensure no regressions for standard models.

Performance Recovery Test: Benchmarked Qwen3-Next-80B-A3B-Thinking (Block Size 544).

Regression Test: Benchmarked standard models using default block sizes (16/32):

Qwen/Qwen3-235B-A22B-Instruct-2507-FP8

RedHatAI/Llama-4-Scout-17B-16E-Instruct-FP8-dynamic

Qwen/Qwen2.5-7B-Instruct

Accuracy Verification: Ran LM_EVAL (GSM8K) to ensure model weights and attention logic remain correct.
