## 正文(PR 描述)

## Motivation

This PR fixes #22311 

Qwen3.5-27B takes a fallback BA path (after commit 5bdc07d974f6cf236fa765a685453ea5e587a838) that returns non-contiguous split views for a and b. The existing GDN Triton kernels assumed contiguous layouts and hardcoded the batch or token stride, which caused incorrect memory reads and the observed accuracy regression.

Regression test (https://github.com/cs-cat/sglang_is_blind) showed a severe drop in accuracy (from 49/50 to 3/50).

## Modifications

- Made `fused_gdn_gating` stride-aware by passing explicit stride_a and stride_b and using them when loading a and b.
- Made `fused_sigmoid_gating_delta_rule_update` stride-aware for a by passing the token-axis stride and using it during recurrent updates.
- Added CUDA GDN regression tests that compare contiguous tensors against non-contiguous split views, including Qwen3.5-like shapes and the KDA path.

## Accuracy Tests

After applying this fix, the regression test pass rate for https://github.com/cs-cat/sglang_is_blind improved **from 3/50 to 49/50** . This is consistent with the pass rate of directly reverting 5bdc07d974f6cf236fa765a685453ea5e587a838.

+def _make_noncontiguous_ab(batch, num_heads, dtype=torch.bfloat16, device="cuda"):
+    """
+    Simulate Qwen3.5 fallback: mixed_ba.split([nv_tp, nv_tp], dim=-1).
+    Returns (b, a) as split views with stride(0) = 2 * num_heads.
+    Also returns contiguous copies for reference comparison.
+    """
+    mixed_ba = torch.randn(batch, 2 * num_heads, dtype=dtype, device=device)
+    b, a = mixed_ba.split([num_heads, num_heads], dim=-1)
+
+    # For batch=1, PyTorch may still report contiguous even when split keeps
+    # a widened leading stride. Validate stride semantics unconditionally.
+    if batch > 1:
+        assert not a.is_contiguous(), "a should be non-contiguous from split"
+        assert not b.is_contiguous(), "b should be non-contiguous from split"
+    assert a.stride(0) == 2 * num_heads
+    assert b.stride(0) == 2 * num_heads
+    return b, a, b.contiguous(), a.contiguous()
+
