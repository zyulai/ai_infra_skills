## Motivation and implementation

SANA-Video's interleaved RoPE spends 2.835 seconds in 2,000 kernel calls per native 50-step request on B300. The existing operation uses separately rounded FP64 products and sums, then converts through FP32 to BF16. This patch lowers saved-video eager E2E by **8.11–8.19%** while preserving that output contract.

On SM103, directed FP32 interval operations enclose the original FP64 expression. Equal finite BF16 endpoint bits certify the original result. Ambiguous boundaries and nonfinite values use the existing FP64 arithmetic; signed-zero pairs retain their sign rules. The SM103 guard leaves other architectures on the original code. Indexing, layout, launch and public API are unchanged.
