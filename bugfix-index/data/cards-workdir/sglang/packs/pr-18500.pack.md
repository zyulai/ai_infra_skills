## 正文(PR 描述)

## Motivation

When using `flashinfer_trtllm` MoE backend with FP4 quantization (`modelopt_fp4`), the FlashInfer autotuner crashes with:

```
File ".../model_runner.py", line 1730, in _flashinfer_autotune
    self._dummy_run(batch_size=self.req_to_token_pool.size)
File ".../model_runner.py", line 1974, in _dummy_run
    run_once()
  ...
File ".../deepseek_v2.py", line 720, in forward_normal
    final_hidden_states = self.experts(...)
  ...
File ".../fused_moe_triton/layer.py", line 1273, in forward_impl
    result = trtllm_fp4_block_scale_moe(...)
File ".../flashinfer/fused_moe/core.py", line 1085, in forward
    assert hidden_states_scale is None or (
AssertionError: hidden_states_scale's first dimension must be batch size
```

This occurs during the `do_preparation` phase of FlashInfer's autotuning process. The root cause is that `hidden_states_scale` is incorrectly flattened to a 1D tensor before being passed to `trtllm_fp4_block_scale_moe`, violating FlashInfer's API which requires a 2D tensor of shape `[seq_len, hidden_size // 16]`.

This PR fix: https://github.com/sgl-project/sglang/issues/18499

## Modifications

Remove the unnecessary `.flatten()` call on `hidden_states_scale` in `FlashInferFP4MoE.forward_impl`.

The tensor `hs_scale_linear` returned by `_quantize_hidden_states_fp4` is already in the correct 2D shape `[seq_len, hidden_size // 16]` with dtype `float8_e4m3fn`. The `.view(torch.float8_e4m3fn)` is a no-op, and the `.flatten()` was incorrectly converting it to 1D, which:

1. Violates [FlashInfer's API](https://github.com/flashinfer-ai/flashinfer/blob/main/flashinfer/fused_moe/core.py#L2494): `hidden_states_scale` shape should be `[seq_len, hidden_size // 16]`
2. Violates the [explicit assertion in FlashInfer](https://github.com/flashinfer-ai/flashinfer/blob/main/flashinfer/fused_moe/core.py#L1085-L1088): `hidden_states_scale.dim() == 2`
3. Contradicts [SGLang's own comment](https://github.com/sgl-project/sglang/blob/main/python/sglang/srt/layers/moe/fused_moe_triton/layer.py#L1253-L1256) in `_quantize_hidden_states_fp4`: `# TRT-LLM expects hidden state scales shaped as [seq_len, hidden_size // 16]`

**Before:**
```python
hidden_states_scale=hs_scale_linear.view(torch.float8_e4m3fn).flatten(),
```

**After:**
```python
hidden_states_scale=hs_scale_linear.view(torch.float8_e4m3fn),
```
