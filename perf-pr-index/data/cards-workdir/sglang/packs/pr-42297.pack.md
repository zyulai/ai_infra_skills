## Motivation

Add the block verifier from [Block Verification Accelerates Speculative Decoding](https://arxiv.org/abs/2403.10444), Algorithm 2. Standard rejection sampling stops at the first rejected draft token. Block verification selects the longest accepted prefix and can accept a longer prefix after an earlier rejection, with a scaled correction distribution that preserves target sampling.

## Modifications

- Add opt-in `--speculative-use-block-verification`; this flag automatically enables the required proposal sampling and draft-probability storage. `--speculative-use-rejection-sampling` alone selects token-wise rejection sampling, and passing both flags remains supported. Support the existing linear EAGLE/EAGLE3/NEXTN proposal path (`--speculative-eagle-topk 1`) on CUDA/ROCm, with startup validation for unsupported configurations.
- Extend the existing Triton chain sampler with a compile-time branch. Compute `r_i = min(1, r_(i-1) * p(x_i) / q(x_i))` forward, then test prefixes longest-first and stop at the first acceptance. The original per-prefix random samples are retained, so skipped shorter-prefix tests cannot change the selected prefix. Commit that prefix once and sample correction from normalized `(r_tau * p - q)+`; full acceptance samples the bonus token from the target.
- Skip a prefix's vocabulary reduction when its coin is already at least `r_i`, using `h_i <= r_i` for normalized distributions. Reuse the selected prefix's residual mass for correction normalization. Use a separate reduction tile capped at 32768 with 8 warps for large vocabularies; keep the final CDF tile at 4096. Token verification retains its original acceptance loop and 4-warps launch.
- Add a reproducible sampler benchmark with optional comparison against a saved baseline kernel.
- Reuse proposal buffers, output indices, TP synchronization, and the greedy verification path. No scheduler or KV-cache changes; the existing verification defaults remain unchanged.
- Document the option and add focused kernel and configuration tests.

+def _reference(target, draft, candidates, coins, final_coins, *, block):
+    target, draft = target.double(), draft.double()
+    batch, slots, _ = target.shape
+    lengths = torch.zeros(batch, dtype=torch.long)
+    prefix_prob = torch.ones(batch)
+    residual_scale = torch.ones(batch)
+    active = torch.ones(batch, dtype=torch.bool)
+    rows = torch.arange(batch)
+    for step in range(1, slots):
+        token = candidates[:, step]
+        ratio = target[rows, step - 1, token] / draft[rows, step - 1, token]
+        if block:
+            prefix_prob = (prefix_prob * ratio).clamp(max=1)
+            if step == slots - 1:
+                probability = prefix_prob
+            else:
+                mass = (
+                    (prefix_prob[:, None] * target[:, step] - draft[:, step])
+                    .clamp(min=0)
+                    .sum(-1)
+                )
+                probability = torch.where(
+                    prefix_prob == 1, 1, mass / (mass + 1 - prefix_prob)
+                )
+            accept = coins[:, step - 1] < probability
+            residual_scale = torch.where(accept, prefix_prob, residual_scale)
+        else:
+            active &= coins[:, step - 1] < ratio
+            accept = active
+        lengths = torch.where(accept, step, lengths)
+    weights = target[rows, lengths].clone()
+    rejected = lengths < slots - 1
+    weights[rejected] = (
+        residual_scale[rejected, None] * weights[rejected]
+        - draft[rows[rejected], lengths[rejected]]
+    ).clamp(min=0)
+    cdf = weights.cumsum(-1) / weights.sum(-1, keepdim=True)
+    final = (cdf <= final_coins[:, None]).sum(-1)
+    output = torch.full((batch, slots), -1, dtype=torch.int32)
+    for row in range(batch):
+        length = lengths[row]
+        output[row, :length] = candidates[row, 1 : length + 1]
+        output[row, length] = final[row]
+    return lengths, output, cdf
