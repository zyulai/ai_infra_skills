## 正文(PR 描述)

Fixes Mamba-based models (Jamba, Mamba, FalconMamba, PLaMo2, etc.) producing garbage/incorrect output when multiple sequences are decoded together in a batch on ROCm. Single-sequence inference works correctly.

## Problem

When running Mamba-based models on ROCm with batch size > 1, sequences produce inconsistent and incorrect outputs:

**Single prompt (correct):**
```
Prompt: 'The capital of France is', Generated text: ' Paris, a city of 12 million...'
```

**Batch of 3 identical prompts (incorrect):**
```
Prompt: 'The capital of France is', Generated text: ' Paris, a city of culture, history...'
Prompt: 'The capital of France is', Generated text: ' Paris, or circ, for you conveni...'
Prompt: 'The capital of France is', Generated text: ' Paris, a city of more than 2 million...'
```

## Root Cause

`causal_conv1d_update` returns a non-contiguous tensor view. When this tensor is passed through transpose operations and then to linear layers (`x_proj` in MambaMixer, `bcdt_proj` in PLaMo2), ROCm's GEMM kernels produce incorrect results for batch positions other than the last one.

**Debug evidence showing identical inputs producing different outputs:**
```
# Inputs to linear layer (identical for positions 1 and 2):
hidden_states_d[1,:5]: [-0.048828125, -0.1259765625, ...]
hidden_states_d[2,:5]: [-0.048828125, -0.1259765625, ...]

# Outputs from linear layer (should be identical, but aren't):
B_d[1,:5]: [-1.3125, 8.9375, ...]   # WRONG
B_d[2,:5]: [-0.828125, 4.0, ...]    # Correct

# Tensor is non-contiguous:
hidden_states_d.is_contiguous(): False
hidden_states_d.stride(): (8192, 1)  # Expected: (4096, 1)
```

## Solution

Ensure tensors are contiguous before passing to linear layers on ROCm:

1. **`mamba_mixer.py`**: Add ROCm check to existing LoRA contiguity handling in `_ssm_transform()`
2. **`plamo2.py`**: Add `.contiguous()` call after `causal_conv1d_update` in decode path

The fix is guarded by `current_platform.is_rocm()` to avoid unnecessary copies on CUDA/other platforms.

## Affected Models

All Mamba-based models using `MambaMixer`:
- Jamba (`ai21labs/Jamba-tiny-dev`, etc.)
- Mamba (`state-spaces/mamba-*`)
- FalconMamba
- PLaMo2
