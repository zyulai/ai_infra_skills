## PR body
```markdown
`triton_kernels` 3.8 reorganized its mxfp4 MoE API (`matmul_ogs`→`matmul`, `RoutingData`→`RaggedTensorMetadata`, `weight_scale`→`b_mx_scale`, and dropped the in-kernel scatter+topk-reduce). This PR:
- adds the 3.8 triton_kernels MoE forward for gpt-oss and DeepSeek-V4, gated behind a shared `get_triton_kernels_version` dispatcher
- forward-fixes the other affected `AITER_MXFP4_W4A{8/16}` backends preparation for https://github.com/vllm-project/vllm/pull/50605
- bumps the triton_kernels commit to ROCm `releases/internal/3.8.x` in `Dockerfile.rock`, since this image i.e. `vllm/vllm-openai-rocm:nightly-rocm100` has triton 3.8 already


## Benchmarks
```
