## Motivation

<!-- Describe the purpose and goals of this pull request. -->

0610's Nightly CI found GLM-5 accuracy dropped to ~0.
Issue: https://github.com/bingxche/sglang-ci-bot/issues/99

sglang [PR#27289](https://github.com/sgl-project/sglang/pull/27289) fused the V4 scale-transpose element-wise kernel into the preceding quant
kernel, but missed the `o_proj` scale param in `forward_mla.py`, causing GLM-5.1 accuracy issue.

aiter [PR#3041](https://github.com/ROCm/aiter/pull/3041) (merged) adds `transpose_scale` support to `fused_flatten_fp8_group_quant`, but it needs an aiter version bump in sglang (also updated in readiness).


## Modifications

<!-- Detail the changes made in this pull request. -->

Add `transpose_scale=_use_aiter_bpreshuffle_gfx95`.
