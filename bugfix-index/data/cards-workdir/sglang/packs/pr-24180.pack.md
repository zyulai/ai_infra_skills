## 正文(PR 描述)

Re-lands #23109 (which was reverted in #24179) with a fix for the bug that caused the original revert.

## Why #23109 was reverted

The `check-maintenance` action's `MIN_BASE_SHA` parser piped through `grep`, which exits 1 when no line matches. With `shell: bash` composite steps defaulting to `bash --noprofile --norc -eo pipefail {0}`, the 1 propagates via pipefail and aborts the whole script before any further check runs. Result: when the issue body had no `MIN_BASE_SHA` directive (the normal case), every job's `check-maintenance` step exited 1 in 0 seconds, falsely blocking all PR CI.

Reproduces locally:

```bash
bash --noprofile --norc -eo pipefail -c '
  A=$(echo "" | grep "x" | head -n1)
  echo after
'
# -> exits 1, never prints "after"
```

## Fix

Wrap `grep` in a brace group with `|| true` so an empty match falls through to `head`/`sed`/`awk` cleanly. Verified locally with both empty-body and directive-present inputs.

```diff
-        MIN_BASE_SHA=$(printf '%s' "$ISSUE_BODY" | tr -d '\r' | grep -iE '...' | head -n1 | sed -E '...' | awk '{print $1}')
+        MIN_BASE_SHA=$(
+          { printf '%s' "$ISSUE_BODY" | tr -d '\r' | grep -iE '...' || true; } \
+            | head -n1 | sed -E '...' | awk '{print $1}'
+        )
```

## Original feature (from #23109)

Adds a rebase-required mode to `check-maintenance`. Issue #21065's body can include a `MIN_BASE_SHA: <sha>` directive — when present, CI runs only for PRs whose branch already contains `<sha>` (verified via GitHub compare API, status `ahead`/`identical` passes, `behind`/`diverged` blocks). The directive is enforced regardless of whether the issue is open or closed; the existing full-pause maintenance gate (issue OPEN, no SHA) still works as before. The `bypass-maintenance` label still bypasses both gates. API errors fail-open.

## Behavior matrix

| Issue #21065 | `MIN_BASE_SHA` in body | PR contains SHA | Result |
|---|---|---|---|
| Closed | absent | — | CI runs (the case that was broken before this fix) |
| Closed | present | yes | CI runs |
| Closed | present | no | Blocked: Rebase Required |
| Open | absent | — | Full pause |
| Open | present | yes | Full pause (rebase OK, but issue still pauses) |
| Open | present | no | Blocked: Rebase Required |
