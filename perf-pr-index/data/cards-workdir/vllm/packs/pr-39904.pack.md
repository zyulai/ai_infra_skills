```markdown
**Purpose**
Optimize gpt-oss 120b Fused MoE kernels Optimization configs

**Test Result**
After introducing the MoE config file (instead of using the default config), the fused_moe kernel benchmark shows a     
  consistent but modest speedup.                                                                                            
  • Metric: Kernel time in us, evaluated across 18 matched batch-size points.                                               
  • Overall improvement:                                                                                                    
    • Geometric-mean speedup: ~1.035x                                                                                       
    • Equivalent to ~3.35% average kernel-time reduction                                                                    
  • Largest observed gains:                                                                                                 
    • bs=8: -8.09% / 1.088x                                                                                                 
    • bs=96: -7.47% / 1.081x                                                                                                
    • bs=128: -6.68% / 1.072x                                                                                               
  • Smallest observed gains:                                                                                                
    • bs=2: -0.12% / 1.001x                                                                                                 
    • bs=2048: -0.54% / 1.005x                                                                                              
    • bs=3072: -0.83% / 1.008x                                                                                              
  • Takeaway: the config-driven setup delivers stable performance wins (~3–4% overall), with more noticeable benefits at    
  some mid-range batch sizes (e.g., 8/96/128).  
```
