## Motivation
Current release v0.4.8 in order to comply with the OpenAI protocol, class OpenAIServingChat adds an additional chunk at the end of the streaming output to describe the reason for the end of the streaming output. 
<img width="1093" alt="Clipboard_Screenshot_1751429477" src="https://github.com/user-attachments/assets/28995cb8-fff7-4c78-9b05-3e492ac58d9b" />

When the streaming output ends with tool_calls, the finish_reason in the reply chunk should be tool_calls. The current code did not perform a tool call check, which resulted in the final chunk always having a 'stop' instead of the expected 'tool_calls' value for the' finish.rason '. This can lead to unpredictable behavior in some open source software (eg. strand agent).
<img width="1813" alt="Clipboard_Screenshot_1751433449" src="https://github.com/user-attachments/assets/483672bc-5bf6-4950-9792-21713602612f" />


<!-- Explain the purpose of this PR and the goals it aims to achieve. -->

## Modifications
Corrected the logic for obtaining finish_reason, returning and setting finish_reason to tool_calls in the final chunk after determining it as a tool call.
