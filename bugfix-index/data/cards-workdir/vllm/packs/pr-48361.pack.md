## 正文(PR 描述)

## Purpose

Adds a regression test for the hybrid-Mamba eagle cache-peek overrun in the Mooncake store connector's `find_longest_cache_hit` (#43559).

## Scope changed since this PR was opened

This PR originally proposed the `not isinstance(spec, MambaSpec)` gate itself. **#49502 has since landed that gate independently** (and extended it with a fine-grained hash margin), so the fix is already on `main`. Rebasing onto current `main` therefore reduces this PR to:

- **the regression test** (`test_lookup_with_eagle_hybrid_full_plus_mamba_no_overrun`) that pins the behavior so it cannot silently regress, and
- **a short comment** recording *why* a recurrent group gets no peek margin, which the merged gate does not explain.

`MambaManager` ignores `drop_eagle_block` (a Mamba block at position p *is* the recurrent state after `(p + 1) * block_size` tokens — there is nothing to recompute), so granting the Mamba group the one-block eagle peek margin lets it match one block **past** the eagle-pruned full-attention hit and resume the recurrent state ahead of the verified token prefix. That is silent output corruption, not a crash — which is exactly why it warrants a test rather than relying on the gate staying in place.

## Not duplicating an existing PR

The production gate is already merged (#49502); this adds only test coverage for it. No open PR adds a Mooncake-connector regression test for the hybrid-Mamba eagle overrun.
