## Motivation

- Found precision issues when testing internvl3 8b, but no issues on 1b and 38b.

- The reason for the modification at that time was that we considered using a fixed mean and variance for normalization, which might be quite different from the mean and variance of the actual input image, which would result in excessive loss of normalization accuracy. but using the mean and variance of the actual image for normalization will result in a smaller normalized result when the variance is small, which may cause precision problems caused by excessive truncation in bf16 mode. Consider normalizing using the mean and variance of the imagenet dataset.

## Modifications

normalizing using the mean and variance of the imagenet dataset.
