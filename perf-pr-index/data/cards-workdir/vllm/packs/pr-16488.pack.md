## PR body
```markdown
Generated with [benchmark_moe.py](https://github.com/vllm-project/vllm/blob/main/benchmarks/kernels/benchmark_moe.py) script for the most part, except for bsz=16 where it needed to be tuned further.

Benchmark commands:

```
VLLM_USE_V1=1 vllm serve meta-llama/Llama-4-Scout-17B-16E-Instruct  --disable-log-requests -tp 8 --max-num-seqs 64 --no-enable-prefix-caching --max_num_batched_tokens=81920 --max-model-len=262144
```

```
python benchmarks/benchmark_serving.py \
        --model meta-llama/Llama-4-Scout-17B-16E-Instruct \
        --host 0.0.0.0 \
        --dataset-name random \
        --ignore-eos \
        --num-prompts 500 \
        --random-input-len 5000 \
        --random-output-len 1000 \
        --max-concurrency $MAX_CONCURRENCY
```

Results tested on 5k input len and 1k output len:
```
