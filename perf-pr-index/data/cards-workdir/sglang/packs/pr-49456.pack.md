## Motivation

Ming's unquantized DiT already uses ordered RMSNorm, but still launches BF16 scale and residual operations after it. This fuses those epilogues into the existing ordered kernel, removing 2,304 pointwise launches per 12-step request while preserving the original intermediate rounding.

## Modifications

- Extend the shared ordered kernel with optional scale/residual operands. Preserve FP32 statistics, the cast before learned-weight multiplication, the cast before scaling, and the cast before residual addition. `tanh` remains native.
- Add Ming-specific block hooks while keeping Z-Image's default helpers. Eligible CUDA BF16 width-3840 inputs use the existing per-signature bit-exact gate; unsupported layouts, small reductions, quantized blocks and compilation retain their existing expressions.
- Reuse the existing kernel during cleanup, add changed-input CUDA graph and actual Dynamo tracing regression coverage, and document the bounded B300 validation scope. No new user flags.

## Accuracy Tests

Frozen main: `5325cfabd757819e2e01bb7eb3b28c5b39b8cec9`
