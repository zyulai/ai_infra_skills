## 正文(PR 描述)

## Summary

This extracts the minimal accuracy fix from BBuf/sglang#4. Native Mistral configs can map `apply_scale=false` to `apply_yarn_scaling=False`; in that case MLA attention scaling should keep the base scale instead of applying YARN mscale again.

The previous behavior over-scaled MLA attention for Mistral/Pixtral-style MLA configs and caused the B200 NVFP4 accuracy drop described in the source PR.

## Changes

- Return `base_scaling` from `compute_mla_mscale_scaling` when `apply_yarn_scaling` is disabled.
- Add a focused regression test for disabled YARN scaling and the default enabled path.
