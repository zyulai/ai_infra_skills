## 正文(PR 描述)

## Summary

`ModelForPooling.load_weights` uses `(*seen_weights, *weights)` which eagerly
consumes the entire iterator at generator creation time. With runai_streamer
(`RUNAI_STREAMER_MEMORY_LIMIT=0`), the shared I/O buffer is overwritten before
tensors are consumed, silently corrupting all pooling/embedding model weights.

Fix: `itertools.chain` for lazy iteration, `.clone()` on probed weights so
packed-weight remapping (q/k/v_proj -> qkv_proj) survives reuse.

+def _buffer_reusing_iterator(weight_dict):
+    """Yield weights through a shared buffer overwritten each step.
+
+    Mimics ``runai_model_streamer`` with ``RUNAI_STREAMER_MEMORY_LIMIT=0``.
+    """
+    buf = None
+    for name, tensor in weight_dict.items():
+        if buf is None or buf.numel() < tensor.numel():
+            buf = torch.empty(tensor.numel(), dtype=tensor.dtype)
+        view = buf[: tensor.numel()].view(tensor.shape)
+        view.copy_(tensor)
+        yield name, view
+
