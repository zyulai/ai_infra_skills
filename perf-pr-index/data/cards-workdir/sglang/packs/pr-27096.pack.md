## Summary
4x speedup for the QK-norm + RoPE segment


## Motivation

previously, Cosmos3 applies Q/K RMSNorm and Qwen3-style mRoPE as separate operations in both the UND causal-attention path and GEN cross-attention path

In my pr i reuse the existing fused QK-norm + RoPE kernel for Cosmos3's Qwen3 half-split RoPE convention
