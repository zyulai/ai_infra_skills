## Purpose
Adds a fast path when all prefills in a batch have `seq_len <= topk`, routing to dense MHA instead of sparse MQA (subject to a `q_len` threshold) to obtain a substantial speedup.

This is also a precursor to a masked MHA implementation (see https://github.com/vllm-project/vllm/pull/34744), which will enable speedups at `seq_len > topk`.

## Test Plan
