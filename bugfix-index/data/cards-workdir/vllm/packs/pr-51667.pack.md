## 正文(PR 描述)

## Purpose

I had a look at the recently merged DiskBackend for KV offloading (#49644), thanks @chengy-sysu. I noticed a subtle bug in `_do_load`'s double-buffer pipeline: pending H2D events were tracked in a list local to each call and, unlike `_do_store`, never drained before returning. A later `_do_load` call's preadv could therefore overwrite a buffer slot while the previous call's trailing H2D copy was still reading it, silently corrupting the GPU KV cache on reload.

This PR drains the trailing events before `_do_load` returns, mirroring `_do_store`'s existing pattern, and adds a regression test that fails without the fix and passes with it.

Tagging @ivanium & @aoshen02  who reviewed https://github.com/vllm-project/vllm/pull/49644.

AI-assisted, every line reviewed and tested by the submitter.

## Test Result

All 3 tests pass with the fix. `test_do_load_drains_inflight_before_next_batch` fails on main (preadv overwrote slot(s) [0, 1] while a prior batch's H2D was still reading them) and passes with this patch.
