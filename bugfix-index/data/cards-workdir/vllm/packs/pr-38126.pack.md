## 正文(PR 描述)

## [Bugfix] Add SM121 (12.1) arch guards for desktop Blackwell, fixes missing NVFP4/scaled_mm/MLA kernels on DGX Spark

### Summary

PR #37725 correctly preserved the CUDA arch suffix (`a`/`f`) during gencode extraction, but the downstream arch guard checks in `CMakeLists.txt` only recognize `12.0a`/`12.0f` — they don't match `12.1`/`12.1a`/`12.1f` (SM121/DGX Spark). This causes all SM12x-family kernels to be silently skipped when building with `TORCH_CUDA_ARCH_LIST=12.1a`.

Additionally, `cuda_archs_loose_intersection` in `cmake/utils.cmake` doesn't handle:
- **TGT suffix with unsuffixed SRC**: e.g. TGT=`12.1a` + SRC=`12.1` (from `CUDA_SUPPORTED_ARCHS`) → should output `12.1a`, was outputting `12.1` (suffix stripped)
- **Cross-suffix matching**: e.g. SRC=`12.1f` + TGT=`12.1a` → should output `12.1a`, was outputting nothing

### Root cause

Build log from SM121 showing all SM12x kernels skipped:
```
CUDA target architectures: 12.1a
CUDA supported target architectures: 12.1
...
Not building scaled_mm_c3x_120 as no compatible archs found
Not building NVFP4 as no compatible archs were found.
Not building NVFP4 as no compatible archs were found.
Not building CUTLASS MLA as no compatible archs were found.
```

The guards use `cuda_archs_loose_intersection` with SRC lists like `"12.0f"` or `"12.0a"`. The suffix handling does an exact base-version match (`12.0`), which fails when the target is `12.1`.

### Fix

**`cmake/utils.cmake`** Two additions to `cuda_archs_loose_intersection`:
- Cross-suffix matching: when SRC has `x.yf` and TGT has `x.ya` (same base version, different suffix), match and use TGT's suffix for correct compilation flags
- TGT suffix preservation: when TGT has `x.ya` and SRC has `x.y` (no suffix), preserve TGT's suffix in output

**`CMakeLists.txt`** Added `12.1` variants to all SM12x-family arch guards:

| Guard | CUDA >= 13.0 | CUDA < 13.0 |
|-------|-------------|-------------|
| Marlin FP8 | `"8.9;12.0;12.1"` | (same, no suffix) |
| scaled_mm SM12x | `"12.0f;12.1f"` | `"12.0a;12.1a"` |
| NVFP4 SM12x | `"12.0f;12.1f"` | `"12.0a;12.1a"` |
| CUTLASS MLA | `"...;12.0f;12.1f"` | already had `12.1a` ✓ |
| moe_data | `"...;12.0f;12.1f"` | already had `12.1a` ✓ |
| MOE Marlin FP8 | `"8.9;12.0;12.1"` | (same, no suffix) |

**`cmake/external_projects/qutlass.cmake`** Added `12.1a` to arch lists and updated TARGET_CC regex to match SM121.
