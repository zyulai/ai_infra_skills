## PR body

## Purpose

Enable fused multi-step draft decode for GLM-5.3

Consider K = 5

Before:

```text
    draft prefill: generate token #0
    decode step 1: rebuild metadata
    decode step 2: rebuild metadata
    decode step 3: rebuild metadata
    decode step 4: rebuild metadata
```

After:

```text
    draft prefill: generate token #0
    decode step 1: build metadata once
    decode step 2: update metadata in place
    decode step 3: update metadata in place
    decode step 4: update metadata in place
```
