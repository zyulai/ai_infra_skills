## 正文(PR 描述)

## Purpose

The optional `flashinfer.comm` import in `allreduce_rms_fusion.py` is guarded by
`except ImportError`, so any other exception during import aborts `EngineCore` startup.
Hit with `flashinfer-python==0.6.16.post3` on Python 3.11, which raises `TypeError` at
import time — killing startup on a `tp_size=1` run with `fuse_allreduce_rms: False`.

Widen the guard to `except Exception` and log a warning, so a broken flashinfer disables
the fusion pass instead of failing startup.
