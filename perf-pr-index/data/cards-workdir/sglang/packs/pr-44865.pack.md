## PR body
```markdown
## Motivation

Users on 24 to 32 GB GPUs often already have the BF16 ComfyUI file for Qwen-Image-2.1 but cannot use online quantization with it. Today they have to find and download a separate pre-quantized file.

Two things blocked this:

1. The plugin preflight rejected `quantization` for any ComfyUI single file.
2. The worker's single-file loader (`comfyui_checkpoints/spec.py`) only built a quant config from per-layer markers in the file. A BF16 file has none, so `--quantization` was silently ignored and the DiT stayed in BF16.

## Modifications

- `runtime/loader/comfyui_checkpoints/spec.py`: when a single file has no quant markers and `quantization` is set, resolve it through the existing `resolve_transformer_quant_load_spec` (same path native directories use), build the matching `WeightLoadPlan`, and run the quant post-load hooks. Methods that need serialized weights (e.g. `mxfp8`) raise a clear error instead of being ignored.
- Plugin `core/preflight.py`: allow `convrot_int8` on BF16 Qwen-Image-2.1 single files. Other models and other methods stay rejected with a clear message.
- Options tooltip and README updated.
- Tests: worker regression test (quant config, param dtype, load device and hooks reach the loader) and preflight accept/reject cases.

Scope is Qwen-Image-2.1 + INT8 ConvRot only. FP8 was tested and left out (results below). Other single-file models can be added once validated.

## Accuracy and speed (Modal, L40S)

ComfyUI v0.41.0, headless API graph through `SGLDUNETLoader` + `SGLDOptions`. `Comfy-Org/Qwen-Image-2.1` turbo file, 1024x1024, 8 steps, euler/simple, cfg 1, seed 42. Time is the second (warm) run. Peak GPU is whole-process `nvidia-smi` (includes ComfyUI's text encoder and VAE). PSNR/SSIM are against SGLD BF16 on the same seed.

| Run | Sampling time | Peak GPU | PSNR / SSIM vs SGLD BF16 |
|---|---|---|---|
| Native ComfyUI BF16 | 3.43 s | 22.9 GB | 28.19 dB / 0.969 |
| SGLD BF16 | 3.29 s | 26.9 GB | reference |
| **SGLD online INT8 (this PR)** | **2.35 s** | 23.5 GB | **28.55 dB / 0.966** |
| SGLD online FP8 (not enabled) | 4.49 s | 23.5 GB | 21.74 dB / 0.855 |

Worker log for the INT8 run:

```
convrot_int8: quantized 224 linear layers (13.00 GiB of BF16 weights -> 6.50 GiB INT8; jit 0, comfy_kitchen 224), left 0 in BF16
```

INT8 is about 1.4x faster than BF16 and halves DiT weight memory, and its distance from BF16 is in line with native ComfyUI vs SGLD BF16. On L40S (CC 8.9) the JIT INT8 kernels are unavailable, so this ran on the comfy_kitchen backend.

### Why FP8 is not enabled

Online FP8 quantizes the same 224 layers but drifts from BF16 and is slower than BF16 on L40S. Keeping some layers in BF16 (`--quantization-ignored-layers`) did not fix it consistently (2 seeds each):

| FP8 variant | Time | SSIM (seed 42 / 1234) | PSNR dB (seed 42 / 1234) |
|---|---|---|---|
| BF16 reference | 3.17 s | | |
| FP8, all layers | 4.36 s | 0.855 / 0.854 | 21.7 / 20.8 |
| keep `img_mlp.out` in BF16 | 3.75 s | 0.814 / 0.866 | 20.6 / 21.7 |
| keep `attn.to_out` in BF16 | 4.18 s | 0.915 / 0.876 | 24.0 / 21.4 |
| keep both | 3.55 s | 0.879 / 0.884 | 22.6 / 21.8 |
| keep blocks 0 and 31 in BF16 | 4.23 s | 0.955 / 0.881 | 27.2 / 22.0 |

So the plugin rejects `fp8` for single files for now.

### Pre-quantized file note

Loading Comfy-Org's own `qwen_image_2.1_turbo_int8_convrot.safetensors` through `SGLDUNETLoader` fails on current main with `Parameter transformer_blocks.1.attn.comfy_attention.config not found in custom model state dict`. That is the serialized-marker path, which this PR does not touch; I can open a separate issue.

## Testing

- Unit tests on Modal (`test_comfyui_checkpoint_spec.py`, `test_comfyui_options.py`, `test_comfyui_generator.py`, `test_comfyui_qwen_image21.py`): 64 passed, 3 skipped.
- Same new tests against unmodified main: 5 failed (the 3 worker regression tests and 2 preflight cases), confirming they guard the change.
- End-to-end ComfyUI runs on L40S as above.

## Limitations

- Only Qwen-Image-2.1 single files are allowed in the plugin; Flux, Qwen-Image, Z-Image and MiniMax-H3 keep the existing rejection until validated.
- FSDP inference with online ConvRot INT8 on single files was not tested.
```
