## Motivation

Fix GLM4-7B-Flash accuracy test configuration, tune Qwen3.6-27B/35B performance test parameters, and harden Ascend NPU multi-node E2E test utilities against pod name format errors.

## Modifications

6 files changed, +56/-16

### 1. E2E multi-node test robustness (run_npu_e2e_test.py, test_npu_multi_node_utils.py)
- run_npu_e2e_test.py : Add label_selector="app=sgl-ascend" to pod listing API call to filter only target pods
- test_npu_multi_node_utils.py :
  - Hostname parsing: validate suffix is digit before int() conversion, raise RuntimeError on unexpected format (3 locations)
  - ConfigMap iteration: skip entries with non-numeric suffix instead of crashing
### 2. GLM4-7B-Flash accuracy fix (test_npu_glm4_7_flash_1p_aime25.py)
- Fix class name to match model: TestNPUDeepSeek_V3_2_8P_AIME2025 → TestNPUGLM_4_7_FLASH_1P_AIME25
- Restore env var HCCL_BUFFSIZE → DEEPEP_HCCL_BUFFSIZE
- Restore accuracy threshold
### 3. Qwen3.6-27B GPQA accuracy test (test_npu_qwen3_6_27b_1p_gpqa.py)
- Add --reasoning-parser qwen3 and --tool-call-parser qwen3_coder arguments
### 4. Qwen3.6-27B W8A8 performance tuning (test_npu_qwen3_6_27b_w8a8_2p_in16k_out1k_50ms.py)
- Add SGLANG_ENABLE_SPEC_V2: 1 env for spec v2 acceleration
- Tune concurrency, memory fraction, CUDA graph batch sizes, and speculative decoding parameters for optimal throughput at target latency
### 5. Qwen3.6-35B-A3B performance fix (test_npu_qwen3_6_35b_a3b_1p_in3k5_out1k5_50ms.py)
- Fix HCCL_BUFFSIZE : "1" → "100"
