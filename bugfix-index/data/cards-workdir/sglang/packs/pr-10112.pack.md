## Motivation

Fix this bug https://github.com/sgl-project/sglang/issues/6828 of qwen 2.5 VL 7B where fp8 quantization was reported to fail in the visual model part.

## Modifications

1. Make the initialization of the intermediate size in qwen 2.5 VL 7B 8-aligned
2. Change both `weight_loader` and `weight_loader_v2` in `linear.py` to add zero padding when loading weights that are not 8-aligned. After this fix, both `w8a8_fp8` and `fp8` can work
3. Change `w8a8_int8.py` to fix the runtime crash when using `w8a8_int8`

We don't change the kernel as the previous version did #7448

## Remaining work
While fixing the quantization failure for qwen2_5_VL model, I found two other issues. Since they are not exactly related to VL model, I created two other issues. The fix of them will go to different patch series
1. When sending two concurrent requests to qwen2_5_VL model, rotary_embedding crashed regardless of quantization, this is reported in #10623 
2. When fixing w8a8_int8, I found qwen2.5 7B instruct base model generates gibberish. This is reported in #10626
