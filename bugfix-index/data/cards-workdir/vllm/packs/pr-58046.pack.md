## 正文(PR 描述)

## Purpose

Address part of [#26533](https://github.com/vllm-project/vllm/issues/26533) by fixing typing in the Qwen/Qianfan model family and removing `r"vllm/model_executor/models/[qQ]"` from the mypy exclusions. All 24 selected model files are now checked.

The changes cover optional configuration and multimodal fields, tensor/container and cache types, generic processing-info types (including ASR inheritance), MoE mixin attributes, and the realtime async-generator protocol.

Five documented, line-specific typing exceptions preserve existing runtime contracts: four incompatible speculative-drafter/MTP overrides and one instance-local override of a class-level LoRA mapping. No file-wide ignores or replacement exclusions were added.

The branch incorporates upstream `main` at `276db94fb2`. The conflict resolution preserves upstream's multimodal processor interfaces, typed dummy options, ASR position fix, tensor video timestamps, and vision caches. The remaining diff against that revision touches 23 files.

## Reproducer

On upstream main, first remove the Q-model exclusion from `tools/pre_commit/mypy.py`, then run:

```bash
.venv/bin/pre-commit run mypy-3.12 --files \
  $(git ls-files 'vllm/model_executor/models/[qQ]*.py') --hook-stage manual
```

The initial baseline was 297 errors in the selected Q-model files on the original base, `7c877062ac`. This is a historical result, not an error count for current main.
