## PR body
```markdown
## Summary

- configure `NVSHMEM_QP_DEPTH` before CUDA DeepEP low-latency buffer initialization
- enforce `max(existing value, 1024, 2 * (num_max_dispatch_tokens_per_rank + 1))`
- preserve larger user-provided values and leave NPU and normal DeepEP paths unchanged
- force reinstall `nvidia-nccl-cu13==2.30.7` in CUDA 13 CI and the main CUDA 13 image; CUDA 12 remains unchanged
- bump the runtime dependency to `sgl-deep-ep==0.1.1`

## Motivation

DeepEP v2 requires NCCL Gin from NCCL 2.30.7 and an NVSHMEM QP depth of at least twice the low-latency dispatch capacity plus two. For the DeepSeek V4 configuration with 1024 dispatch tokens per rank, the required QP depth is 2050, which is larger than NVSHMEM default of 1024.

## Validation

- SGLang pre-commit hooks passed for all changed files
- PyPI reports `sgl-deep-ep` 0.1.1 as the latest release with 8 wheel files
- CI dependency script passes shell syntax validation
- mocked CUDA-major checks confirm CUDA 13 installs `nvidia-nccl-cu13==2.30.7 --force-reinstall --no-deps` and CUDA 12 skips it
- GB300, four GPUs, with `NVSHMEM_QP_DEPTH` explicitly unset: `TestDSV4FlashFP4B200Balanced` passed all 9 tests in 165.585 seconds
  - GSM8K score: 0.965
  - average speculative accept length: 1.9488
```
