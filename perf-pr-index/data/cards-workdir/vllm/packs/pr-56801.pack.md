## PR body
```markdown
## Summary

- centralize engine and request compatibility policy in `VllmConfig._check_supports_watermarking(config) -> bool`
- treat omitted or `true` request watermarking as enabled by default, with `false` as the sole explicit opt-out
- warn once and fall back to unwatermarked generation when the engine or request mode cannot apply watermarking
- cover missing engine configuration, greedy decoding, trace replay, and beam search with the same warning-and-fallback policy
- centralize request-time resolution in engine admission, applying the result only to the request-local copy so reused caller parameters cannot carry a decision across requests or engines
- validate supported speculative-decoding methods and reject incompatible draft, rejection, parallel-drafting, and custom-sampler configurations
- keep explicit seeds and parallel sampling (`n > 1`) supported, with documented caveats for plain Gumbel diversity and seeded fallback sampling
- preserve the optional request value across OpenAI, Anthropic, Cohere, speech, realtime, batch, beam-search, and direct engine paths until centralized admission resolves it
- explicitly opt internal bookkeeping requests out: language detection, generative scoring, KV-transfer cleanup, and mixed prefill/decode warmup
- add CPU contract tests plus accelerator smoke tests for seeded parallel sampling, prefix caching, grammars, tool calling, TP/PP/DP, mixed batches, API propagation, and internal request paths

## Request behavior

- `watermarking=None`: request watermarking by default
- `watermarking=True`: request watermarking explicitly
- `watermarking=False`: opt out

If watermarking cannot be applied, vLLM warns once for that incompatibility and continues with the request unwatermarked. Transcription, translation, and realtime requests therefore warn once and continue unwatermarked with their default greedy decoding.

## Test plan

- focused impacted suite excluding the unavailable optional Cohere SDK: `139 passed, 15 skipped, 412 deselected`
- all pre-commit hooks for touched files pass, including Ruff, markdownlint, and mypy
- Cohere conversion tests were not collected locally because the optional `cohere` SDK is not installed
- accelerator smoke modules collect successfully; CUDA/GPU execution remains pending
```
