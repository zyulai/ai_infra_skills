## 正文(PR 描述)

## Purpose
`TritonMLA` declared single-token decode support, so a speculative-decode verify block reached `forward_mqa` unflattened: `query_len * num_reqs` query rows against `num_reqs` rows of `block_table` / `seq_lens`. `decode_attention_fwd` launches one program per query row and indexes `tl.load(B_Seqlen + cur_batch)`, so every row past `num_decodes` is an out-of-bounds read.

Reaching it takes a group whose reorder threshold is raised past 1. Ordinary MLA spec decode does not qualify: `TritonMLAMetadataBuilder` inherits `query_len_support = SINGLE_ONLY`, so multi-token queries route to prefill. The threshold is raised by the non-causal route (DSpark draft) which sets its flags after the base `__init__` has asserted `SINGLE_ONLY ⇒ threshold == 1`.
`build()` then splits a *causal* batch with the raised threshold, and `forward_mqa` expands tables only under `if not causal`. Where that happens there is no fallback on either affected platform:

- **NVIDIA sm_86** — `triton_mla` is the only MLA backend whose   `supports_compute_capability` admits `major == 8` (CUTLASS/FlashInfer require 10,   FlashAttn 9, FlashMLA 9 or 10). Reported as `Triton Error [CUDA]: an illegal   memory access` (#51848).
- **ROCm without AITER MLA** — `rocm.py` falls back to `[TRITON_MLA]` alone.

Fixes #51848.

On Kimi-K3 + DSpark, TP8, MI325: (18.01 → 45.00 tok/s), no quality regression (verified on gsm8k: **95%**)

## The fix
`decode_attention_fwd` has no causal flag, but it reads each row's KV extent from `seq_lens`. A uniform verify block is a contiguous suffix, so intra-block causality is expressible as per-row extents: flatten to one decode row per query token and give row `t` extent `seq_len - (query_len - 1 - t)`.

1. `forward_mqa`: derive `query_len` from `q.shape[0] // seq_lens.shape[0]` and    expand `block_table` / `seq_lens` to match, causal or non-causal.
2. `_cudagraph_support` → `UNIFORM_BATCH`, `query_len_support` → `UNIFORM`, so the    reorder threshold admits `query_len > 1`. `attn_logits` workspace grows to match  (workspace locks after capture).
3. `MLAAttentionSpec.merge()` asserts layers agree on  `non_causal_multi_token_decode` instead of `any()`, so a non-causal draft group cannot be merged with a causal target group.
