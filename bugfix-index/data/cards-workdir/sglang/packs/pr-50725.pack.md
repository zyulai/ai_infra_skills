## Motivation

<!-- Describe the purpose and goals of this pull request. -->
#50102 added a read of `wants_int64_query_start_loc` during shared KDA metadata initialization. The Ascend KDA prefill kernel lacked this attribute, causing initialization to fail with an `AttributeError`.


## Modifications

<!-- Detail the changes made in this pull request. -->
Set `wants_int64_query_start_loc = False` on `_AscendKDAExtendKernel`. The Ascend kernel already converts `query_start_loc` to `int64` before calling `chunk_kda_fwd`, so it can skip the shared metadata conversion.
