## PR body
```markdown
## Purpose

This PR improves the ROCm DeepSeek-V4 mHC path by wiring the existing AITER fused mHC operators into vLLM. The ROCm path can now replace the previous sequence of separate mHC/RMSNorm kernels with the fused AITER flow:

- `mhc_post` + `mhc_pre_gemm_sqrsum` -> `mhc_fused_post_pre_gemm_sqrsum`
- `mhc_pre_big_fuse` + `add_rmsnorm_quant` -> `mhc_pre_big_fuse_rmsnorm`

For unsupported fused-RMSNorm hidden sizes, the path still uses fused post+pre where available, while preserving the standalone RMSNorm fallback.

> [!NOTE]
> The change is scoped to the ROCm/AITER path and does not change the CUDA or XPU implementations.

The results show that **This PR improves Output Token Throughput across all concurrency levels, with gains ranging from +0.66% to +1.81%**. **Mean TPOT also improves consistently, decreasing by 0.73% to 1.81% across all concurrency levels**.

For **Mean TTFT**, the results are mixed: it **increases slightly at conc=1 (+9.86%) and conc=64 (+1.80%)**, while it **decreases at conc=4 (-0.60%), conc=16 (-1.15%), and conc=256 (-4.59%)**. Overall, the PR provides a small but consistent throughput improvement and lower TPOT, while TTFT shows some variation depending on the concurrency level.
