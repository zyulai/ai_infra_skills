## 正文(PR 描述)

## Overview

This PR is to revert the changes in https://github.com/vllm-project/vllm/pull/58173, and to add a check to make sure this doesn't happen again. I believe what happened was that a local old version of QuTLASS, before it was migrated to the stable ABI, was being built against the new flags that help ensure QuTLASS stays stable. So I also added a check in here to make sure that a version of QuTLASS after this update is being used. This checks for the file `qutlass/csrc/include/registration.h` which was only added after the migration.
