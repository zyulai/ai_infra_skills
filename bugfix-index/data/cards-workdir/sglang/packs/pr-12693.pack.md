## Motivation

<!-- Describe the purpose and goals of this pull request. -->
In mamba prefix cache match, it needs fork a space to copy mamba state from radix tree and then move the ownership to the request once `HybridReqToTokenPool.alloc` is called. If a request abort between `MambaRadixCache.match_prefix` and   `HybridReqToTokenPool.alloc`, it will cause memory leak. The pr fix this issue.

reproduce command
``` bash
python3 -m sglang.launch_server --model Qwen/Qwen3-Next-80B-A3B-Instruct   --chunked-prefill-size 2048

# after a while, cancel this command, memory leak will occasionally happen
python3 -m sglang.bench_serving  --backend sglang --dataset-name generated-shared-prefix --gsp-num-groups 50 --gsp-prompts-per-group 100 --gsp-system-prompt-len 10240 --gsp-question-len 1024 --gsp-output-len 128 --max-concurrency 50
```
