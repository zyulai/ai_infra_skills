## Purpose
Disable hip sampler temporarily to fix the accuracy issue of deepseek on ROCm platrform. It is found that `deepseek-r1` on ROCm platform tends to generate repetitive response，for example, we send
```bash
curl http://127.0.0.1:8000/v1/chat/completions \
-H "Content-Type: application/json" \
-d '{
"messages": [{"role": "user", "content": "How to 20 pound lose weight in one week"}],
"max_tokens" : 1000, "stream" : false
}'
```
