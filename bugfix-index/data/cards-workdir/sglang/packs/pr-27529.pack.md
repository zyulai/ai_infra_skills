## Motivation
coworked with @yctseng0211，https://github.com/sgl-project/sglang/pull/27525

The compress JIT kernel (c128_v2.cuh) requires `kv_score_buffer`/ `kv_score_input`/ `ape` to have same dtype.  So before feeding the kernel, we need unify all three to the same dtype. Otherwise, the mismatch crashes outright `dtype=float32 not in allowed [bfloat16]`.

similar error on jit norm when enable `SGLANG_OPT_USE_JIT_NORM`
<img width="1457" height="239" alt="image" src="https://github.com/user-attachments/assets/b1564cf0-a193-4ec1-999e-9804605e6ecc" />

c4_sparse_raw_indices attribute error
<img width="1010" height="512" alt="image" src="https://github.com/user-attachments/assets/b2cdeddf-88ca-4baf-b11a-9169f5c819e3" />

## Modifications

- template the C128 / C4 compress kernel on per-tensor dtypes `BufFloat` / `InFloat` / `ApeFloat` / `OutFloat` (cast each input to fp32 at load; no host-side `.to()`) in `python/sglang/jit_kernel/csrc/deepseek_v4/c128_v2.cuh` and `python/sglang/jit_kernel/csrc/deepseek_v4/c4_v2.cuh`
- template the fused norm+rope kernel on a separate `WeightFloat` for the fp32 RMSNorm weight in `python/sglang/jit_kernel/csrc/deepseek_v4/fused_norm_rope_v2.cuh`
- pass the per-tensor dtypes when building the JIT modules (`_jit_compress_module`, `_jit_compress_norm_rope_module`) in `python/sglang/jit_kernel/dsv4/compress.py`
- add `c4_sparse_raw_indices` in `python/sglang/srt/layers/attention/deepseek_v4_backend_hip_radix.py`
