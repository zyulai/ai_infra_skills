## 正文(PR 描述)

## Purpose
TritonExperts did not recognize torch.int8 as a valid input dtype, causing INT8 W8A8 MoE models to crash when processing quantized activations. The change adds INT8 to the supported activation types and uses BF16 as the compute type, allowing INT8 activations to pass through the Triton MoE path correctly.
