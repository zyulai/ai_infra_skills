## Summary

Fix pooling model always being disabled by correcting broadcast_pp_output logic in `gpu_model_runner.py`, which was always set to true and triggered assert not self.is_pooling_model.

### Problem
Changes made to `gpu_model_runner.py` in PR [#24810](https://l.facebook.com/l.php?u=https%3A%2F%2Fgithub.com%2Fvllm-project%2Fvllm%2Fpull%2F24810&h=AT2yp_PT-VpnzX8qemqbKrC_wClaXoXMEk5gGFVCGnhpGuMahNp-AwU0rQrtt6B6MquvUVw2VFtHLGuOhsWp6692rQKQKFtek_Vt6D6nKd6njQ7P5ns2JXSKpD3aYp-Ws7vSC2NBfX02EZsXB30LNH2c) incorrectly disables pooling models if self.broadcast_pp_output is set to true. 

```
        self.broadcast_pp_output = (
            self.parallel_config.distributed_executor_backend == "external_launcher"
            and len(get_pp_group().ranks) > 0
        )

        else: # if self.broadcast_pp_output
          # Rare case.
          assert not self.is_pooling_model

``` 
This is a bug because:
1. The logic to set this flag always evaluates to true as get_pp_group() will always have atleast 1 rank (Set in vllm/distributed/parallel_state.py)
2.  Before PR [#24810](https://l.facebook.com/l.php?u=https%3A%2F%2Fgithub.com%2Fvllm-project%2Fvllm%2Fpull%2F24810&h=AT2yp_PT-VpnzX8qemqbKrC_wClaXoXMEk5gGFVCGnhpGuMahNp-AwU0rQrtt6B6MquvUVw2VFtHLGuOhsWp6692rQKQKFtek_Vt6D6nKd6njQ7P5ns2JXSKpD3aYp-Ws7vSC2NBfX02EZsXB30LNH2c), pooling model condition was based on `get_pp_group().is_last_rank` which would return true if get_pp_group().ranks == 1.
```
            if not get_pp_group().is_last_rank:
              ...
            else:
                if self.is_pooling_model:
                    return self._pool(hidden_states, num_scheduled_tokens,
                                      num_scheduled_tokens_np,
                                      kv_connector_output)
``` 
### Fix
* set flag broadcast_pp_output to True only when get_pp_group().ranks > 1.
* When get_pp_group().ranks = 1, pipeline_parallel_size is 1 which means no broadcast is required.

## Test Plan

Manual verification with llama3 8b model with classification head. Before changes, inference fails with assertion `assert not self.is_pooling_model` being triggered. With changes, batch inference runs successfully. 
Configuration used in testing: `tensor_parallel_size = 1, pipeline_parallel_size = 1`
