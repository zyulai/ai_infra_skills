## PR body
```markdown
MHATokenToKVPool gated the fused store_cache JIT kernel on head_dim == v_head_dim, so models with asymmetric KV (MiMo-V2.5 is 192/128) fell back to two separate index_put_ per layer. This specializes the kernel on (k_row_bytes, v_row_bytes) and gives K and V independent cache strides, so asymmetric K/V takes the fused path as well. Equal-width K/V keeps the existing interleaved two-tensor copy unchanged.

MiMo-V2.5 (310B) TP=4, bs=1 decode: KV-write kernels 102 -> 51 per step, KV-write GPU time -76%, output throughput +2.9%, generated tokens byte-identical.

Also tightens the CPU AMX path, which takes a single row_dim for both tensors and therefore only serves equal-width rows.
```
