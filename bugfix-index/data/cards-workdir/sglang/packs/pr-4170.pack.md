## Motivation
https://github.com/sgl-project/sglang/pull/3986 made substaintial change on memory pool which breaks hierarchical cache, this PR fix the interfaces problem around it.
There are separated PRs fixing other known issues with hierarchical caching, which will be merged later:
Large TP sizes: https://github.com/sgl-project/sglang/pull/4082
MLA support: https://github.com/sgl-project/sglang/pull/4009

## Modifications
