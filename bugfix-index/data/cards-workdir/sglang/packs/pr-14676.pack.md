## Motivation

Recently — especially over the past week — the stability of SGLang OSS has declined significantly. Some very basic accuracy guarantees have not been upheld. The main reason is CI flakiness: many CI jobs, especially those on B200, either didn’t run or were merged before completing, which led to several issues that should have been easily caught. We need to pay significantly closer attention to B200 CI stability and ensure critical tests consistently run to completion. Otherwise, we risk existing users losing confidence and migrating to other inference stack. @Ying1123 @merrymercy @Fridge003 @Kangyan-Zhou
