## 正文(PR 描述)

## Purpose

Fix MTP producing NaN logits for models (e.g. GLM-5) whose checkpoints don't store a duplicate `shared_head.head` weight in the MTP layer (like DeepSeek V3.2). 
The existing `_maybe_share_lm_head` only sets `self.model.lm_head`, but MTP's `compute_logits` uses `shared_head.head` inside each MTP layer. This left it uninitialized when the checkpoint omits it. This patch explicitly shares the target model's `lm_head` with each MTP layer's `shared_head.head,` matching what DeepSeek-V3.2 gets for free by having the weight duplicated in its checkpoint.
