## Motivation

In `Qwen3HybridAttentionDecoderLayer`, the attention output gate on CUDA copies the strided gate slice with `gate.reshape(...)`, then runs `torch.sigmoid` and a multiply as two more kernels. `fused_sigmoid_mul` already reads a 3D strided gate directly. Qwen3.5 (`qwen3_5.py`) uses it for the same layer shape; HIP in this file already used it, after the copy.

## Modifications

- `qwen3_next.py`: `forward_prepare_native` keeps the gate as the `[T, H, D]` strided view from `torch.chunk` instead of copying it.
  - CUDA: `fused_sigmoid_mul(attn_output, gate, inplace=True, round_sigmoid=True)`. `round_sigmoid` rounds the sigmoid to bf16 before the multiply, so the output is **bit-identical** to the previous `attn_output * torch.sigmoid(gate)`.
  - HIP: same kernel and same arguments as before (no `round_sigmoid`), minus the gate copy, so HIP output is unchanged too.
  - CPU / NPU: unchanged torch path (the 3D gate is reshaped back to 2D first).
- Also drops a duplicated `_use_aiter` definition.
- Tests:
  - `test_sigmoid_gate_mul.py`: new `test_sigmoid_gate_mul_head_strided_gate_round_sigmoid_is_bit_exact` asserts `torch.equal` against the torch two-op reference for the Qwen3-Next layout (per-head `[q | gate]`, 16 heads x 256). The existing bit-exact case only covered a 2D column-sliced gate.
  - `test_qwen3_next_fused_qk_prologue.py`: compare the prologue gate against the native gate with `reshape_as`, since the native gate is now 3D.

## Accuracy Tests

Output is bit-identical on CUDA by construction and checked by test, so no eval run:

- `test_sigmoid_gate_mul.py`: 24 passed on 1x A100-SXM4-80GB, including the new head-strided bit-exact case.
- The benchmark below also checks `torch.equal(after, before)` for every shape: all `True`.
- HIP keeps the same kernel arguments as before; CPU and NPU keep the torch path.

## Speed Tests and Profiling

Hardware: 1x NVIDIA A100-SXM4-80GB (driver 595.91.07), bf16, torch 2.14.1+cu130, triton 3.8.0.

"""Before/after microbenchmark for the Qwen3-Next attention output gate.

before: gate.reshape(T, -1) (copies the strided slice) -> torch.sigmoid -> mul
after : fused_sigmoid_mul(attn, gate_3d, inplace=True, round_sigmoid=True)
        on the strided [T, H, D] view from torch.chunk, no copy

Run on one CUDA GPU from the repo root:
    python bench_qwen3next_output_gate.py
Timed with marker.do_bench: CUDA graph replay, inputs cloned per iteration
(cold L2). Reported value is the median. Also checks bit-exactness.
"""

import torch

from sglang.kernels.jit.benchmark import marker
from sglang.kernels.ops.elementwise.elementwise import fused_sigmoid_mul

DTYPE = torch.bfloat16
HEAD_DIM = 256
# (num_q_heads, num_kv_heads) per rank for Qwen3-Next-80B-A3B (16 q / 2 kv) at TP1/2/4
SHAPES = [(16, 2), (8, 1), (4, 1)]
TOKENS = [1, 8, 32, 128, 512, 2048, 8192]


def split_gate(qkv, nq, nkv):
    q_size, kv_size = nq * HEAD_DIM, nkv * HEAD_DIM
    q_gate, _, _ = qkv.split([q_size * 2, kv_size, kv_size], dim=-1)
    q_gate = q_gate.view(qkv.shape[0], nq, -1)
    _, gate = torch.chunk(q_gate, 2, dim=-1)
    return gate  # [T, H, D], strided


def before(qkv, attn, nq, nkv):
    gate = split_gate(qkv, nq, nkv).reshape(qkv.shape[0], -1)
    gate = torch.sigmoid(gate)
    return attn * gate


def after(qkv, attn, nq, nkv):
    gate = split_gate(qkv, nq, nkv)
    return fused_sigmoid_mul(attn, gate, inplace=True, round_sigmoid=True)


def main():
    torch.manual_seed(0)
    print(f"GPU: {torch.cuda.get_device_name()}  dtype: {DTYPE}  torch {torch.__version__}")
    print("| heads q/kv (head_dim 256) | tokens | before (us) | after (us) | speedup | bit-exact |")
    print("|---|---|---|---|---|---|")
    for nq, nkv in SHAPES:
        width = 2 * nq * HEAD_DIM + 2 * nkv * HEAD_DIM
        for T in TOKENS:
            qkv = torch.randn(T, width, device="cuda", dtype=DTYPE)
            attn = torch.randn(T, nq * HEAD_DIM, device="cuda", dtype=DTYPE)

            ref = before(qkv, attn, nq, nkv)
            out = after(qkv, attn.clone(), nq, nkv)
            exact = torch.equal(out, ref)

            t0, t1 = (
                marker.do_bench(
                    lambda q, a, f=fn: f(q, a, nq, nkv),
                    input_args=(qkv, attn),
                    disable_log_bandwidth=True,
                ).times[0]
                * 1e6
                for fn in (before, after)
            )
            print(
                f"| {nq}/{nkv} | {T} | {t0:.2f} | {t1:.2f} | {t0 / t1:.2f}x | {exact} |",
                flush=True,
            )


if __name__ == "__main__":
    main()
```
