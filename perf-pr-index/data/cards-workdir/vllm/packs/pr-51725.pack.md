## Purpose

Let's consider `max_num_seqs=1024`and `max_num_batched_tokens=8192`  (by default) 

Actual Request num | Old logic scheduled tokens | Now
-- | -- | --
1 | 2048 | 8186
32 | 2048 | 8000
128 | 2048 | 7424
1024 | 2048 | 2048

This PR make the scheduled tokens much larger when request num is small by using an adaptive strategy

This is **extremely helpful** when request num is small and give very huge perf improvement
