## Motivation
Issue : https://github.com/sgl-project/sglang/issues/21372

closes #21372
**Flux2-Klein** uses a **Qwen3/Mistral-style** text encoder path where `77 ` is incorrect and truncates long prompts.
The old behavior came from inherited `text_encoder_extra_args` from Flux1.

This change fixes the root cause and adds a defensive guard in Klein tokenization so merged kwargs cannot silently reintroduce 77.

## Modifications

- Fixes Flux2-Klein prompt tokenization using `max_length=77` due to inherited Flux1 config.
- Updates Flux2-family tokenizer extra args to use `max_length=512` (instead of inheriting Flux1 CLIP-style 77).
- Hardens `Flux2KleinPipelineConfig.tokenize_prompt` to explicitly enforce `max_length=512` and ignore conflicting inbound max_length.
- Adds regression/behavior tests for Klein tokenization to prevent future regressions.
