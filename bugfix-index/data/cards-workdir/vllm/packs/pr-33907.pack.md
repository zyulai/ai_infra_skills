## Purpose
This PR fixes the `RandomDataset` prefix generation so the shared prefix token length is adjusted via decode-encode tokenization, similar to the way the input prompt is generated.

## Test Plan
Observe prefix cache hit rate before and after. For testing, a prefix length of 4096 with an input length of 1024 is used. The expected prefix cache hit rate should thus be around 80% `(4096/(4096+1024) = 0.8)`.
