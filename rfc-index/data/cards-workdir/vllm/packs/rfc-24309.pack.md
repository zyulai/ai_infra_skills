## 正文(PRD / 提案全文)

### Motivation.

In the PD disaggregation scenario, it is common to wait for the entire Prefill computation to complete before starting the transmission of the KV cache. The first token is generated by P, but this approach affects the generation time of the second token, as the transmission time of the KV cache must be taken into account.

### Proposed Change.

 Here, an optimization method is proposed:
Shift the generation of the first token to the Decode phase, as illustrated below:
<img width="864" height="617" alt="Image" src="https://github.com/user-attachments/assets/a7b396e8-711d-439c-9801-d00de8ec27d0" />
1.1 Once the KV cache computation is completed, layer-wise transmission can be initiated, or transmission can wait until all computations are finished.
1.2 After the last layer of P completes computation, the hidden state is transmitted to the D instance.
2 The D instance performs the computation for the first token.
3 Once the KV cache transmission is completed, the decode phase proceeds with the generation of subsequent tokens.
Steps 1.1 and 1.2/2 can be executed concurrently.

Advantages: The P node can eliminate all layers after the computation of the transformer blocks, and the subsequent computation of the first token and the transmission of the KV cache are overlapped.
