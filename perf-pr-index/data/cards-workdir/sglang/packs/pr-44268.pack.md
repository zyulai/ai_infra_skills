## Motivation

With `--enable-fused-moe-sum-all-reduce` (#19672) the Triton down GEMM sums the experts into `out_hidden_states` and leaves `intermediate_cache3` unwritten, but `_fused_moe_kernel_sequence` honours that only under `_is_cuda or _is_musa` and ignores LoRA's `after_down` hook; this PR handles the fused case before the platform dispatch and disables the fusion when `hooks.after_down` is set.

On HIP, XPU and the fallback, the combine reduces the unwritten `intermediate_cache3` over the result. On every platform the LoRA down delta, added to `intermediate_cache3`, is dropped. On ROCm every Triton-runner MoE layer with `topk > 2` breaks; GSM8K is 0 % for Qwen3.6-35B-A3B and Kimi-Linear-48B with `--moe-runner-backend triton`, and for GLM-5.3, MiniMax-M2.7 and Qwen3-Next/Qwen3.8-Flash-Next FP8 with `SGLANG_USE_AITER=0`. gemma-4-26B-A4B (I=704) runs Triton by default, so the flag alone breaks it.

## Modifications

- In the fused case, apply `routed_scaling_factor` as the platform's unfused combine does: everywhere except the aiter path, whose `moe_sum` skips it too. The CUDA/MUSA code is moved, not changed.
- An empty `LoRAHooks()` (LoRA enabled, no active adapter) keeps the fusion on.
- Add `TestFusedMoeSumAllReduce`: flag-on output must match flag-off and the fused kernel launch is asserted, for routed scale None/2.5 with no hooks, empty hooks or an `after_down` hook. Without the LoRA guard the 6 `after_down` cases fail with ~20 % relative error.

## Accuracy Tests

`sgl-eval` gsm8k, temperature 0, MI355X. First two rows: 1319 items, Triton runner, main flag-off run twice as noise control. Rest: 200 items, `SGLANG_USE_AITER=0`, `auto` resolves to Triton:

## Speed Tests and Profiling

No speed change is intended. gemma-4-26B-A4B-it, cookbook command, flag off, TP1, `sglang.benchmark.serving` random 1937/389, 307 prompts, concurrency 61, median of runs 2–4 of 4: total 13870.9 → 13935.4 tok/s (+0.5 %), TTFT and TPOT flat. With the flag on, gemma-4 runs ~60 % below its flag-off throughput on gfx950 (`acq_rel` atomics), so the flag should stay off on ROCm.
