## PR body
```markdown
## Purpose
FlashInfer supports sparse MLA as of https://github.com/flashinfer-ai/flashinfer/pull/2138. This PR integrates support for this kernel in vLLM, and enables it by default when head count <= 16 (TP8 or higher)

## Test Plan
### Performance
```

