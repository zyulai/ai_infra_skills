## Motivation

flashinfer has an optimized routing kernel for DeepSeek V3:  https://github.com/flashinfer-ai/flashinfer/pull/2099
The API was renamed to `fused_topk_deepseek` here:  https://github.com/flashinfer-ai/flashinfer/pull/2181 

## Modifications

Replace the call to `moe_fused_gate` with `fused_topk_deepseek`.
