## PR body
```markdown
## Disclosure

AI assistance was used. The changes were reviewed and tested manually.

## Purpose

Deprecates online quantization through ``quantization="fp8"`, redirecting to the online shothand `fp8_per_tensor`.

This removes online-quantization path from `fp8.py` in favor of `ONLINE_QUANT_SHORTHAND_NAMES`, such as `quantization="fp8_per_tensor"`, that uses https://github.com/vllm-project/vllm/blob/main/vllm/model_executor/layers/quantization/online/fp8.py as documented in https://docs.vllm.ai/en/stable/features/quantization/online: https://github.com/vllm-project/vllm/blob/79bb395eea64dbfef99a55f010d2854db71f8571/vllm/config/quantization.py#L151-L155

This is a followup of:
- https://github.com/vllm-project/vllm/pull/32189
- https://github.com/vllm-project/vllm/pull/45463

Keep `Fp8Config.is_checkpoint_fp8_serialized` for backward compatibility with callers that still read the attribute.

Breaking changes:
- None. `quantization="fp8" redirects to `"fp8_per_tensor"`.

Removes some slow outdated online quantization tests from `test_fp8.py` (linked to https://github.com/vllm-project/vllm/pull/53291). These tests were mostly duplicated with `test_online.py`, and taking excessive time (e.g. in [(MI300) Quantization](https://buildkite.com/vllm/amd-ci/builds/12674/list?sid=01a07b19-ca08-487c-b195-fd03f88df6b4&tab=output) group):
```
