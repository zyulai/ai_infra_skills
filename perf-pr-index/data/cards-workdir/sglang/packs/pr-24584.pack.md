<!-- Describe the purpose and goals of this pull request. -->

With CUDA graph enabled, graph capture uses `max_seqlen` as the `seqlen`, which leads to a lot of redundant computation. 
We add an early-exit in the attention kernels so that only meaningful tokens (< topk) are computed. 
This brings 10-40% TPUT improvement on e2e, more pronounced at higher conc.
