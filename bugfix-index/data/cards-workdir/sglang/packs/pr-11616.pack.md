## Motivation

<!-- Describe the purpose and goals of this pull request. -->

This pull request addresses an issue with the cache eviction logic introduced in #11214. The eviction step is implemented in `schedule_batch.py`​​, but due to the recent refactoring in #11313 (which moved `alloc_req_slots` and its associated logic to `common.py`), the eviction logic wasn't being called. This issue was also reported in https://github.com/sgl-project/sglang/pull/11214#issuecomment-3396063269 .

This patch ensures that evictions are correctly called from the refactored alloc_req_slots function.

## Modifications

<!-- Detail the changes made in this pull request. -->

Moving eviction logic to `common.py`.
