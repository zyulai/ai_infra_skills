## 正文(PR 描述)

## Purpose

PR #36487 ("Replace OMP initialization") introduced unconditional calls to Linux-only APIs that break vLLM's CPU support on macOS:

1. `os.sched_getaffinity` — does not exist on macOS  
2. `lscpu` — Linux-only command

This was flagged by @hmellor in #36487 (review comment).

## Changes

**`vllm/utils/ompmultiprocessing.py`**:
- Add `_get_default_affinity()` — falls back to `os.cpu_count()` when `sched_getaffinity` is unavailable
- Add `_get_cpu_topology_json()` — synthesizes a simple single-node topology on non-Linux platforms instead of calling `lscpu`
- Use these helpers in `enumerate_resources()` and `OMPProcessManager.__init__()`

**`vllm/platforms/cpu.py`**:
- Guard `CpuPlatform.get_global_cpu_mask()` with `hasattr(os, "sched_getaffinity")` check, falling back to `os.cpu_count()`

## Test Plan

- Verified on macOS (Darwin) that `OMPProcessManager` initializes successfully
- Verified `_get_default_affinity()` returns correct CPU set via `os.cpu_count()` fallback
- Verified `_get_cpu_topology_json()` produces valid JSON topology on macOS
- All pre-commit hooks pass
