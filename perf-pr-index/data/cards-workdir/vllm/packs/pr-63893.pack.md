## Overview

**This draft is stacked on #63027. Only the last commit (`3d923a6848`) is new; the first three (`96fa04ad7a`, `043dd8da90`, `37372f010c`) are #63027's, rebased onto main `4b47db922b`.**

#63027 tunes K1 and K2 for the target's compress-ratio-2 layers at TP2 only. This PR turns its tuned K1 (the attention seam and front) on for every TP4 layer on gfx950 (MI355X), the DSpark draft's included. K2 stays generic at TP4, and TP8 keeps the generic K1. We run DeepSeek-V4.1-Flash at low concurrency on MI355X as TP4 with `--monokernel`.

## Claims

- **Decode step (ABBA against #63027 rebased, 4 rounds):** c1 -284 us (-5.2%), c2 -326 us (-4.8%), c4 -194 us (-2.2%); every round faster, beyond t x SE and the base A/A spread.
- **Outputs unchanged, by design:** the paths are #63027's, which it shows bit-exact against the generic code at TP2. The numerics test now also compares them bit for bit at TP4: it passes on MI355X, and a mutant one bf16 ulp off in TP4 K1 fails it. GSM8K and AL match base within noise. The draft K1 has no GPU bit check (see test coverage).
- **Scope:** fixed per build, no env var: `MonoBuild.tuned_front = tuned or (not GFX942 and not generic and tp == 4)`. Mono builds only for gfx942 and gfx950, so this means gfx950. TP2, TP8, `generic=True` and gfx942 builds compile as on #63027. TP8 keeps the generic K1; #64152 extends this PR to TP8. TP4 K2 code is unchanged; only its scratch offsets move.
- **Compile level (measured):** TP4 K1 uses 148-174 VGPRs at 1-48 rows (#63027 rebased: 142-240), with no spills and unchanged LDS. TP8 builds are binary-identical to main's.

## Details

**Design**
- #63027's tuned K1 paths (flag copies, norms and gates off the wqkv CTAs, fused fold and slice, wide normed stores, batched norm polls) read no routing dims. At TP4 they apply to every ratio, to fold off, to index sources and to the draft.
- K2 keeps `tuned` (TP2 ratio 2 only). A TP4 tuned K2 hung during FULL capture in an earlier experiment, and that code is gone from #63027's head.

**Scratch**
- K1 and K2 of a width share `_layout(key)`; its K1 regions now follow `tuned_front`.
- The runner keys a scratch by (width, tuned, front), so a front-tuned layout never aliases the FFN launch's generic one.
- The cost is at most 8,960 B per width (48 rows: 11,153,024 -> 11,161,984 B; 14 rows: +5,632 B).
- `build_key()` replaces `tuned()` and the duplicate `MonoBuild` construction in `kernels()`.

**Earlier estimate:** -273 us at c1 and -298 us at c2 (an earlier #63027 K1 revision, one unswapped run per arm); the ABBA above measured -284 us and -326 us.

**Related PRs**
- **#63027** (open, head `d104a70f8d`, conflicts with main): the first three commits here are its commits rebased onto main. When it is rebased, this PR follows. This PR makes two statements in its description stale: "TP4 is not tuned" (TP4 K1 now is), and "every other build ... compiles to the same MLIR as on main" (TP4 K1 is new code; TP4 K2 keeps its instruction stream, but its scratch offsets move). I am happy for this commit to be folded into #63027.
- **#64152** (draft) is stacked on this PR. It changes the gate to `tp in (4, 8)`, so TP8 takes the tuned K1 too.
- **#63892** (sibling, K2 side: batch TP4 K2's X8 copies, load its push's peer bases late) applies cleanly to main, but still conflicts with this stack: 6 hunks in 3 files (the numerics test 1, `layer.py` 1, `stages/moe.py` 4). It gives the same 6 hunks on #63027 rebased alone, so the conflict comes from #63027's commits, not this one. Whichever lands second resolves them.
- **#63486** (draft): it moves this test and reads scratch through `runner.scratch(M)`, which #63027's TP2 ratio-2 steps already break. After this PR the same reads need `build_key(M, ratio)`'s `(tuned, tuned_front)` at TP4 too. Whichever lands second adapts.
- **#61934:** it hoisted K2's FFN-seam loads and was closed with "No e2e gain observed". That is why the ABBA gates this PR.
- No other open PR turns on the tuned K1 at TP4: #63027 is TP2-only, #64152 builds on this PR, and #63892 and #64153 change K2 (TP4 and TP8).
