## Motivation

Add autotuned JSON configs for `_w8a8_block_fp8_matmul_gfx1250` covering all DSV4-Flash 2-D fp8 weight shapes on AMD Instinct Graphics (gfx1250/MI45x). Without these, the runtime fell back to BLOCK_SIZE_M=64 — wasting 63/64 rows at token=1 for decode shape.

## Accuracy Tests

Intact.
