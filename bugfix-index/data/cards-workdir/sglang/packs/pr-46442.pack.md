## 正文(PR 描述)

## Motivation

https://github.com/sgl-project/sglang/pull/45700 reworded the fused draft KV dtype mismatch error and dropped the flag name, so `test_kv_cache_configurator_draft_gate.py` (weekly suite) no longer matches it. The mismatch happens when an `auto` draft resolves a KV dtype other than the one its region was sized in; setting `--speculative-draft-kv-cache-dtype` explicitly sizes the region in the draft's dtype, so the error names the flag again.
