## Motivation

This patch is to fix tensor shape mismatch issue for amd dsr1 0528 mxfp4 https://huggingface.co/amd/DeepSeek-R1-0528-MXFP4 . Root cause is amd dsr1 0528 introduced a new regex rule `re:model.layers.61.*` for excluding MTP layer, however the MTP layer is renamed to be `model.decoder.mlp.experts.*` so lead to wrong QuarkFusedMoEMethod selected.

## Modifications

The `QuantizationConfig` class provides an interface to remap and post-process the quant config name.
By adding `hf_to_sglang_mapper` as a class attribute in `DeepseekV3ForCausalLMNextN`, following the implementation pattern used in models like Qwen2.5 VL.
Then, in Quark implementation, we then instantiate and invoke the `apply_weight_name_mapper` method accordingly.
