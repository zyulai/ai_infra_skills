## Purpose
Add `compile_mm_encoder` support for both Pixtral vision encoder implementations:

- `PixtralForConditionalGeneration`, including Mistral-format Mistral 3 models.
- The Hugging Face Pixtral encoder used by `Mistral3ForConditionalGeneration`.

The change applies `support_torch_compile` to the transformer blocks in both implementations and marks the token, rotary embedding, and packed-sequence dimensions as dynamic.

The feature remains gated behind `compile_mm_encoder`, which is disabled by default.

### Performance results
Note: the results are only about GPU kernel time. Total E2E runtime improves much less, even with Cuda graphs from #56277, because apply_hf_processor is the main bottleneck now.

Profiling was performed on an NVIDIA GB200 system using the same 16-image BF16 capture before and after enabling compilation. 
Total GPU kernel time decreased by **42%**, from **1173.6 ms to 676.8 ms**, corresponding to a **1.73x speedup**.

The improvement came from eliminating or fusing much of execution overhead:

| Kernel category | Before | After | Reduction |
| --- | ---: | ---: | ---: |
| FlashAttention | 273 ms | 273 ms | 0% |
| GEMM | 272 ms | 272 ms | 0% |
| Elementwise operations | 368 ms | 11 ms | 97% |
| SiLU | 121 ms | 44 ms | 64% |
| Concat | 96 ms | 0.3 ms | >99% |


  ### CUDA-graph compatibility

  This work is complementary to #56277, which adds Pixtral encoder CUDA-graph support. It does not duplicate or modify that implementation.

  The CUDA-graph PR’s pixtral.py and mistral3.py changes apply cleanly over this change. Its packed encoder forwards continue to use the unchanged transformer interface. Encoder CUDA-graph capture also performs an eager warmup before capture,
  allowing the transformer blocks to compile first.

  A combined compile_mm_encoder=True plus cudagraph_mm_encoder=True integration test should be added once #56277 is merged.

## Test Plan
Exercise both encoder implementations with compilation enabled and disabled:

- Mistral-format `PixtralForConditionalGeneration`
- Hugging Face `Mistral3ForConditionalGeneration`

The test uses dummy weights and verifies that the compilation counter increases only when `compile_mm_encoder` is enabled.
