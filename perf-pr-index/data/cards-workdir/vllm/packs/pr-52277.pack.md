## Purpose
`_pack_binary_embeddings` (`vllm/entrypoints/pooling/embed/protocol.py`) bit-packs
embeddings for the Cohere `/v2/embed` `binary` / `ubinary` embedding types with a
nested Python loop. This PR replaces it with `np.packbits`, which is ~4.3x faster with byte-identical output.
