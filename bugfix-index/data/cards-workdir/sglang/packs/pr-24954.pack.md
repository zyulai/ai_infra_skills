## 正文(PR 描述)

## Summary
Goal: move all mamba state operations to forward stream to avoid scheduler <-> forward stream data manipulation races
1. Fix `cache_unfinished_req`'s copy mamba state races with forward stream:  cache unfinished donate the index to the radix cache instead of copying, then alloc a new one for next iteration
2. prefix match copy-on-write (cow) and mamba state clear both happen during init metadata instead of scheduler stream.

## Testing
- CI coverage is sufficient
- Verified race-free fix with 0kl RL testing, context: https://github.com/sgl-project/sglang/issues/24221#issuecomment-4424945325
