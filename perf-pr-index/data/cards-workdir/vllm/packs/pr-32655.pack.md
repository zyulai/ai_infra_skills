## PR body
```markdown
## Purpose
This PR enhances the fused MoE LoRA implementation by adding support for the unpermute execution path. It introduces a small-batch fallback path in particular for models with large numbers of experts . For these regimes, we skip permutation kernel for MoE LoRA and use token-wise naive block assignment.
```
