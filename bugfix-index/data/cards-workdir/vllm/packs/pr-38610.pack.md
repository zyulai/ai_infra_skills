## 正文(PR 描述)

## Purpose

Currently, working on returning mean-pooled vector with the normal response https://github.com/vllm-project/vllm/pull/38565

However, the current extract_hidden_states_proposer is currently returning **raw tensor** instead of
[batch_size, num_speculative_tokens]

So, there is a size mismatch for decode steps

```python
self.draft_token_ids_cpu[:num_reqs].copy_(draft_token_ids)
*                    [N, 1]                        [N, 2]  → SHAPE MISMATCH*
```

Since num_speculative_tokens is set to 1 for the proposer, just hard-coded it to :1
