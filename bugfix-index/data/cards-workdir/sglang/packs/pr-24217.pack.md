## Motivation

Fixes #24215. Reporter saw STANDALONE spec-decode crash on Llama-3.1-8B (target, hidden=4096) + Llama-3.2-1B (draft, hidden=2048) at `EagleDraftInput.merge_batch.torch.cat`:

```
RuntimeError: Sizes of tensors must match except in dimension 0.
Expected size 4096 but got size 2048
```

## Diagnosis

`spec_info.hidden_states` has two canonical shapes, switched at phase boundaries:

| Phase | Producer | Wire shape |
|-------|----------|------------|
| decode | draft model output, re-written by `capture_for_decode` and the draft loop (`eagle_worker.py:875`, `:1234`) | **draft** |
| extend | target verify output (`eagle_worker.py:959`), carried by `EagleDraftExtendInput` from `eagle_info.py:547`/`:617` | **target** |

`capture_for_decode` at the end of `forward_draft_extend` (`eagle_worker.py:1115`) normalizes the batch back to draft shape before it leaves the worker, so the scheduler always sees draft shape.

The reporter's 0.5.9 crash is no longer reachable on current main — the `capture_for_decode` normalization (added 2025-03-05) already handles the cross-phase shape switch.

## Changes

Two extend-phase wiring sites aligned to target (the producer for extend):

1. **`eagle_worker.py:1117`** — `forward_draft_extend_after_decode`'s idle fallback sizes the `EagleDraftExtendInput` placeholder from `target_worker.model_runner.model_config`.
2. **`eagle_draft_extend_cuda_graph_runner.py:154-163`** — the extend cuda graph buffer is sized from the target config.

Both are hygiene fixes: pre-PR the extend wiring used draft shape, which was latent because (a) the idle fallback path requires `enable_dp_attention=True` to be reachable (`eagle_worker.py:499-504`), and (b) the extend cuda graph runner has a shape-guard at `:486-492` that silently skips `copy_` on mismatch.

Decode-phase wiring is left at draft shape (the pre-PR state). Flipping it to target — as the initial hypothesis suggested — would actively produce the exact `Expected 4096 got 2048` crash by giving the scheduler a target-shaped idle batch to cat against a draft-shaped running batch.

Per #21058 task 1 (PR #21434), STANDALONE should not carry `hidden_states` at all on the spec v1 path. Once that lands, both sites become dead code.
