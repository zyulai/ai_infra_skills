## Motivation

HiCache must restore every cache state required by speculative decoding, not only the target model KV cache.

MTP/EAGLE draft models may keep KV, DSA indexer, or SWA state in separate device pools. If HiCache restores only the target pools, the prefix can report a cache hit while the draft-side state is missing or uses a different slot mapping. This can reduce speculative acceptance after an L2/L3 replay.

This PR adds two draft-cache integration paths so each draft topology can reuse the appropriate target cache index space.

## Design

| Path | Models/topology | Host-pool layout | Transfer semantics |
|---|---|---|---|
| **Packed** | Standard NextN MTP/EAGLE, including DeepSeek-V3.2, GLM-5.x, DeepSeek-V4, MiMo-V2.5; also DeepSeek-V4 DSpark | Draft KV/indexer/SWA buffers are appended as tail layers of the matching target host pool | Target and draft share the same host slots and are moved by the same HiCache operation |
| **Sidecar** | Standalone EAGLE/EAGLE3, DFlash, and non-DeepSeek-V4 DSpark | Separate `DRAFT`, `DRAFT_INDEXER`, or `DRAFT_SWA` host-pool entries are created only for non-empty draft state | Sidecars derive indices from target KV or SWA and are attached to the same L2/L3 operation |

The sidecar host pool uses the same slot count as its source target host pool, keeping target and draft host indices one-to-one. Draft SWA follows target SWA trailing-page semantics; draft full KV and DSA indexer follow target KV indices.

Inkling HiCache MTP is intentionally not supported by this PR.

## Modifications

- Add a HiCache draft plan that selects packed or sidecar mode before building the tree cache.
- Keep the existing packed MTP path for compatible NextN models and DeepSeek-V4 DSpark.
- Pack draft KV, DSA indexer, and SWA buffers into the corresponding target host pools.
- Add dynamic sidecar registration for non-packed draft pools:
  - `DRAFT <- KV`
  - `DRAFT_INDEXER <- KV`
  - `DRAFT_SWA <- SWA`
- Transfer registered sidecars together with their source pool for L2 and storage-backed L3 operations, including Mooncake.
