## Motivation

If `@dataclass` is not added, the type of this pipeline will still be t2i.

---

Previously, SP (Sequence Parallelism) alignment was performed before pipeline_config.adjust_num_frames. This created a race condition where adjust_num_frames could alter an already-aligned frame count, causing the final value to fail the divisibility check required for multi-GPU execution.

Modifications 

- Reordered the execution flow so that adjust_num_frames is processed first.

Current Flow

- Execute Pipeline-specific frame adjustment (adjust_num_frames).

- Apply SP alignment logic based on the GPU count to the adjusted frames.

Effect 
- Guarantees that the final num_frames adheres to both the Pipeline's logic and the SP alignment constraints (divisible by num_gpus).
