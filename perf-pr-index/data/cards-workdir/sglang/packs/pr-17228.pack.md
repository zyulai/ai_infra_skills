## Motivation

Slightly improve performance of LoRA torch_native backend on NPU.

## Modifications

torch.einsum replaced with torch.mm and torch.Tensor.T in lora_ops. Removed one intermediate tensor by inplace operation. 

## Accuracy Tests

Algorithm logic and sequence of math operations don't changed. Quick test with curl request of Qwen3-14B with LoRA adapter showed the same answer.

## Benchmarking and Profiling

bench_serving showed ~3% overall model execution improvement of Qwen3-14B with LoRA adapter on Atlas A2 & A3 hardware.
