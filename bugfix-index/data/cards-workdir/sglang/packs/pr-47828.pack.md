## 正文(PR 描述)

## Motivation

Fixes #47827.

Starting the simulator with the Replay predictor fails when the optional
`aiconfigurator` dependency is not installed. Eager imports in the predictor
package, configuration manager, and simulation utilities load AIConfigurator
even when Replay is selected and `--max-total-tokens` is explicitly configured.

Replay should run without AIConfigurator in this configuration.

## Modifications

- Lazily expose `AIConfiguratorTimePredictor` through the predictor package,
  preserving its package-level import path.
- Import AIConfigurator only when its predictor is selected or automatic
  KV-cache memory estimation is requested.
- Provide an actionable error when `aiconfigurator` is missing, including
  installation instructions and guidance for Replay/ML users.
- Preserve the original errors for unrelated missing dependencies.
- Correct `__all__` to contain export names.
- Add isolated subprocess regression tests for Replay initialization and
  prediction without AIConfigurator, missing-dependency messages, and error
  propagation.

No scheduling, latency prediction, KV-cache sizing algorithms, or benchmark
metric calculations are changed.

+"""Optional predictor dependencies must not prevent Replay startup."""

+import subprocess
+import sys

+import pytest

+BLOCK_AISIMULATE = """
+import importlib.abc
+import sys
+
+class BlockAISimulate(importlib.abc.MetaPathFinder):
+    def find_spec(self, fullname, path=None, target=None):
+        if fullname == "aisimulate" or fullname.startswith("aisimulate."):
+            raise ModuleNotFoundError("No module named 'aisimulate'", name="aisimulate")
+
+sys.meta_path.insert(0, BlockAISimulate())
+"""
+
+
+def run_isolated(code):
+    result = subprocess.run(
+        [sys.executable, "-c", BLOCK_AISIMULATE + textwrap.dedent(code)],
+        capture_output=True,
+        text=True,
+        timeout=30,
+    )
+    assert result.returncode == 0, result.stdout + result.stderr
