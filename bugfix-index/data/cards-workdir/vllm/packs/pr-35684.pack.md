## 正文(PR 描述)

## Purpose

This PR fixes and stabilizes the OpenAI render preprocessing endpoint.

Fixes https://github.com/vllm-project/vllm/issues/35665
Refactors POST /v1/chat/completions/render to return an RFC-aligned (https://github.com/vllm-project/vllm/issues/22817), JSON-serializable token-in GenerateRequest instead of internal render artifacts (which could trigger HTTP 500 on serialization for multimodal inputs).
Ensures sampling_params can be carried through the GenerateRequest cleanly and serialized safely 
Adds coverage for multimodal /render (base64 image_url + text) and for stream=True + stream_options requests.
