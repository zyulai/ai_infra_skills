## PR body
```markdown
## Summary

With cross-layer index sharing, only some attention layers update the shared top-k buffer.
The old path still remapped that buffer on every layer.

This PR runs the remap only when the layer owns an indexer. For GLM-5.2 with
`index_topk_freq = 4`, this reduces remaps from 78 to 21 per forward pass.

## Safety

- Layer 0 always owns an indexer, so the shared output is initialized before reuse.
- Non-indexer layers do not change the inputs to the remap.
- The default `index_topk_freq = 1` path is unchanged.
- Speculative decoding still remaps on every layer.

## Update: indexer and non-indexer layers are two KV cache groups

https://github.com/vllm-project/vllm/pull/53781  added the is_index_group_leader field to MLAAttentionSpec: `is_index_group_leader=self.indexer is not None,`. Layers can only share a KV cache group if they agree on is_index_group_leader, so once the flag is set per layer, indexer and non-indexer layers land in different groups and therefore get different metadata instances with separate paged_kv_indices

```
index_group_leader_set = {spec.is_index_group_leader for spec in specs}
assert (
    ...
    and len(index_group_leader_set) == 1
    ...
), (
    "All attention layers in the same KV cache group must use the same "
    "... index-sharing role, ..."
)
```

So, remap should run for all indexer layers and the first non-indexer layer. The two non-indexer layer following the first non-indexer layer doesn't need a remap.

The following table shows how the remap condition changed between the commits and how it is implemented by `index_epoch` and  `remapped_epoch`. index_epoch is fixed per layer at construction: it counts indexer writes up to and including that layer - which selection is this layer entitled to read. remapped_epoch lives on the metadata and moves during the pass: it records which selection is currently sitting in that group's paged_kv_indices. A mismatch means the group is holding an older selection and must refresh.

| Layer | Owns indexer | Group | `index_epoch` | group's `remapped_epoch` before | Commit 1 | Commit 2 | group's remapped_epoch after |
|---:|:---:|:---:|---:|---:|:---:|:---:|---:|
| 0 | yes | A | 1 | -1 | remap | remap | 1 |
| 1 | yes | A | 2 | 1 | remap | remap | 2 |
| 2 | yes | A | 3 | 2 | remap | remap | 3 |
| 3 | no | B | 3 | -1 | skip | remap | 3 |
| 4 | no | B | 3 | 3 | skip | skip | 3 |
| 5 | no | B | 3 | 3 | skip | skip | 3 |
| 6 | yes | A | 4 | 3 | remap | remap | 4 |
| 7 | no | B | 4 | 3 | skip | remap | 4 |
| 8 | no | B | 4 | 4 | skip | skip | 4 |
| 9 | no | B | 4 | 4 | skip | skip | 4 |
| 10 | yes | A | 5 | 4 | remap | remap | 5 |
| 11 | no | B | 5 | 4 | skip | remap | 5 |
