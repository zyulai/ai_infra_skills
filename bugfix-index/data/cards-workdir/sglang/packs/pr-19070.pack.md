## 正文(PR 描述)

fix(dense): fix Qwen3.5 dense model precision bug in TP_SIZE>1

- Add conditional `should_allreduce_fusion` check for MLP layers.
- Separate calling logic for MoE vs. Dense blocks.
- Mark `hidden_states` with fusion flags to manage communication.
- Bypass explicit communication when AllReduce fusion is enabled.
- Preserve original `forward_batch` and `use_reduce_scatter` behaviors.
