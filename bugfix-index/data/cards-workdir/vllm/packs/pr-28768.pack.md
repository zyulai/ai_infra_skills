## 正文(PR 描述)

This fixes two pipeline-parallel related issues introduced by https://github.com/vllm-project/vllm/pull/26866:

1. Performance regression reported in https://github.com/vllm-project/vllm/issues/28270
2. KV connector output propagation/aggregation from workers

The first commit just reverts the granular tracing context managers added in #28329 which make the code very difficult to read/update. Please just look at the changes in the [second commit](https://github.com/vllm-project/vllm/pull/28768/commits/818983d7bd17e99611e11c54722bfde684153413) which are smaller/cleaner.

Fixes #28270

Thanks to @weireweire for reporting.
