## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->
This pr implemented a faster kernel for per_token_group_quant_fp8, which can replace triton kernel. https://github.com/sgl-project/sglang/pull/4817

I tested the kernel with 2048x7168 fp8 quant:
![image](https://github.com/user-attachments/assets/8ae931f9-f5bc-4387-9e8e-6e8faf12a1ff)

and benchmark DeepSeek-R1 on 8*H20, about 5% throughput increase

## Modifications

<!-- Describe the changes made in this PR. -->
Column-major scale is constructed as input of cuda kernel.
