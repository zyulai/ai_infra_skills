## 正文(PR 描述)

## Purpose
When running the following command:
```
vllm serve deepseek-ai/DeepSeek-V2-Lite \
--data-parallel-size 2 \
--enable-expert-parallel \
--all2all-backend deepep_v2 \
--enforce-eager
```
vLLM will crash at startup with the following error
```
expert_indices.size(1) == args->top_k (1 vs. 6) : expert_indices dim1 must match top_k.
```
This error is caused by `TrtLlmBf16ExpertsModular` not properly extracting the `top_k` value when DeepEP V2 returns the topk_ids in it's "expanded" layout. This PR updates the logic to use the correct value for `top_k` in this backend and improves the DeepEP V2 + MoE unit test to cover the expanded and non expanded layouts for the `flashinfer_trtllm`, `flashinfer_cutlass`, and `trtllm_fp8` backends.


## Test Plan

