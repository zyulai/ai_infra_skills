## 正文(PR 描述)

## Purpose
Fix a bug in apply_grammar_bitmask where the number of bitmasks was derived from the pre-initialized sorted_bitmask tensor instead of the actual indices requiring masking. This misalignment caused non-structured output requests to be masked, leading to illegal memory access issues due to their logits being converted to NaN.

## Changes Made
Derive bitmask count from the actual required indices rather than `sorted_bitmask `length.
Ensure masking is applied only to relevant requests to prevent unintended NaN logits.
