## 正文(PR 描述)

## Motivation

In `python/sglang/srt/managers/tokenizer_manager.py` file, the `__init__` method of class `TokenizerManager`, this line:

```python
self.context_len = server_args.context_length or get_context_length(
            self.hf_config
        )
```

is problematic because when loading a vision-LLM like Llama-3.2, the text related config is under `config/text_config`, and here `self.hf_config` is the whole model config, not just `text_config`, `get_context_length()` function won’t find max context length parameter and will instead return a default value of 2048. 

## Modifications

A simple fix is just replacing this line with:

```python
self.context_len = server_args.context_length or get_context_length(
            getattr(self.hf_config, "text_config", self.hf_config)
        )
```

to check if there is a `text_config` item inside the whole config, if yes, there the context length parameter must be found under that.
