## Motivation

EAGLE `topk=1` only needs the largest-logit token. For finite logits, a full-vocabulary softmax cannot change the argmax and is redundant. AITER `greedy_sample` has an unmasked vector-tail correctness issue; on MI355X it returned an out-of-vocabulary index for vocabulary size 151,666. SGLang’s existing Triton split-argmax masks offsets `>= vocab_size` and safely handles NaNs.

## Changes

- Use the existing masked Triton split-argmax for ROCm EAGLE `topk=1` in both draft-decode and draft-extend.
- Make position advancement optional so the implementation can be reused in draft-extend.
- Add AMD coverage for aligned and misaligned vocabularies, NaN, `-inf`, and all-negative logits.
- Keep rejection sampling, `topk > 1`, and all non-ROCm paths unchanged.
- Apply the optimization generically to supported ROCm EAGLE, EAGLE3, and MTP models without model-name gating.

## Correctness
- `test_spec_topk1.py`: **6 passed, 12 subtests passed**
- `test_eagle_worker_v2_topk1_fastpath.py`: **9 passed, 7 subtests passed**
- Triton outputs remained within `[0, vocab_size)` for vocabulary sizes **151,666** and **248,320**.

## Conclusion

This removes a redundant full-vocabulary softmax from ROCm EAGLE `topk=1` while using a vocabulary-masked selector with generic correctness and safety benefits. Qwen shows a measurable improvement, while MiniMax confirms no regression within variance. The optimization applies to supported ROCm EAGLE/MTP models without introducing model-specific behavior.
