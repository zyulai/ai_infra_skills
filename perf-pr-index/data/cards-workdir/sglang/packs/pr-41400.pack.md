## Motivation

[FlashInfer #5021](https://github.com/flashinfer-ai/flashinfer/pull/5021) (0.7.0) adds indexed, floor-aligned checkpoints to CuTe DSL KDA prefill, which SGLang needs for radix prefix caching.

## Modifications

- Opt-in `--linear-attn-prefill-backend flashinfer` for BF16, 128-dim safe-gate KDA on SM100/SM103.
- Map FlashInfer checkpoints to radix-cache track rows (FP32 state pools, padded gate/beta); write only radix-tracked checkpoints.
- KDA models pass raw beta logits in every phase. Kernel adapters own activation, without backend-dependent model flags or model mutation during backend construction. FlashInfer tensor validation runs during warmup.
- Call `flashinfer.kda.recurrent_kda(..., backend="cute-dsl")` directly. FlashInfer owns scheduling and workspace allocation; SGLang maps radix-cache checkpoint destinations once per tracked batch. Invalid scheduler/checkpoint metadata raises an assertion.
- Reject incompatible checkpoint intervals, TBO, and full prefill CUDA graphs at setup. FlashInfer validates safe gates during warmup. BCG keeps linear attention eager; verify uses its separately configured backend.
- Retain Triton fallback for a packed prefill containing only one token, which FlashInfer's current packed-prefill API excludes.

This PR leaves dependency pins unchanged; the current tree already pins FlashInfer 0.7.0.post1.

+def build_flashinfer_kda_checkpoint_plan(
+    forward_batch: ForwardBatch,
+    metadata: ForwardMetadata,

+    """Plan scheduler-generated tracked boundaries, asserting their validity.
+
+    Host track metadata follows build_prefill_track_plan's unaligned-row order.
+    """
+    extend_lens = forward_batch.extend_seq_lens_cpu
+    track_lens = forward_batch.mamba_track_seqlens_cpu
+    prefix_lens = forward_batch.extend_prefix_lens_cpu
+    track_mask = forward_batch.mamba_prefill_track_mask_cpu
+
+    checkpoint_counts = [length // chunk_size for length in extend_lens]
+    checkpoint_starts = list(accumulate(checkpoint_counts, initial=0))
+    # NOTE(kpham-sgl): FlashInfer GDN writes all periodic checkpoints for SGLang
+    # to select from; FlashInfer KDA writes only mapped destinations (-1 skips).
+    checkpoint_destinations = [-1] * checkpoint_starts[-1]
+    num_tracked_checkpoints = 0
+    for row, tracked in enumerate(track_mask):
+        if not tracked:
