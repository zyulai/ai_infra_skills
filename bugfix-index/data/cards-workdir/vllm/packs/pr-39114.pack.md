## 正文(PR 描述)

## Purpose
Fix https://github.com/vllm-project/vllm/issues/39089

Root cause: _parse_gemma4_value() misidentified partial literals as bare strings, causing a type change (string → boolean) that corrupted the streamed JSON.

## Test Plan
Unit tests
```
pytest tests/tool_parsers/test_gemma4_tool_parser.py -v
```
Manual repro
  Before fix: streaming chunks produce "search_all": "trutrue (corrupted)
  After fix: streaming chunks produce "search_all": true (correct boolean)
