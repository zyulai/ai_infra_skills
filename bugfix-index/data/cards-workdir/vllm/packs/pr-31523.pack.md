## Purpose
This PR fix the accuracy issue introduced from https://github.com/vllm-project/vllm/pull/31221, which caused all the model with MOE structure have serious accuracy regression when shared experts fusion enabled. This PR add `+grouped_topk` into custom_ops to make the dispatch actually happens.
