Supersedes #49377, which GitHub closed when its base branch (#49370's head) was deleted after #49370 merged. The same five commits, rebased onto main, then a merge of main (#49382's shared symmetric workspace) and a sixth commit that fixes how ring_simple splits the tensor over channels; the earlier review and discussion are on #49377.

## Motivation

On gfx1250, carv2's 2shot_push sends almost the whole tensor across the fabric twice, and the per-vector kernel waits after every scoped store. Above a few MB it loses to RCCL, so large all-reduces (prefill chunks, large-batch decode) fell back to RCCL. This PR adds two gfx1250-only paths so carv2 can take every size up to 4 GB at TP2-8, and tunes the size table for both kernel-argument modes, `HIP_FORCE_DEV_KERNARG=0` (the default) and `=1`.

The `=0` table's TP8 row is validated in serving on node C. The `=1` table's TP2, TP4 and TP8 rows are validated in serving on node A, and its TP8 row again on node B at the final head (three 8-GPU gfx1250 nodes). The other rows come from standalone runs plus the skew-tuned 64 KB 1shot_push limit.

## Modifications

- **`ring_simple`**, a ring all-reduce. One channel per CU (256 threads, unroll 32) pushes 2 MB slices through a two-slot FIFO in the next rank's memory, behind 64-bit ready/drained counters. The FIFO and its counters live in an uncached symmetric buffer of their own (`SymmetricBuffer` from #49382, as the hier planes do), allocated only where the table selects `ring_simple`: 4 MB per channel, one channel per CU the device reports. The ring keeps the partitions of each accelerator next to each other (seventh commit): they share its links to the other accelerators, so with them apart every hop leaves an accelerator and the ring runs 1.5-1.8x slower from 64 MB. Like `hier_2shot_push` in `DpxHierAllReduce`, it stays out of the abstraction every platform shares:
  - `RingSimpleAllReduce` (`ring_simple_all_reduce.py`) owns the ring's plan, its buffer, its plane and the all-reduce.
  - The plane is its own FFI object: `RingPlaneObj` and its registration live in `csrc/distributed/ring_simple.cuh`, and `ops/communication/ring_simple.py` registers `RingPlane` through its own JIT module. The kernel takes the ring plane, not the communicator.
  - `CustomAllReduceV2` marks the choice with `AllReduceConfig.use_ring`, as it does `use_hier`; there is no `AllReduceAlgo` for it.
  - `AllReduceAlgo`, `CommunicatorObj`, `communicator.cuh`, `registry.cuh` and `all_reduce.py` are unchanged from the base, and `custom_all_reduce.cuh` keeps the four common algorithms.
  - Each channel's share of the tensor is a whole number of warp hunks per chunk (world size x 32 lanes x 32 packs; sixth commit). An even split over channels left most chunks with a partial hunk, which ran as extra passes of the one-pack path, each costing about as much as a full pass. At TP8 every size that is not a multiple of 12 MB paid for it: 40 MB took 278 us, 48 MB 185 us. Now only the last active channel can get a partial hunk.
- **Unrolled `2shot_push`**, which keeps the slots, Lamport markers, single-word push epoch (#49365), and fp32 rank order of the per-vector kernel. A warp issues a whole hunk of loads before using any of them, and writes peer payload with batched stores. It runs at world size <= 8, from 1 MB at TP8, 2 MB at TP5-7, and 8 MB at TP2-4. Below that, and at TP16, the per-vector kernel stays faster. It is gfx1250's implementation of `2shot_push`, not another algorithm, so it lives in `csrc/distributed/two_shot_push_unrolled.cuh`. `custom_all_reduce.cuh` includes that header on ROCm and picks the kernel by size, so the hier cross stage and forced-`2shot_push` tests use it too.
- **Memory accesses on gfx1250**, for every push kernel, the hier_2shot_push pair stages, and the ring:
  - All of it is uncached symmetric memory: the push slots, pull buffer and semaphores in the shared workspace, the hier planes and the ring FIFO in buffers of their own.
  - Payload loads (Lamport polls, ring FIFO reads) are the existing `ld_relaxed_16B`: `global_load_b128` at device scope (`scope:SCOPE_DEV`), which no CU cache serves stale. An agent fence before each CU-scope poll was the alternative, and it cost up to 5x.
  - Payload stores to peers are the existing `st_relaxed_16B` (system scope), and marker resets in this rank's own slots are `st_global_16B`. The shared 1shot/2shot kernel and the pair stages keep the base accesses unchanged.
  - The unrolled 2shot_push and the ring write long runs to a peer with one new helper, `st_relaxed_run_16B`. It issues eight system-scope `global_store_b128`s, then one `s_wait_xcnt`. The builtin store makes the compiler wait after every store on gfx1250, and that costs these kernels 4-19% from 1 MB to 256 MB. On other targets it is a loop of `st_relaxed_16B`.
  - Input and output use plain loads and stores, so they stay cacheable. Synchronization flags (ring counters, pull semaphores) keep their scoped acquire/release accesses.
  - No cache hints: non-temporal payload loads and stores were measured, with no gain (see below).
- **gfx1250 size tables, TP2-8**: 1shot_push, then 2shot_push, then ring_simple up to 4 GB, with no RCCL window in between. `get_all_reduce_config` picks the table from `HIP_FORCE_DEV_KERNARG`; only an explicit `1` selects the second one.

  | world size | `=0` (default) 1shot / 2shot / ring | `=1` 1shot / 2shot / ring |
  |---|---|---|
  | 2 | <= 64 KB / <= 8 MB / > 8 MB | <= 2 MB / <= 16 MB / > 16 MB |
  | 3, 5 | <= 64 KB / <= 8 MB / > 8 MB | same as `=0` |
  | 4 | <= 64 KB / <= 16 MB / > 16 MB | <= 2 MB / <= 32 MB / > 32 MB |
  | 6, 7 | <= 64 KB / <= 16 MB / > 16 MB | same as `=0` |
  | 8 | <= 64 KB / <= 8 MB / > 8 MB | <= 768 KB / <= 32 MB / > 32 MB |

  The `=0` cutoffs are the last size at which each algorithm was fastest back to back on one host, with two serving-driven exceptions:
  - 1shot_push stops at 64 KB. At TP8 on node C, a 256 KB cutoff cost 18% of DeepSeek-V4-Flash's C16 decode throughput (second commit). This limit has not been re-measured on the current kernels under `=0`.
  - At TP8, 2shot_push wins back to back up to 32 MB, but in serving it halved prefill throughput on the 16 MB prefill all-reduces: every rank stalled about 2 ms in the kernels after it. ring_simple at those sizes causes no stall.

  **Why two tables.** The TP8 prefill stall needs kernel arguments in host memory:
  - In a quant-after-all-reduce reproducer, the first launches of the fp8 quant kernel after a 2shot_push took about 2 ms under `=0`. Under `=1` they took about 51 us, its normal time.
  - Serving the same table on node A (TP8, 2shot_push up to 16 MB), 1k/1k C256 output was 4,844-4,999 tok/s under `=0` (four runs) and 7,187-7,249 tok/s under `=1` (three runs).

  So `=0` must keep 16 MB off 2shot_push at TP8, while `=1` can run 2shot_push to its back-to-back limit. The `=1` table was then tuned and served on its own (third commit):
  - 2shot_push runs to the last size it wins back to back.
  - 1shot_push runs to the last decode size it wins in CUDA graphs, back to back, with a late rank, and after a GEMM: 768 KB at TP8, and 2 MB (the largest DeepSeek-V4-Flash decode all-reduce) at TP2 and TP4.

  The TP16 row keeps hier_2shot_push for 256 KB-64 MB, and ring_simple takes the sizes above that. Its push grid takes every CU the device reports (eighth commit; it was capped at a fixed count).
- Tests: a ring_simple case and a small-FIFO ring sweep in `test_custom_all_reduce.py`. Table tests check, for both tables, that each world size picks the measured winner on both sides of every cutoff, and that no 16 B-aligned size up to 4 GB falls back to RCCL.

+template <typename T, uint32_t kWorldSize, bool kUsePDL>
+__global__ __launch_bounds__(kRingSimpleThreads, 1) __attribute__((
+    amdgpu_waves_per_eu(1, 2))) void all_reduce_ring_simple_kernel(const __grid_constant__ Params params) {
+  using namespace device;
+  constexpr uint32_t kVecSize = 16 / (sizeof(T) * 2);
+  constexpr uint32_t kNumPackets = 2 * (kWorldSize - 1);
+  constexpr uint32_t kWarpVecs = kWarpThreads * kRingSimpleUnroll;
+  using vec_t = AlignedVector<packed_t<T>, kVecSize>;
+  const auto& ws = params.ws;
+  const auto r = params.rank;
+  const auto num_vecs = params.num_vecs;
+  const auto ch = blockIdx.x;
+  const auto num_channels = gridDim.x;
+  const auto lane_id = threadIdx.x % kWarpThreads;
+  const auto warp_id = threadIdx.x / kWarpThreads;
+  const auto num_warps = blockDim.x / kWarpThreads;
+  const auto slot_mask = ws.num_slots - 1;
+  const auto slot_vecs = ws.slot_bytes / 16;
+  const auto fifo_offset = ch * ws.num_slots * ws.slot_bytes;
+  const auto recv_fifo = ws.recv + fifo_offset;
+  const auto send_fifo = ws.send + fifo_offset;
+  auto& sem = ws.credits[ch];
+  auto& prev_sem = ws.prev_credits[ch];
+  auto& next_sem = ws.next_credits[ch];
+  const auto slot_of = [&](uint8_t* fifo, uint64_t p) { return fifo + (p & slot_mask) * ws.slot_bytes; };
+
+  PDLWaitPrimary<kUsePDL>();
+  uint64_t packet = sem.packet;
+  // polled by thread 0 only; the barrier after each wait publishes the result
+  uint64_t ready = 0, drained = 0;
+  const auto wait_until = [&](uint64_t& seen, const uint64_t* ptr, uint64_t target) {
+    while (seen < target) {
+      seen = load_acquire_sys(ptr);
+      if (seen < target) __builtin_amdgcn_s_sleep(1);
+    }
+  };
+  // Packet p may be received once the predecessor published it, and sent
+  // once the successor drained the packet that last held its slot.
+  const auto wait = [&](bool recv, uint64_t recv_p, bool send, uint64_t send_p) {
+    if (threadIdx.x == 0) {
+      if (recv) wait_until(ready, &sem.ready, recv_p + 1);
+      if (send && send_p >= ws.num_slots) wait_until(drained, &sem.drained, send_p + 1 - ws.num_slots);
+    }
+    __syncthreads();
+  };
+  // Once every wave's stores (and so the loads feeding them) completed: tell
+  // the predecessor `recv_p` is drained and the successor `send_p` is ready.
+  const auto post = [&](bool recv, uint64_t recv_p, bool send, uint64_t send_p) {
+    wait_stores_sys();
+    __syncthreads();
+    if (threadIdx.x == 0) {
+      if (recv) ptx::store_relaxed_sys(&prev_sem.drained, recv_p + 1);
+      if (send) ptx::store_relaxed_sys(&next_sem.ready, send_p + 1);
+    }
+  };
+  // One slice: warps take contiguous
+  // hunks of kWarpVecs, each lane a pack per kWarpThreads vectors, so a lane
+  // has kRingSimpleUnroll loads per source in flight. Only whole hunks take the
+  // unrolled path: a bounds check per pack splits it into branches the
+  // compiler fences with a full load wait each, serializing the loads.
+  const auto copy_packs =
+      [&](auto unroll, auto mode, const uint8_t* recv_slot, uint8_t* send_slot, uint32_t start, uint32_t j) {
+        constexpr uint32_t kUnroll = decltype(unroll)::value;
+        constexpr uint32_t kStride = kUnroll == 1 ? 1 : kWarpThreads;
+        constexpr bool kRecv = decltype(mode)::kRecv, kReduce = decltype(mode)::kReduce;
+        constexpr bool kStoreOut = decltype(mode)::kStoreOut, kSend = decltype(mode)::kSend;
+        // Per-lane base pointers with constant pack offsets, which fold into the
+        // instructions' immediate offsets: an index recomputed per pack reuses
+        // its VGPR, and each store then waits (s_wait_xcnt) for the last to read it.
+        const auto in = static_cast<const vec_t*>(params.input) + start + j;
+        const auto out = static_cast<vec_t*>(params.output) + start + j;
+        const auto send_at = reinterpret_cast<vec_t*>(send_slot) + j;
+        vec_t vecs[kUnroll];
+        vec_t inputs[kUnroll];
+    // every pack of the local input, then every pack of the FIFO
+#pragma unroll
+        for (uint32_t u = 0; u < kUnroll; ++u) {
+          if constexpr (!kRecv || kReduce) inputs[u] = in[u * kStride];
+        }
+#pragma unroll
+        for (uint32_t u = 0; u < kUnroll; ++u) {
+          if constexpr (kRecv) ptx::ld_relaxed_16B(vecs[u], recv_slot, j + u * kStride);
+        }
+        // keep every load ahead of the first use: left alone, the scheduler pulls
+        // each reduction up behind its two loads and waits there, to save registers
+        __builtin_amdgcn_sched_barrier(0);
+    // results land in `vecs`; then the stores, one destination at a time
+#pragma unroll
+        for (uint32_t u = 0; u < kUnroll; ++u) {
+          if constexpr (kRecv && kReduce) {
+            vec_t pair[2];
+            pair[0] = vecs[u];
+            pair[1] = inputs[u];
+            vecs[u] = reduce_vec(pair);
+          } else if constexpr (!kRecv) {
+            vecs[u] = inputs[u];
+          }
+        }
+        if constexpr (kStoreOut) {
+#pragma unroll
+          for (uint32_t u = 0; u < kUnroll; ++u)
+            out[u * kStride] = vecs[u];
+        }
+        if constexpr (kSend) {
+          if constexpr (kUnroll % 8 == 0) {
+            ptx::st_relaxed_run_16B<kStride, kUnroll>(vecs, send_at);
+          } else {
+#pragma unroll
+            for (uint32_t u = 0; u < kUnroll; ++u)
+              ptx::st_relaxed_16B(vecs[u], send_at, u * kStride);
+          }
+        }
+      };
+  const auto copy = [&](auto mode, const uint8_t* recv_slot, uint8_t* send_slot, uint32_t start, uint32_t n) {
+    const auto full = n / kWarpVecs * kWarpVecs;
+    for (uint32_t base = warp_id * kWarpVecs; base < full; base += num_warps * kWarpVecs) {
+      copy_packs(
+          std::integral_constant<uint32_t, kRingSimpleUnroll>{}, mode, recv_slot, send_slot, start, base + lane_id);
+    }
+    for (uint32_t j = full + threadIdx.x; j < n; j += blockDim.x) {
+      copy_packs(std::integral_constant<uint32_t, 1>{}, mode, recv_slot, send_slot, start, j);
+    }
+  };
+
+  // each channel takes a contiguous share of the tensor, then loops over it in
+  // kWorldSize chunks of at most one slot. Shares are whole hunks per chunk:
+  // a partial hunk runs as passes of the one-pack path, each costing about as
+  // much as a full pass, so the last channels may get less or nothing instead.
+  constexpr uint32_t kShareVecs = kWorldSize * kWarpVecs;
+  const auto channel_vecs = div_ceil(div_ceil(num_vecs, num_channels), kShareVecs) * kShareVecs;
+  const auto channel_start = min(ch * channel_vecs, num_vecs);
+  const auto channel_len = min(channel_vecs, num_vecs - channel_start);
+  const auto loop_vecs = kWorldSize * slot_vecs;
+  for (uint32_t base = 0; base < channel_len; base += loop_vecs) {
+    const auto len = min(loop_vecs, channel_len - base);
+    const auto chunk_vecs = div_ceil(len, kWorldSize);
+    const auto chunk_start = [&](uint32_t c) { return channel_start + base + c * chunk_vecs; };
+    const auto chunk_len = [&](uint32_t c) { return min(chunk_vecs, len - min(len, c * chunk_vecs)); };
+
+    // first hop: this rank's own chunk
+    wait(false, 0, true, packet);
+    copy(RingHop<false, false, false, true>{}, nullptr, slot_of(send_fifo, packet), chunk_start(r), chunk_len(r));
+    post(false, 0, true, packet);
+
+    // hop q receives chunk r - 1 - q: a partial for q < kWorldSize - 1, which
+    // this rank completes at q = kWorldSize - 2, then a reduced chunk
+    for (uint32_t q = 0; q < kNumPackets; ++q, ++packet) {
+      const bool forward = q + 1 < kNumPackets;
+      const auto c = (r + 2 * kWorldSize - 1 - q) % kWorldSize;
+      const auto recv_slot = slot_of(recv_fifo, packet);
+      const auto send_slot = slot_of(send_fifo, packet + 1);
+      const auto start = chunk_start(c);
+      const auto n = chunk_len(c);
+      wait(true, packet, forward, packet + 1);
+      if (q + 2 < kWorldSize) {
+        copy(RingHop<true, true, false, true>{}, recv_slot, send_slot, start, n);
+      } else if (q + 2 == kWorldSize) {
+        copy(RingHop<true, true, true, true>{}, recv_slot, send_slot, start, n);
+      } else if (forward) {
+        copy(RingHop<true, false, true, true>{}, recv_slot, send_slot, start, n);
+      } else {
+        copy(RingHop<true, false, true, false>{}, recv_slot, send_slot, start, n);
+      }
+      post(true, packet, forward, packet + 1);
+    }
+  }
+
+  PDLTriggerSecondary<kUsePDL>();
+  if (threadIdx.x == 0) sem.packet = packet;
+}

+/**
+ * \brief Ring plane: symmetric FIFOs per rank plus one semaphore per ring.
+ *
+ * Each block of the launch runs one ring (channel), so each rank holds
+ * `[num_rings][num_slots][slot_bytes]`: ring i of the predecessor streams
+ * packets into slot `packet % num_slots` of row i. The counters in the
+ * semaphores persist across launches, so the semaphores MUST be zero-filled
+ * before first use.
+ *
+ * Holds no storage: the caller (Python) owns the tensors and their lifetime.
+ * Everything is inline: the registration module and every kernel module are
+ * separate shared objects that only share this header.
+ */
+struct RingPlaneObj : public tvm::ffi::Object {
+  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("sgl.distributed.RingPlane", RingPlaneObj, tvm::ffi::Object);
+
+  RingPlaneObj(
+      uint32_t rank,
+      uint32_t world_size,
+      std::vector<tvm::ffi::TensorView> workspaces,  // world_size * [num_rings][num_slots][slot_bytes]
+      std::vector<tvm::ffi::TensorView> semaphores)  // world_size * [num_rings][sizeof(RingSemaphore)]
+      : rank(rank), world_size(world_size), num_rings(), num_slots(), slot_bytes(), semaphores{}, workspaces{} {
+    CHECK_HOST(1 < world_size && world_size <= kMaxWorldSize) << "Invalid world size: " << world_size;
+    CHECK_HOST(rank < world_size) << "Invalid rank " << rank << " for world size " << world_size;
+    CHECK_HOST(workspaces.size() == world_size) << "Bad ring workspace count";
+    CHECK_HOST(semaphores.size() == world_size) << "Bad ring semaphore count";
+    auto R = SymbolicSize{"num_rings"};
+    auto S = SymbolicSize{"num_slots"};
+    auto N = SymbolicSize{"slot_bytes"};
+    auto device_sym = SymbolicDevice{};
+    device_sym.set_options<kDLGPU>();
+    for (uint32_t i = 0; i < world_size; ++i) {
+      TensorMatcher({R, S, N})  //
+          .with_dtype<uint8_t>()
+          .with_device(device_sym)
+          .verify(workspaces[i]);
+      TensorMatcher({R, static_cast<int64_t>(sizeof(ring_simple::RingSemaphore))})  //
+          .with_dtype<uint8_t>()
+          .with_device(device_sym)
+          .verify(semaphores[i]);
+    }
+    const auto rings = R.unwrap(), slots = S.unwrap(), bytes = N.unwrap();
+    CHECK_HOST(rings > 0 && bytes > 0 && bytes % 16 == 0) << "Bad ring slot: " << rings << " x " << bytes;
+    CHECK_HOST(slots >= 2 && (slots & (slots - 1)) == 0) << "Ring slot count must be a power of two >= 2: " << slots;
+    // the kernel forms FIFO offsets in 32 bits
+    CHECK_HOST(rings * slots * bytes <= std::numeric_limits<uint32_t>::max())
+        << rings * slots * bytes << " bytes of ring FIFO exceeds the 32-bit offset range";
+
+    this->num_rings = static_cast<uint32_t>(rings);
+    this->num_slots = static_cast<uint32_t>(slots);
+    this->slot_bytes = bytes;
+    for (uint32_t i = 0; i < world_size; ++i) {
+      this->semaphores[i] = static_cast<ring_simple::RingSemaphore*>(semaphores[i].data_ptr());
+      this->workspaces[i] = static_cast<uint8_t*>(workspaces[i].data_ptr());
+    }
+  }
+
+  uint32_t rank;
+  uint32_t world_size;
+  uint32_t num_rings;                                                 // one per block of the launch
+  uint32_t num_slots;                                                 // FIFO depth per ring, a power of two
+  int64_t slot_bytes;                                                 // one packet
+  std::array<ring_simple::RingSemaphore*, kMaxWorldSize> semaphores;  // symmetric memory
+  std::array<uint8_t*, kMaxWorldSize> workspaces;                     // symmetric memory
+
+  ring_simple::RingWorkSpace get_workspace() const {
+    const auto next = (rank + 1) % world_size;
+    const auto prev = (rank + world_size - 1) % world_size;
+    return ring_simple::RingWorkSpace{
+        workspaces[rank],
+        workspaces[next],
+        semaphores[rank],
+        semaphores[prev],
+        semaphores[next],
+        static_cast<uint32_t>(slot_bytes),
+        num_slots,
+    };
+  }
+};

+  using Tensor = tvm::ffi::Tensor;

+  /// All-reduce `in` over the ring plane, one ring per block.
+  static Tensor run(const host::distributed::RingPlaneRef ring_ref, const Tensor in) {
+    using namespace host;
+    const auto& ring = *ring_ref.get();
+    CHECK_HOST(ring.world_size == kWorldSize) << ring.world_size;
+    CHECK_HOST(in.IsContiguous() && is_type<T>(in.dtype()) && in.device().device_type == kDLGPU);
+    const auto num_elems = in.numel();
+    const auto nbytes = static_cast<int64_t>(num_elems * sizeof(T));
+    CHECK_HOST(reinterpret_cast<intptr_t>(in.data_ptr()) % 16 == 0 && nbytes % 16 == 0);
+    const auto num_vecs = static_cast<uint32_t>(nbytes / 16);
+    CHECK_HOST(int64_t{num_vecs} * 16 == nbytes) << nbytes;
+
+    Tensor out = ffi::empty_like(in);
+    const auto params = ring_simple::Params{
+        .input = in.data_ptr(),
+        .output = out.data_ptr(),
+        .num_vecs = num_vecs,
+        .rank = ring.rank,
+        .ws = ring.get_workspace(),
+    };
+    const auto stream = LaunchKernel::resolve_device(in.device());
+    LaunchKernel(ring.num_rings, ring_simple::kRingSimpleThreads, stream)  //
+        .enable_pdl(kUsePDL)(ring_simple::all_reduce_ring_simple_kernel<T, kWorldSize, kUsePDL>, params);
+    return out;
+  }
+};

+// ROCm: the same algorithm as `all_reduce_2shot_push_kernel` with a deeper memory
+// pipeline. `AllReduceKernel` picks it by size.
+#pragma once

+#include <sgl_kernel/type.cuh>
+#include <sgl_kernel/utils.cuh>

+/// Threads per unrolled 2shot_push block, and 16-byte packs each lane keeps in
+/// flight in its scatter and gather phases. The reduce phase holds a pack from
+/// every rank per unroll step, so it unrolls less as the world grows.
+inline constexpr uint32_t kTwoShotPushThreads = 256;
+inline constexpr uint32_t kTwoShotPushUnroll = 8;
+template <uint32_t kWorldSize>
+inline constexpr uint32_t kTwoShotPushReduceUnroll = kWorldSize <= 4 ? 8 : 4;
+/// Below these sizes the per-vector kernel wins: one vector per thread spreads a
+/// chunk over more warps than whole hunks do (TP2/TP4 unrolled are 10-14% slower
+/// at 128 KB - 1 MB), and with one rank arriving late TP2/TP4 stay 3-10% slower
+/// up to 4 MB.
+template <uint32_t kWorldSize>
+inline constexpr int64_t kTwoShotPushUnrolledMinBytes =
+    int64_t{
+        kWorldSize <= 4  ? 8
+        : kWorldSize < 8 ? 2
+                         : 1}
+    << 20;
+
+/// `all_reduce_2shot_push_kernel` with the ring_simple memory pipeline: same
+/// slots, markers and epochs, but warps take contiguous hunks of
+/// `kWarpThreads * unroll` vectors and issue every load of a hunk before using
+/// any, and slot payload moves as device-scope loads and batched system-scope
+/// stores while the input and output take plain accesses. The
+/// tail past the last whole hunk takes the per-vector path. Single node only
+/// (at most 8 ranks).
+template <typename T, uint32_t kWorldSize, bool kUsePDL, typename Params>
+__global__ __launch_bounds__(kTwoShotPushThreads, 1) __attribute__((
+    amdgpu_waves_per_eu(1, 2))) void all_reduce_2shot_push_unrolled_kernel(const __grid_constant__ Params params) {
+  using namespace device;
+  constexpr uint32_t kVecSize = 16 / (sizeof(T) * 2);
+  constexpr uint32_t kFan = kWorldSize - 1;
+  constexpr uint32_t kUnroll = kTwoShotPushUnroll;
+  constexpr uint32_t kReduceUnroll = kTwoShotPushReduceUnroll<kWorldSize>;
+  constexpr uint32_t kHunk = kWarpThreads * kUnroll;
+  constexpr uint32_t kReduceHunk = kWarpThreads * kReduceUnroll;
+  using vec_t = AlignedVector<packed_t<T>, kVecSize>;
+  using Lamport = distributed::LamportTrait<T, kVecSize * 2, /*kAtom=*/4>;
+  const auto r = params.rank;
+  const auto num_vecs = params.num_vecs;
+  const auto chunk_vecs = div_ceil(num_vecs, kWorldSize);
+  const auto get_chunk_len = [&](uint32_t c) {  //
+    return min(chunk_vecs, num_vecs - min(num_vecs, c * chunk_vecs));
+  };
+  const auto input = static_cast<const vec_t*>(params.input);
+  const auto output = static_cast<vec_t*>(params.output);
+  const auto num_threads = blockDim.x * gridDim.x;
+  const auto num_warps = num_threads / kWarpThreads;
+  const auto warp_in_block = threadIdx.x / kWarpThreads;
+  const auto lane_id = threadIdx.x % kWarpThreads;
+  const auto global_warp_id = blockIdx.x + gridDim.x * warp_in_block;
+  const auto global_tid = global_warp_id * kWarpThreads + lane_id;
+
+  // peer will cover 0..kWorldSize - 1, except for local rank `r`
+  const auto peer = (r + 1 + global_warp_id % kFan) % kWorldSize;
+  const auto group_warp = global_warp_id / kFan;
+  const auto group_warps = num_warps / kFan + (global_warp_id % kFan < num_warps % kFan ? 1 : 0);
+  const auto group_tid = group_warp * kWarpThreads + lane_id;
+  const auto group_stride = group_warps * kWarpThreads;
+  const auto peer_len = get_chunk_len(peer);
+  const auto peer_full = peer_len / kHunk * kHunk;
+
+  PDLWaitPrimary<kUsePDL>();
+  const auto epoch = distributed::PushEpoch<kWorldSize>{params.ws};
+
+  // reduce-scatter: my partial of the peer's chunk to its owner
+  {
+    const auto src = input + peer * chunk_vecs;
+    const auto push_ptr = static_cast<vec_t*>(epoch.slot_ptr(/*dst=*/peer, /*src=*/r));
+    for (uint32_t base = group_warp * kHunk; base < peer_full; base += group_warps * kHunk) {
+      const auto j = base + lane_id;
+      const auto in = src + j;
+      vec_t vecs[kUnroll];
+#pragma unroll
+      for (uint32_t u = 0; u < kUnroll; ++u) {
+        vecs[u] = in[u * kWarpThreads];
+      }
+      __builtin_amdgcn_sched_barrier(0);
+#pragma unroll
+      for (uint32_t u = 0; u < kUnroll; ++u) {
+        Lamport::clear_pos_zero(vecs[u].data());
+      }
+      ptx::st_relaxed_run_16B<kWarpThreads, kUnroll>(vecs, push_ptr + j);
+    }
+    for (auto j = peer_full + group_tid; j < peer_len; j += group_stride) {
+      vec_t vec = src[j];
+      Lamport::clear_pos_zero(vec.data());
+      ptx::st_relaxed_16B(vec, push_ptr, j);
+    }
+  }
+
+  vec_t pos_zero_vec;
+  Lamport::fill_pos_zero(pos_zero_vec.data());
+
+  vec_t* poll_ptrs[kWorldSize];
+#pragma unroll
+  for (uint32_t i = 0; i < kWorldSize; ++i) {
+    poll_ptrs[i] = static_cast<vec_t*>(epoch.slot_ptr(/*dst=*/r, /*src=*/i));
+  }
+
+  // reduce my chunk, keep it and fan it out
+  {
+    const auto my_len = get_chunk_len(r);
+    const auto my_full = my_len / kReduceHunk * kReduceHunk;
+    const auto my_in = input + r * chunk_vecs;
+    const auto my_out = output + r * chunk_vecs;
+    for (uint32_t base = global_warp_id * kReduceHunk; base < my_full; base += num_warps * kReduceHunk) {
+      const auto j = base + lane_id;
+      vec_t vecs[kReduceUnroll][kWorldSize];
+      vec_t mine[kReduceUnroll];
+#pragma unroll
+      for (uint32_t u = 0; u < kReduceUnroll; ++u) {
+        mine[u] = my_in[j + u * kWarpThreads];
+      }
+      // every rank's slot, the unused (r, r) one too, so no branch on r splits
+      // the batch; this rank's own partial is the input, swapped in below
+#pragma unroll
+      for (uint32_t u = 0; u < kReduceUnroll; ++u) {
+#pragma unroll
+        for (uint32_t i = 0; i < kWorldSize; ++i) {
+          ptx::ld_relaxed_16B(vecs[u][i], poll_ptrs[i], j + u * kWarpThreads);
+        }
+      }
+      // A late peer is re-polled alone, with a sleep per spin: re-polling every
+      // rank's packs floods the memory the peers' pushes land in.
+#pragma unroll
