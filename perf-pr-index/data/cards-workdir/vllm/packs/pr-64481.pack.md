## Overview

Adds a measured B200 (SM100) table for the GLM-5.2/5.3 low-latency BF16 decode GEMM; SM100 used cuBLAS. Related: #59822.

## Claims

- 1.14–2.35x over cuBLAS per projection at M ≤ 8.

## Validation

```
pytest tests/kernels/test_bf16_skinny_gemm.py -k "glm or dsv3"   → 84 passed, 180 skipped (B200)
run_glm52_plan vs F.linear, every routed cell (CUPTI, CUDA graph) → 40 cells, all ≥ 1.05x cold and hot L2
```

| projection | (N, K) | routed M | M=1 cuBLAS → table (µs, cold L2) | speedup over routed M |
|---|---|---|---|---|
| q_a + kv_a | (2624, 6144) | 1–4, 6, 8 | 12.00 → 8.48 | 1.21–1.42x |
| q_b TP8 | (2048, 2048) | 1–4, 6, 8 | 6.02 → 4.06 | 1.46–2.00x |
| q_b TP4 / indexer wq_b | (4096, 2048) | 1–4 | 6.94 → 5.76 | 1.15–1.29x |
| o_proj TP8 | (6144, 2048) | 1–2 | 8.03 → 6.91 | 1.14–1.16x |
| indexer wk + weights | (160, 6144) | 1–4, 6, 8 | 6.08 → 2.62 | 1.48–2.35x |
| shared gate_up TP8 | (512, 6144) | 1–4, 6, 8 | 8.00 → 4.26 | 1.37–1.88x |
| shared gate_up TP4 | (1024, 6144) | 1–4, 6, 8 | 9.09 → 5.22 | 1.16–1.74x |
| MTP eh_proj | (6144, 12288) | 1–4 | 37.63 → 26.24 | 1.31–1.43x |

## Details

Cells kept only if ≥ 5 % faster on cold and hot L2; others stay on cuBLAS. No e2e (needs 4–8 B200).
