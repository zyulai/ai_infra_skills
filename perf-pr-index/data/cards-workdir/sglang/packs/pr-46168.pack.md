## Motivation

Layer-wise prefix restoration through the Mooncake direct linker spends host time opening one get session per pool and building range metadata row by row.

## Modifications

- Combine every pool's keys into one `batch_get_session_start` call per load, while retaining main's grouped asynchronous range transfers.
- Prepare keys before the GPU slot fence, then wait before starting the batched get session. This prevents the fence wait from consuming session leases. Location reads and range transfers also happen after the fence.
- End the session for every submitted key in `finally`, including when only some keys started successfully. Mooncake session-end ignores absent keys.
- Build layer pointers with NumPy and share read-only size/offset lists across rows. Copy rows before grouped range assembly extends them, so shared metadata is not mutated.
