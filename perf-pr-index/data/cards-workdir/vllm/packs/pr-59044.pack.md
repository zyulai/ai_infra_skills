## Purpose

Avoid computing with padding in the Blackwell FP4 DeepGEMM MoEs layers. Currently we are doing so in both GEMMs and activations.  This mainly affects the decoder when running DeepEPv2+ DeepGEMM. This PR updates the grouped GEMMs to use DeepGEMM's prefix-sum scheduler, and changes the packed SiLU+mul+FP8-quantization kernel to use those endpoints to process only live rows.

Each endpoint is the aligned expert start plus its actual token count; the next expert starts at the preceding endpoint rounded up to the GEMM alignment. No count readback, additional launch, or DeepGEMM source change is required. Activation workspaces keep their allocated capacity. The per-row layout metadata shrinks from 112 KiB to 128 bytes for 32 local experts and 28,672 allocated rows.

The quantization metadata is optional. Calls without it retain the original dense launch configuration, and the metadata loads compile out. SM120 and FP8 expert callers retain their existing path. Padding outputs are left unwritten; the down GEMM uses the same bounds to identify live rows. `mk_alignment_scope` and `ensure_zero_padding=True` remain in place.

The new activation masking also differs from #51332/#51217 (shared masked activation/Humming paths) and #53911 (Humming indexed metadata preparation): `DeepGemmFP4Experts` directly calls the packed-UE8M0 fused activation kernel. Those changes do not pass this caller's expert endpoints into that kernel. Open-PR searches for DeepGEMM prefix sums and SiLU padding found no implementation of this change. No associated issue is being closed.

## Test Result

| Measurement | Prefix sums only | + activation masking |
|---|---:|---:|
| Full FFN, unprofiled | 425.5 µs | 385.7 µs |
| SiLU+mul+quant, separately profiled | 76.0 µs | 20.7 µs |
| Standalone quantization: 3,072 live / 28,672 allocated rows, hidden 2,048 | 63.984 µs | 10.510 µs |

Full FFN latency fell 9.36% (1.103× speedup); outputs match bit for bit on all eight ranks, including eager versus graph execution. Both projections used prefix sums in both variants; only the masked variant supplied expert bounds to activation. The median profiled activation saving is larger than the FFN saving because ranks carry different amounts of expert work and meet again at combine. Main activation workspaces are unchanged.

**Dense-path control:** calls without metadata preserve the original launch and differed by 0.20% faster to 0.39% slower across ten controls in the corrected rerun. At 28,672×2,048, the old and new dense paths measured 64.082 and 64.020 µs; at 28,672×7,168, 217.796 and 217.814 µs. No extra kernel or GPU-to-host count synchronization is introduced.

Supplying metadata for an already full buffer does have a small checking/scheduling cost in some shapes: 64.082→64.822 µs for the fully populated 28,672×2,048 case, and approximately 0.15–0.32 µs for the tested smaller group-128 cases. The ordinary dense path does not pay this cost. The 28,672×7,168 metadata-aware case improved from 217.796 to 212.236 µs. The benchmark includes these full-buffer cases rather than measuring padded buffers alone.

Save the following script as `benchmark.py`. It replays all three captured graphs and synchronizes before checking live FP8 values and packed scales. This fixes the pre-replay comparison of uninitialized captured scale tensors.

```python
# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: Copyright contributors to the vLLM project

"""Compare dense and expert-aware packed quantization with CUDA graph timing."""

import argparse
import importlib.util
import json
import statistics
from pathlib import Path

import torch

from vllm.model_executor.layers.quantization.utils.fp8_utils import (
    silu_mul_quant_fp8_packed_triton,
)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--baseline", type=Path, required=True)
    parser.add_argument("--output", type=Path, required=True)
    args = parser.parse_args()
    spec = importlib.util.spec_from_file_location("baseline", args.baseline)
    assert spec is not None and spec.loader is not None
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    baseline = module.silu_mul_quant_fp8_packed_triton
    warmups, iterations, graph_calls = 5, 25, 16
    results = []
    torch.manual_seed(0)
    cases = [
        (128, 1, 128, 256, 128),
        (512, 4, 128, 2048, 128),
        (4096, 32, 128, 2048, 128),
        (28672, 32, 896, 2048, 128),
        (28672, 32, 96, 2048, 128),
        (28672, 32, 1, 2048, 128),
        (28672, 32, 0, 2048, 128),
        (28672, 32, 896, 7168, 128),
        (28672, 32, 96, 7168, 128),
        (4096, 32, 128, 2048, 32),
    ]
    for capacity, experts, live_per_expert, hidden, group in cases:
        x = torch.randn((capacity, hidden * 2), device="cuda", dtype=torch.bfloat16)
        starts = torch.arange(experts, device="cuda", dtype=torch.int32)
        starts *= ((live_per_expert + 127) // 128) * 128
        ends = starts + live_per_expert
        graphs = {}
        for name, fn, kwargs in [
            ("baseline", baseline, {}),
            ("dense", silu_mul_quant_fp8_packed_triton, {}),
            (
                "expert",
                silu_mul_quant_fp8_packed_triton,
                {"expert_ends": ends, "expert_alignment": 128},
            ),
        ]:
            output = torch.empty(
                (capacity, hidden), device="cuda", dtype=torch.float8_e4m3fn
            )

            def invoke(fn=fn, output=output, kwargs=kwargs, x=x, group=group):
                return fn(
                    x, group_size=group, output_q=output, clamp_limit=10.0, **kwargs
                )

            for _ in range(warmups):
                invoke()
            torch.accelerator.synchronize()
            graph = torch.cuda.CUDAGraph()
            with torch.cuda.graph(graph):
                for _ in range(graph_calls):
                    q, s = invoke()
            graphs[name] = (graph, q, s)

        for graph, _, _ in graphs.values():
            graph.replay()
        torch.accelerator.synchronize()

        live = torch.zeros(capacity, device="cuda", dtype=torch.bool)
        for start in starts.tolist():
            live[start : start + live_per_expert] = True
        for name in ("dense", "expert"):
            torch.testing.assert_close(
                graphs[name][1].view(torch.uint8)[live],
                graphs["baseline"][1].view(torch.uint8)[live],
                rtol=0,
                atol=0,
            )
            torch.testing.assert_close(
                graphs[name][2][live], graphs["baseline"][2][live], rtol=0, atol=0
            )
        samples = {name: [] for name in graphs}
        for iteration in range(iterations):
            order = list(graphs)
            if iteration % 2:
                order.reverse()
            for name in order:
                begin, end = (torch.cuda.Event(enable_timing=True) for _ in range(2))
                begin.record()
                graphs[name][0].replay()
                end.record()
                end.synchronize()
                samples[name].append(begin.elapsed_time(end) * 1000 / graph_calls)
        result = dict(
            capacity=capacity,
            experts=experts,
            live_rows=experts * live_per_expert,
            hidden=hidden,
            group_size=group,
            samples_us=samples,
            median_us={k: statistics.median(v) for k, v in samples.items()},
        )
        results.append(result)
        print(json.dumps(result), flush=True)
    args.output.write_text(
        json.dumps(
            {
                "gpu": torch.cuda.get_device_name(),
                "warmups": warmups,
                "iterations": iterations,
                "graph_calls": graph_calls,
                "results": results,
            },
            indent=2,
        )
        + "\n"
    )


if __name__ == "__main__":
    main()
```
