## Motivation

Fix hanging issue (AllGather size mismatch) in EAGLE speculative decoding (both V1 and V2) when running with TP>1 and non-greedy sampling. (https://github.com/sgl-project/sglang/issues/22276)

The actual root cause chain is:
same `next_token_logits` in non-greedy sampling branch
→ `softmax`/`top_k_renorm_prob`/`top_p_renorm_prob` produces slightly different `target_probs` across GPUs due to floating-point non-determinism 
→ `tree_speculative_sampling_target_only` samples different accepted token values 
→ divergent `output_ids` inserted into radix cache → different prefix match lengths on subsequent requests 
→ different `extend_seq_lens` and `num_seqs` → different AllGather sizes in LogitsProcessor → hang

## Modifications

 broadcast predict from rank 0 after the sampling kernel to ensure all TP ranks have identical accepted token values
