## Motivation

page_unified load-back always selected the two-CTA register-copy kernel, even when legacy page_first transfers used TMA. Reuse the existing TMA staging pipeline for MHA head groups and MLA, with page-aware addressing and chunk sizes that respect page boundaries. Retain the register fallback when TMA is disabled, unsupported, or a group row exceeds a staging slot. Adds TMA support for page_unified HiCache load-back on SM90+, covering MHA and MLA while preserving the existing fallback. On B200, load-back improves from 18.0 to 51.0 GB/s (2.84× faster), matching legacy performance.
