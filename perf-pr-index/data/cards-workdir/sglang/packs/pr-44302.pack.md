## PR body
```markdown
## Motivation

The change makes AMD use one fused packing kernel for this model’s QKVZ/BA outputs, replacing the separate copy-and-concatenate path. It changes how the tensors are prepared, while preserving their values.

## Modifications

This model has 16 key heads and 48 value heads, so its head ratio is 3. The patch adds that ratio to AMD’s supported list.

## Accuracy Tests
All four end-to-end performance runs completed 80 measured requests with zero errors or cancellations.

Full AgentX GSM8K accuracy evaluation of patch commit `ff27193485` passed the supplied InferenceX score validator: **97.50% strict-match and flexible-extract (1286/1319)**, against the default **90%** threshold.

## Speed Tests and Profiling

Compared fresh `origin/main` at `bab9c81fea` against the same base plus this patch on one AMD Instinct MI355X, TP=1. Two unprofiled runs per revision, with a server restart between revisions and a cache flush plus 16 warmup requests before each 80-request measurement.

Workload: Qwen3.8-Flash-Next-Quark-MXFP4-PLEFP8, concurrency 8, approximately 1000 input tokens and exactly 1000 output tokens, seed 42, temperature 0, `ignore_eos=true`, NEXTN (3 steps / 4 draft tokens). Server-reported input lengths matched across all runs: mean 1000.1625, range 1000–1002. The synthetic content length was set to 948 to account for the chat template.

Runtime: PyTorch `2.11.0+rocm10.0.0`, AITER `9539fd397005117c7b2387b55e469675edc76ce4`, `SGLANG_USE_AITER=1`. The benchmark launcher retains simulated speculative acceptance length **2.32** and stream interval **50**. Results describe this configuration; the token-time metric is an average rather than token-by-token delivery timing. Runs were ordered main/main then patched/patched, so this is not a randomized multi-session study.
```
