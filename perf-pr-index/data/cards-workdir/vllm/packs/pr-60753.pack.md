## Details

### Before: 1.9ms per kernel call

At 512k ISL, the final chunk's indexer splits the context into **16** chunks and scores+topk's each of them individually. This happens for each of the **11** sparse MLA layers. These kernels execute in
- mqa_logits: ~800us
- indexer topk: 1.9ms

Hence we spend `1.9ms * 11 * 16 = 350ms` on topk only, The full forward takes 800ms, so 43% of chunked prefill is spent just doing topk's!
