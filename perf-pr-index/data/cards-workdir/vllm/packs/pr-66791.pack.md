## Overview

Qwen4Exp's SM90 HyperConnection path materializes a 10,240-column BF16 gate between the up projection and four-stream mixing. Fuse the projection, sigmoid and mixing in Triton to consume gate tiles directly.

The specialization covers BF16, four streams, hidden size 2560, low-rank dimension 320 and at least 512 local rows. It preserves BF16 gate rounding and FP32 mixing order and uses the existing dispatch and weights. No new parallelism or communication is introduced.

Duplicate searches found no other open PR implementing this SM90 fusion. This adds a Hopper path alongside the SM100 implementation from #64898; existing ROCm, padding and sequence-parallel changes address different work.
