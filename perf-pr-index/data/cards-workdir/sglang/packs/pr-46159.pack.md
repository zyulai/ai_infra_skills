## Motivation

In deterministic mode, RMSNorm with a residual add (both norms in every decoder layer) falls back to eager PyTorch, which takes about ten kernel launches instead of a single fused kernel. This PR adds a fused, batch-invariant add+RMSNorm kernel for that path. It applies to any model whose decoder layers use `RMSNorm` with a residual (Llama, Mistral, Qwen2/3, Qwen3-MoE, Phi, DeepSeek, gpt-oss and most others). Tested on MI350X with Qwen3-8B, Qwen3-30B-A3B and Phi-4: single-request decode throughput with the fused kernel is 56-73% higher and 12-22% higher at concurrency 16, and every determinism check passes on Qwen3-8B (TP1, TP2) and Qwen3-30B-A3B.

The fallback is a large share of deterministic decode time. Profile of a single-request decode (1k-token prompt, 256 output tokens, CUDA graphs off) in deterministic mode on MI350X:

| model | GPU time, deterministic | GPU time, normal mode | eager add+RMSNorm fallback |
| --- | --- | --- | --- |
| Qwen3-8B | 603 ms | 323 ms | about 205 ms (34%) |
| Qwen3-30B-A3B | 678 ms | 298 ms | about 215 ms (32%) |
| Phi-4 | 902 ms | 474 ms | about 205 ms (22%) |

In normal mode the same norms take 12.6 ms on Qwen3-8B as one fused kernel.

Scope: deterministic mode only, on every platform that runs the batch-invariant Triton kernels. The new kernel uses the same float32 math as `forward_native`. Models that use `GemmaRMSNorm` (Gemma, Qwen3-Next/3.5/3.8) take a different path and are not affected. Normal mode is unchanged.

## Modifications

- `batch_invariant_ops.py`: new `_fused_add_rms_norm_kernel` and `fused_add_rms_norm_batch_invariant`, next to the existing `rms_norm` kernel and in the same style. One program per row:
  - adds the residual (and the optional post-residual addend) to the input in float32;
  - stores the sum as the new residual, in the input's dtype or float32 (`fp32_residual`);
  - RMS-normalizes the float32 sum and applies the weight.

  The reduction runs over one row with a fixed block size, so a row's result does not depend on the batch.
- `layernorm.py`: in the batch-invariant branches of `RMSNorm.forward_cuda`, `forward_aiter`, `forward_hip` and `forward_xpu`, calls with a residual use the new kernel where `forward_native`'s math applies. These cases keep falling back to `forward_native` as before:
  - `cast_x_before_out_mul`;
  - a variance-size override;
  - a padded output;
  - the FSDP RL target.
- New `test/registered/unit/batch_invariant_ops/test_fused_add_rms_norm_batch_invariant.py` (per-PR, CUDA and MI35x):
  - every row's output and new residual are bit-identical (`torch.equal`) when computed in batches of 1, 3, 17 and 64;
  - the new residual equals the eager float32 sum exactly, and the output matches the eager path within rounding;
  - covered: hidden sizes 2048/4096/5120/2880, bf16 and fp16, with and without the addend, `fp32_residual` on and off.
- Unchanged: normal mode; batch-invariant calls without a residual; the fallback cases above.

+def _fused_add_rms_norm_kernel(
+    input_ptr,
+    residual_ptr,
+    addend_ptr,
+    weight_ptr,
+    output_ptr,
+    residual_out_ptr,
+    input_row_stride: tl.constexpr,
+    residual_row_stride: tl.constexpr,
+    addend_row_stride: tl.constexpr,
+    output_row_stride: tl.constexpr,
+    residual_out_row_stride: tl.constexpr,
+    n_cols: tl.constexpr,
+    eps,
+    HAS_ADDEND: tl.constexpr,
+    BLOCK_SIZE: tl.constexpr,
+):
+    """
+    Add the residual (and an optional addend) to the input in float32, store the
+    sum as the new residual, and RMS-normalize the sum.
+    Each block handles one row, so a row's result does not depend on the others.
+    """
+    row_idx = tl.program_id(0).to(tl.int64)
+    input_row = input_ptr + row_idx * input_row_stride
+    residual_row = residual_ptr + row_idx * residual_row_stride
+    addend_row = addend_ptr + row_idx * addend_row_stride
+    output_row = output_ptr + row_idx * output_row_stride
+    residual_out_row = residual_out_ptr + row_idx * residual_out_row_stride
+
+    # Step 1: Sum in float32, store the new residual, accumulate the sum of squares
+    sum_sq = tl.zeros([1], dtype=tl.float32)
+    for col_offset in range(0, n_cols, BLOCK_SIZE):
+        col_idx = col_offset + tl.arange(0, BLOCK_SIZE)
+        mask = col_idx < n_cols
+        vals_f32 = tl.load(input_row + col_idx, mask=mask, other=0.0).to(tl.float32)
+        vals_f32 += tl.load(residual_row + col_idx, mask=mask, other=0.0).to(tl.float32)
+        if HAS_ADDEND:
+            vals_f32 += tl.load(addend_row + col_idx, mask=mask, other=0.0).to(
+                tl.float32
+            )
+        tl.store(
+            residual_out_row + col_idx,
+            vals_f32.to(residual_out_ptr.dtype.element_ty),
+            mask=mask,
+        )
+        sum_sq += tl.sum(tl.where(mask, vals_f32 * vals_f32, 0.0))
+
+    # Step 2: Compute RMS (root mean square) in float32
+    mean_sq = sum_sq / n_cols
+    rms = tl.sqrt(mean_sq + eps)
+    inv_rms = 1.0 / rms
+
+    # Step 3: Recompute the float32 sum, normalize and apply weight
+    for col_offset in range(0, n_cols, BLOCK_SIZE):
+        col_idx = col_offset + tl.arange(0, BLOCK_SIZE)
+        mask = col_idx < n_cols
+        vals_f32 = tl.load(input_row + col_idx, mask=mask, other=0.0).to(tl.float32)
+        vals_f32 += tl.load(residual_row + col_idx, mask=mask, other=0.0).to(tl.float32)
+        if HAS_ADDEND:
+            vals_f32 += tl.load(addend_row + col_idx, mask=mask, other=0.0).to(
+                tl.float32
+            )
+        weight_f32 = tl.load(weight_ptr + col_idx, mask=mask, other=1.0).to(tl.float32)
+        output_f32 = vals_f32 * inv_rms * weight_f32
+        tl.store(
+            output_row + col_idx,
+            output_f32.to(output_ptr.dtype.element_ty),
+            mask=mask,
+        )

+"""Batch-invariant fused residual add + RMSNorm.
+
+In batch-invariant mode, RMSNorm calls with a residual run this kernel instead of
+the eager float32 path. A row's output and new residual must not depend on how
+many other rows share the batch, and must match the eager float32 math.
+"""
+
+import unittest
+
+import torch
+
+from sglang.srt.batch_invariant_ops import fused_add_rms_norm_batch_invariant
+from sglang.test.ci.ci_register import register_amd_ci, register_cuda_ci
+from sglang.test.test_utils import CustomTestCase
+
+register_cuda_ci(est_time=10, stage="base-b", runner_config="1-gpu-small")
+register_amd_ci(est_time=15, suite="stage-b-test-1-gpu-small-amd-mi35x")
+
+EPS = 1e-6
+
+
+def _reference(x, residual, weight, addend, fp32_residual):
+    """The float32 math of RMSNorm.forward_native with a residual."""
+    s = x.float() + residual.float()
+    if addend is not None:
+        s = s + addend.float()
+    new_residual = s.clone() if fp32_residual else s.to(x.dtype)
+    out = s * torch.rsqrt(s.pow(2).mean(dim=-1, keepdim=True) + EPS)
+    return (out * weight).to(x.dtype), new_residual
+
+
+@unittest.skipUnless(torch.cuda.is_available(), "needs a GPU")
+class TestFusedAddRMSNormBatchInvariant(CustomTestCase):
+    def _check(self, hidden, dtype, with_addend, fp32_residual):
+        torch.manual_seed(0)
+        m = 64
+        x = torch.randn(m, hidden, device="cuda", dtype=dtype)
+        residual = torch.randn(m, hidden, device="cuda", dtype=dtype)
+        addend = (
+            torch.randn(m, hidden, device="cuda", dtype=dtype) if with_addend else None
+        )
+        weight = torch.randn(hidden, device="cuda", dtype=dtype)
+        residual_dtype = torch.float32 if fp32_residual else dtype
+
+        def run(rows):
+            return fused_add_rms_norm_batch_invariant(
+                x[rows],
+                residual[rows],
+                weight,
+                EPS,
+                addend=addend[rows] if addend is not None else None,
+                residual_dtype=residual_dtype,
+            )
+
+        out, new_residual = run(slice(0, m))
+        self.assertEqual(new_residual.dtype, residual_dtype)
+
+        # Batch invariance: every row equals the same row computed in smaller batches.
+        for bs in (1, 3, 17):
+            for start in range(0, m, bs):
+                rows = slice(start, min(start + bs, m))
+                part_out, part_residual = run(rows)
+                self.assertTrue(torch.equal(part_out, out[rows]), f"bs={bs}")
+                self.assertTrue(torch.equal(part_residual, new_residual[rows]))
+
+        # Same math as the eager path.
+        ref_out, ref_residual = _reference(x, residual, weight, addend, fp32_residual)
+        self.assertTrue(torch.equal(new_residual, ref_residual))
+        torch.testing.assert_close(out, ref_out, atol=2e-2, rtol=2e-2)
