## Motivation

<!-- Describe the purpose and goals of this pull request. -->
Sometimes `test/registered/8-gpu-models/test_gpt_oss_120b.py` hangs until NCCL watch dog timeout due to FlashInfer create workspace OOM https://github.com/sgl-project/sglang/actions/runs/24918423411/job/72975439419

## Modifications

<!-- Detail the changes made in this pull request. -->
- probe the correct memory allocation instead of using `torch.cuda.memory.get_mem_info`
     - probe correct amount and type of memory required
- ranks go into voting to collectively decide whether to enter `create_allreduce_fusion_workspace`


FYI I spent sometime to look into flashinfer and can confirm this fix is legit. Don't think there are other approaches at flashinfer level
 
## Accuracy Tests

Add `test_flashinfer_fusion_preflight.py` which force rank 0 to reserve almost all of its GPU memory using the same CUDA driver allocation prop as the preflight. Expected behavior should be rank 0 local probe fails, `dist.all_reduce(BAND)` broadcasts that failure, and both ranks return False.
