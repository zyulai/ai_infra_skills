## Modifications

Add critical safety check using np.clip to ensure block indices never exceed block_table dimensions. This fixes index errors that occurred with sequences slightly larger than the attention chunk size (e.g., 8193 tokens with 8192 chunk size) where the second local attention block would try to access indices beyond the block_table's bounds.
