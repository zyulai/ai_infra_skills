## PR body
```markdown
## Purpose

DeepEncoder relative attention currently expands decomposed height and width
terms into a dense `[B, heads, HW, HW]` bias before SDPA. Its 64x64 global
attention therefore materializes a 384 MiB BF16 temporary.

This PR adds a dedicated Triton forward kernel that evaluates both relative
terms while streaming key/value tiles through online softmax:

```text
before: rel_h + rel_w -> dense 4D bias -> SDPA
after:  compact rel_h/rel_w -> fused Triton attention
```

The Triton path is limited to the production DeepEncoder global-attention
configuration on CUDA: FP16/BF16 with head dimension 64. Window attention,
CPU, unsupported dtypes, and unsupported head dimensions retain the existing
SDPA path. The implementation does not use FlexAttention or `torch.compile`.

### RTX 4090 microbenchmark

```bash
PYTHONPATH="$PWD" .venv/bin/python \
  benchmarks/kernels/benchmark_deepencoder_rel_pos_attention.py \

```

Hardware/software: NVIDIA RTX 4090, CUDA 13.2, PyTorch 2.13.0+cu132,
Triton 3.7.1, BF16. Results are medians of 50 interleaved samples.

| Scope | Path | p50 (ms) | Incremental peak allocation (MiB) | Max abs error |
|:---|:---|---:|---:|---:|
| attention operator | Dense SDPA | 1.1453 | 390 | reference |
| attention operator | Triton | 0.5478 | 6 | 9.77e-4 |
| full `RelPosAttention` | Dense SDPA | 1.5667 | 426 | reference |
| full `RelPosAttention` | Triton | 0.9820 | 42 | 4.88e-4 |

The independent recheck reduced operator latency by 52.2% and full-layer
latency by 37.3%, while both measurements saved exactly 384 MiB of incremental
peak allocation. Reference and candidate both pass CUDA Graph capture/replay.

The previous FlexAttention candidate measured 1.4469 ms for the full layer on
the same GPU. The Triton revision is about 32.1% lower than that result and has
no per-process `torch.compile` dependency.

### DeepSeek-OCR end-to-end correctness

I ran `deepseek-ai/DeepSeek-OCR` with a deterministic 1024x1024 OCR image,
greedy decoding, and `enforce_eager=True`. The base reference and Triton
candidate generated exactly the same 21 token IDs and decoded text.

## Limitations

These are isolated DeepEncoder attention results from one RTX 4090, not an
end-to-end serving throughput claim or a performance claim for other GPU
architectures. The optimized path is forward-only and intentionally limited to
CUDA FP16/BF16 with head dimension 64; other configurations use SDPA.
