## PR body
```markdown
Apply same O(1) optimization to INSERT that we applied to MATCH. Intermediate node timestamps are never used - eviction only checks leaf timestamps via leaf_of(). Skip redundant O(depth) updates.

Changes:
- Root: use or_insert(0) instead of insert(epoch)
- Intermediate nodes: only ensure tenant exists, don't update timestamp
- Leaf node: update timestamp after loop or when creating new node
- Lazy char count: only compute chars().count() when creating leaf

Performance improvement:
- INSERT now 6-7x faster (52-64µs → 7-11µs)
- Flat scaling across worker counts
```
