## 正文(PR 描述)

This PR fixes a critical crash occurring on AMD (ROCm) hardware when initializing the Qwen3-Omni model (specifically the Qwen3Omni_VisionTransformer).

During the memory profiling phase (profile_run), the operation torch.repeat_interleave on the GPU triggers a hipErrorIllegalState, causing the worker to crash. This appears to be a stability issue with dynamic tensor shape operations on the current ROCm driver/backend when processing visual grid dimensions.

The Fix The calculation of cu_seqlens inside Qwen3Omni_VisionTransformer.forward involves very small tensors (grid_thw). I have moved this specific calculation (the repeat_interleave and cumsum ops) to the CPU. The result is then moved back to the device.

This change avoids the GPU crash and allows the model to load and profile correctly. Since the tensors involved (grid dimensions) are negligible in size, this has no impact on inference performance.
