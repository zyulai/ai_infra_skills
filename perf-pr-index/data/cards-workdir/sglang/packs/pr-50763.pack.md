## PR body
```markdown
## Motivation

In DFlash-family speculative decoding (DSpark/dFlash verify) on Ascend NPU, the attention backend requires a CPU mirror of `seq_lens` (`SGLANG_NPU_ATTN_BACKEND_NEEDS_CPU_SEQ_LENS=1`). The scheduler publishes this mirror every step, and any consumer that falls back to a device-side `seq_lens.cpu()` pays a pageable D2H that drains the whole CANN async task queue — up to ~52ms of `StreamSynchronize` per verify step while the device idles.

This PR adds a mirrorless path (`=0`) for the DeepSeek-V4 NPU attention backend: all metadata that previously depended on the CPU mirror (live/final KV lengths, verify compress metadata, prefix lens, the DSV4 verify cache-loc bundle) is derived on device from the live `seq_lens`. Idle/padding rows (DP padding) stay all-zero via where-gating. The CUDA DSPARK backend is already unconditionally mirrorless, which motivated this port.

The `=1` path is unchanged except two numerically-equivalent replacements of boolean row-indexing (`x[mask]` — aclnnNonzeroV2 fails to start on NPU and implies a hidden D2H) with mask-multiply / stable compact.

## Modifications

- `ascend_dsv4_backend.py`:
  - Graph replay: device-side derivation of live/final KV lengths and verify compress metadata (where-gated `live + n_draft`); kernel metadata `*_cpu` args gated by `needs_cpu_seq_lens` so warmup and replay agree on the ABI.
  - Eager verify: expand live prefix to final KV lengths on device; never trust the potentially stale `fm.seq_lens_cpu_int`.
  - Replay-prep width bound via `max_seq_len_host` hint (+1 page slack for overlap host-view lag), full-width fallback when no hint exists.
  - Decode compress-loc: stable compact instead of boolean indexing (the dynamic-shape output would force a per-step D2H sync).
- `dsv4_common_hooks.py`: mirrorless verify builds the DSV4 cache-loc bundle on device — the c128 draft-interval locs are gathered and stably compacted (cumsum + scatter, no NonZero) into a fixed-width buffer sized by the consumers' padding bound, so no consumer `numel()` ever syncs. Gated on the effective `live_seq_lens_cpu` being None.
- `eagle_utils.py`: set `batch.max_seq_len_host` in `eagle_prepare_for_verify` (host-side upper bound of final KV lengths, already forwarded by `ForwardBatch` and the graph runner).
- `dflash_info_v2.py` / `dflash_info.py` / `dspark_draft.py`: set the same hint on the DFlash prep paths — `prepare_for_decode` (over-allocated KV upper bound, pure host), `prepare_for_verify` (`max(req.seqlen) + draft_token_num`) — and carry it into the hand-built draft `ForwardBatch` (bypasses `init_new`). Consumers gate on `seq_lens_cpu`, so `=1` never reads the hint.
```

## Speed Tests and Profiling

Benchmark: ShareGPT gsp, 64 prompts, concurrency 32, system prompt 57.6k tokens, seed 1, 16P, 3 steady runs each (first warm-up run excluded):

| Metric | =1 | =0 |
|---|---|---|
| Output throughput (tok/s) | 481 / 482 / 518 | 545 / 504 / 519 |
| Accept length | 5.55 / 5.58 / 5.35 | 5.36 / 5.06 / 5.54 |
| Median ITL (ms) | 12.01 / 11.98 / 11.89 | 11.06 / 11.01 / 11.08 |
| Per-step wall time (ms)* | 11.5 / 11.6 / 10.3 | 9.8 / 10.0 / 10.7 |

\* duration ÷ (generated tokens ÷ accept length). Accept length is content-level noise (it swings 5.0–5.6 across identical configs), so ITL and per-step wall time are the stable comparators: **mirrorless cuts median ITL by ~7.6%, output throughput by ~6%, and average per-step wall time by ~9%**.

Profiling (metadata stream, per verify step, steady decode):

| Metric | =1 | =0 |
|---|---|---|
| `aclnnIndex_StridedSlice` | 0.52ms | 0.52ms |
| `aclnnIndex_Index` | 0.20ms | 0.46ms |
| Metadata stream busy | 3.4ms | 4.15ms |
| ProfilerStep | 83.1ms | 81.3ms |

With `with_stack` profiling, the per-step `Runtime@StreamSynchronize` (pageable D2H, up to 51.7ms) is fully eliminated; device kernel busy stays ~98% across the steady window, and the remaining host waits are overlap result waits with the device 100% busy.

```diff
+def _flatten_interval_device(
+    *,
+    table: torch.Tensor,
+    page_size: int,
+    req_pool_indices: torch.Tensor,
+    live_seq_lens: torch.Tensor,
+    verify_lens: torch.Tensor | None,
+    n_draft: int,
+    upper: int,
+) -> torch.Tensor:
+    """Device twin of the host ``flatten_interval`` loop (ratio=128): the c128
+    slots of the compressed positions ``[live // 128, (live + verify) // 128)``,
+    compacted req-major into a fixed ``upper``-wide buffer whose tail carries
+    the slot-map skip sentinel. Every op is an asynchronous device kernel and
+    the shape is host-known, so consumers' ``numel()`` never syncs. DP-padding
+    rows (live == 0) yield an empty interval, like the host ``end > start``
+    guard.
+    """
+    from sglang.srt.hardware_backend.npu.attention.ascend_dsv4_backend import (
+        _loc_pad_value,
+    )
+
+    device = live_seq_lens.device
+    bs = live_seq_lens.shape[0]
+    if verify_lens is None:
+        verify_lens = torch.full((bs,), n_draft, dtype=torch.int64, device=device)
+    live = live_seq_lens.reshape(-1)[:bs].to(torch.int64)
+    verify = verify_lens.reshape(-1)[:bs].to(torch.int64)
+    starts, ends = live // 128, (live + verify) // 128
+
+    # Per-req interval is at most n_draft // 128 + 1 compressed positions,
+    # which sizes the shared position grid without a host ``max()`` read.
+    positions = (
+        starts[:, None] + torch.arange(n_draft // 128 + 1, device=device)[None, :]
+    )
+    valid = positions < ends[:, None]
+
+    # Single flat gather; invalid lanes clamp their page index into the row
+    # and contribute garbage that the compact below drops.
+    n_cols = table.shape[1]
+    page_idx = (positions // page_size).clamp_(max=n_cols - 1)
+    flat_idx = (
+        req_pool_indices[:bs].to(torch.int64)[:, None] * n_cols + page_idx
+    ).reshape(-1)
+    locs = table.reshape(-1)[flat_idx] * page_size + positions.reshape(-1) % page_size
+
+    # Stable compact without NonZero, mirroring _compact_c4_loc: each valid
+    # lane lands on its ordinal among valid lanes; invalid lanes share the
+    # trash slot at ``upper`` (duplicate writes are fine) which the slice
+    # below drops.
+    flat_valid = valid.reshape(-1)
+    dest = flat_valid.cumsum(0).sub_(1).masked_fill_(~flat_valid, upper)
+    buf = torch.full((upper + 1,), _loc_pad_value(), dtype=locs.dtype, device=device)
+    buf.scatter_(0, dest, locs)
+    return buf[:upper]
```
