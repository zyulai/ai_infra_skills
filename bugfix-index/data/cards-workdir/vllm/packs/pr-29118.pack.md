## 正文(PR 描述)

In any of the tests in test_cache.py that are testing a Triton kernel, it is necessary to call both` torch.set_default_device` and `torch.cuda.set_device` with the same device to ensure that the kernel executes on the same device as the allocated tensors.

In `test_concat_and_cache_ds_mla`, `fp8_ds_mla `is not supported by `concat_and_cache_mla `on ROCm, so this test is skipped for AMD hardware.

Test results on AMD now:

1110 passed, 294 skipped, 3 warnings in 741.42s (0:12:21)
