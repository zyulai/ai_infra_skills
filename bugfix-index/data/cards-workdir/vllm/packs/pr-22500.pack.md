The reason for this failure is that both Ray actors use the same device to allocate the kv cache tensors, indicating that the env var set in the init method of [DPEngineCoreActor](https://github.com/vllm-project/vllm/blob/main/vllm/v1/engine/core.py#L1169) doesn't take effect.

The reason why it doesn't take effect is that Ray has already initialized the XPU context before loading Ray actors.  As a result, any environment variable changes made in the actor's __init__ method are too late to influence device selection.

To fix this problem, we need to set the XPU environment variable before Ray actors are initialized. Since runtime_env is set while starting Ray worker processes, this PR configures the required XPU environment variable ZE_AFFINITY_MASK via runtime_env for each actor.
