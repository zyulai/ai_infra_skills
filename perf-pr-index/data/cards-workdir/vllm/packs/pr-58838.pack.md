## PR body
```markdown
## Purpose

Migrate the base `RotaryEmbedding` from a plain `CustomOp` to a vLLM **IR op** (`vllm.ir.ops.rotary_embedding`), so the QK-norm + RoPE(+KVCache) fusion patterns match a stable IR node **without** having to force `custom_ops=["+rotary_embedding"]`.

This resolves the long-standing `# TODO: support rope native forward match` blocks in `vllm/config/compilation.py` and the underlying pattern-match failure tracked in **#28042** (RoPE only matched the fusion when registered as a custom op). It follows the direction of **#38756** ("Port RoPE ops to IR").

RoPE now emits the same IR node on every forward path (native/CUDA/HIP), so:
- fusion patterns match regardless of `custom_ops`, and
- the actual kernel (native vs. `_C` vs. AITER Triton) is chosen by **IR op priority** during lowering instead of a global custom-op flag.

## Why this is not duplicating an existing PR

The prior effort — **#43199** (`[vLLM IR][Rope] Port RotaryEmbedding to IR Ops`, @wxsIcey) and its predecessors #39488/#41773/#42264 — is **closed and unmerged** (last state: merge conflicts, `mergeable_state: dirty`), and RoPE is **not** an IR op on current `main`. This PR differs materially:

- **Rebased on current `main`** and conflict-free.
- **Keeps `MatcherRotaryEmbedding`** (making it emit the IR node) instead of deleting it. Current `main` gained `QkNormRopeKvCacheFusionPass` (the AITER QK-norm+RoPE+KVCache fusion, #42749) *after* #43199 was written, and that pass depends on the matcher — deleting it (as #43199 did) would break the AITER fusion.
- **Completes the ROCm/AITER path**: adds an `aiter` IR provider for `rotary_embedding`, decouples the AITER Triton dispatch from `RotaryEmbedding.enabled()`, and sets ROCm IR-op priority to prefer AITER when enabled. Removing the `+rotary_embedding` force otherwise silently disabled AITER RoPE on ROCm.
- Scope is intentionally limited to the **base `RotaryEmbedding`** (Neox + GPT-J, full/partial rope). `DeepseekScalingRotaryEmbedding`, mRoPE, flashinfer, and the `key=None` cross-layer-KV-sharing path are left on their existing paths and can be ported in follow-ups.

+// Out-of-place RoPE: reads heads from src, writes rotated heads to dst and
+// copies the non-rotated tail (partial rotary) so dst is fully defined.
+template <typename scalar_t, typename cache_t, bool IS_NEOX>
+inline __device__ void rotate_heads_out(
+    const scalar_t* src, scalar_t* dst, const int num_heads,
+    const int64_t src_head_stride, const int64_t dst_head_stride,
+    const cache_t* __restrict__ cos_ptr, const cache_t* __restrict__ sin_ptr,
+    const int embed_dim, const int rot_dim, const int head_size) {
+  for (int i = threadIdx.x; i < num_heads * embed_dim; i += blockDim.x) {
+    const int head_idx = i / embed_dim;
+    const int rot_offset = i % embed_dim;
+    const scalar_t* s = src + head_idx * src_head_stride;
+    scalar_t* d = dst + head_idx * dst_head_stride;
+    const int x_index = IS_NEOX ? rot_offset : 2 * rot_offset;
+    const int y_index = IS_NEOX ? embed_dim + rot_offset : 2 * rot_offset + 1;
+    const float cos_f = static_cast<float>(VLLM_LDG(cos_ptr + rot_offset));
+    const float sin_f = static_cast<float>(VLLM_LDG(sin_ptr + rot_offset));
+    const float x_f = static_cast<float>(s[x_index]);
+    const float y_f = static_cast<float>(s[y_index]);
+    d[x_index] = static_cast<scalar_t>(x_f * cos_f - y_f * sin_f);
+    d[y_index] = static_cast<scalar_t>(y_f * cos_f + x_f * sin_f);
+  }
+  const int pass_dim = head_size - rot_dim;
+  for (int i = threadIdx.x; i < num_heads * pass_dim; i += blockDim.x) {
+    const int head_idx = i / pass_dim;
+    const int offset = rot_dim + i % pass_dim;
+    dst[head_idx * dst_head_stride + offset] =
+        src[head_idx * src_head_stride + offset];
+  }

+__global__ void rotary_embedding_out_kernel(
+    const int64_t* __restrict__ positions,  // [num_tokens]

+    const int64_t query_head_stride, const int64_t key_head_stride,
+    const int64_t query_out_head_stride, const int64_t key_out_head_stride,
+    const int num_heads, const int num_kv_heads, const int head_size) {
+  const int token_idx = blockIdx.x;
+  const int64_t pos = positions[token_idx];
+  const int embed_dim = rot_dim / 2;
+  const cache_t* cos_ptr = cos_sin_cache + pos * rot_dim;
+  const cache_t* sin_ptr = cos_ptr + embed_dim;

+      query + token_idx * query_stride,

+      query_out_head_stride, cos_ptr, sin_ptr, embed_dim, rot_dim, head_size);
+  if (key != nullptr) {
+    rotate_heads_out<scalar_t, cache_t, IS_NEOX>(
+        key + token_idx * key_stride, key_out + token_idx * key_out_stride,
+        num_kv_heads, key_head_stride, key_out_head_stride, cos_ptr, sin_ptr,
+        embed_dim, rot_dim, head_size);
+  }
