## PR body
```markdown
## Motivation

Follow-up to #29734. FlashInfer GDN prefill could not previously participate in SGLang's Mamba `h`/track-state flow, so `extra_buffer` and `extra_buffer_lazy` radix caching required Triton prefill even though FlashInfer can emit intermediate state checkpoints.

## Modifications

- Request packed `state_checkpoints` from FlashInfer GDN prefill and map them to SGLang's tracked-state metadata.
- Read aligned boundaries from the final state pool and unaligned boundaries from packed checkpoints.
- Support nonzero prefixes and packed variable-length tracking.
- Keep SM100/SM103 state and checkpoints in native BF16 with FlashInfer 0.6.14; SM90 remains FP32.
- Auto-select FlashInfer for `no_buffer`, `extra_buffer`, and `extra_buffer_lazy` within the validated #29734 selector domain.
- Keep Triton tree verify fallback and add focused policy/checkpoint tests.

## Accuracy Tests
