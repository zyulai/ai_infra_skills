## Performance Improvement for FP8 MoE on H100 PCIe

### Summary

This PR optimizes the FP8 MoE kernel configuration for NVIDIA H100 PCIe by updating the fused MoE configuration from `E=128,N=384` to `E=64,N=768` with FP8 support (`dtype=fp8_w8a8`). This change improves throughput for FP8 MoE models on H100 PCIe.

### Benchmark Results

**Test Configuration:**
- **Model:** Qwen/Qwen3-30B-A3B-FP8
- **Script:** `python benchmarks/kernels/benchmark_moe.py --tune --save-dir vllm/model_executor/layers/fused_moe/configs --model Qwen/Qwen3-30B-A3B-FP8  --tp-size 2 --enable-expert-parallel --type fp8_w8a8`
- **Server:** `python -m vllm.entrypoints.openai.api_server --model $MODEL --enable-expert-parallel -tp 2 --port 8101 --gpu_memory_utilization=0.95`
- **Benchmark:** `vllm bench serve --model $MODEL --dataset-name random --random-input-len 7500 --random-output-len 7500 --max-concurrency 64 --num-prompts 128 --port 8101`

**Performance Comparison:**

| Metric | Before | After | Improvement |
|--------|--------|-------|-------------|
| Output token throughput (tok/s) | 1600.05 | 1626.21 | +1.6% |
| Peak output token throughput (tok/s) | 2240.00 | 2304.00 | +2.9% |
| Total token throughput (tok/s) | 3211.70 | 3270.29 | +1.8% |
| Mean TPOT (ms) | 38.88 | 38.05 | -2.1% |
| Median TPOT (ms) | 39.22 | 38.56 | -1.7% |
| P99 TPOT (ms) | 39.81 | 38.85 | -2.4% |
| Mean ITL (ms) | 38.68 | 37.88 | -2.1% |
| Median ITL (ms) | 36.20 | 35.45 | -2.1% |

- Replaced `E=128,N=384,device_name=NVIDIA_H100_PCIe,block_shape=[128,128].json` with `E=64,N=768,device_name=NVIDIA_H100_PCIe,dtype=fp8_w8a8,block_shape=[128,128].json`
