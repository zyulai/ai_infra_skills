## Problem

On sm100 the default attention backend resolves to `DYNAMIC_CUDNN_SDPA`, but `USPAttention`'s masked local path opens its varlen fast path only for `backend == FA`. Every other backend gets a dense additive mask for `torch.nn.functional.scaled_dot_product_attention`, and any mask moves SDPA off flash and cuDNN onto PyTorch's `fmha_cutlassF_*_sm80` kernel, even when the mask masks nothing.

Ideogram4 passes such a mask on both guidance branches at batch 1: its text is never padded at batch 1, so `segment_ids > 0` is all true. Every attention call on B200 therefore took the cutlassF path:

- torch profile of the denoising loop: attention = **54% of GPU time on 1×B200, 47% at TP2**, all in `fmha_cutlassF_bf16_aligned_32x128_gmem_sm80`
- per call (`[1, 18, 4126, 256]` bf16): **2.19 ms with the mask, 0.81 ms without**

It is also consistent with Ideogram4 measuring only ~9% faster on B200 than on H200, against 1.7-2.6× for the other models: on Hopper the default backend is FA, whose varlen path already treats an all-valid mask as dense.

## Fix

When `attn_mask_meta` shows every key valid (its index count equals the mask's element count, known on the host, no device sync), the masked local path runs the backend's own unmasked kernel. Segmented-prefix inputs (Qwen-Image) are concatenated first, so the prefix is kept. Masks with real padding, and meta without indices (padding-gap meta), keep the masked path. The FA backend is untouched (its varlen branch returns before this point), and so are the sequence-parallel paths.

## Validation (4×B200)

- Unit: the new `test/unit/test_usp_all_valid_key_mask.py` drives `USPAttention.forward` through the masked local branch with real varlen meta. An all-valid mask runs the backend kernel once and matches unmasked attention; a real padding mask, and padding-gap meta without indices, keep the masked path; a segmented prefix is concatenated before dispatch. The two backend-kernel tests fail on `main`. The neighbouring attention/mask unit tests (ring tail-pad, K/V gather, varlen meta, replicated prefix, Ideogram4, BCG padding) pass.

- Ideogram4 serving, default B200 command (`--tp-size 2`), warmup then 5 measured requests, interleaved main/PR/main/PR on the same node:

  | | round 1 | round 2 |
  |---|---:|---:|
  | `main` | 3.424 s | 3.427 s |
  | this PR | **2.192 s** | **2.205 s** |

- Steady denoising step (single `sglang generate`, no warmup): 1 GPU 277.0 → 158.2 ms, TP2 160.8 → 126.1 ms.
- Kernels (torch profile, TP2): attention 78.0 → 8.7 ms per step. cuDNN 9.20 (bundled with torch 2.13) has no head_dim-256 kernel on sm100, so `DYNAMIC_CUDNN_SDPA` takes its FA4 fallback (`sm100_hd256_2cta_fmha_forward`, 128 µs per call against 1104 µs for cutlassF).
- Output: PR vs `main` PSNR 26.2 dB at TP2 and 26.5 dB on 1 GPU, against 22.7 dB between TP2 and 1 GPU on `main` itself. Ideogram4's guidance amplifies FP reordering; the all-valid additive mask is exactly zero, so the math is unchanged.

- Qwen-Image-2512 and Z-Image-Turbo, which also pass masks with varlen meta, produce bitwise-identical images before and after: at batch 1 they do not reach this branch.
- The second commit logs the cuDNN → FlashAttention fallback once per process. Routing these calls to the backend kernel made Ideogram4 log it once per attention layer, 68 times per start.

+"""An all-valid key mask must not force the dense-mask SDPA path.
+
+Outside the FA backend, USPAttention serves a masked call with a dense SDPA
+mask, which on sm100 pins PyTorch's cutlassF kernel even when the mask masks
+nothing (Ideogram4 passes such a mask on every step).
+"""
+
+import unittest
+from types import SimpleNamespace
+from unittest.mock import patch
+
+import torch
+import torch.nn.functional as F
+
+from sglang.multimodal_gen.runtime.layers.attention.layer import (
+    USPAttention,
+    build_varlen_mask_meta,
+)
+from sglang.multimodal_gen.runtime.platforms import AttentionBackendEnum
+
+_LAYER = "sglang.multimodal_gen.runtime.layers.attention.layer"
+
+
+class _CountingSdpa:
+    """Stands in for the backend kernel and counts calls."""
+
+    def __init__(self, scale: float):
+        self.scale = scale
+        self.calls = 0
+
+    def forward(self, q, k, v, _ctx):
+        self.calls += 1
+        return _sdpa(q, k, v, self.scale)
+
+
+def _sdpa(q, k, v, scale, key_mask=None):
+    return F.scaled_dot_product_attention(
+        q.transpose(1, 2),
+        k.transpose(1, 2),
+        v.transpose(1, 2),
+        attn_mask=None if key_mask is None else key_mask[:, None, None, :],
+        scale=scale,
+    ).transpose(1, 2)
+
+
+class TestAllValidKeyMask(unittest.TestCase):
+    def setUp(self):
+        torch.manual_seed(0)
+        obj = USPAttention.__new__(USPAttention)
+        obj.causal = False
+        # sm100 default: the masked varlen fast path only serves FA
+        obj.backend = AttentionBackendEnum.DYNAMIC_CUDNN_SDPA
+        obj.softmax_scale = 8**-0.5
+        obj.attn_impl = _CountingSdpa(obj.softmax_scale)
+        obj.allow_cudnn_sdp = False
+        obj.skip_sequence_parallel = False
+        obj.sp_attention_mode = "ulysses"
+        obj.sp_attention_mode_is_auto = False
+        self.attn = obj
+
+    def _forward(self, *args, **kwargs):
+        with (
+            patch(
+                f"{_LAYER}.get_forward_context",
+                return_value=SimpleNamespace(attn_metadata=None),
+            ),
+            patch(f"{_LAYER}.get_sequence_parallel_world_size", return_value=1),
+        ):
+            return self.attn.forward(*args, **kwargs)
+
+    def test_all_valid_mask_runs_the_backend_kernel(self):
+        q, k, v = (torch.randn(2, 6, 2, 8) for _ in range(3))
+        mask = torch.ones(2, 6, dtype=torch.bool)
+
+        out = self._forward(
+            q, k, v, attn_mask=mask, attn_mask_meta=build_varlen_mask_meta(mask)
+        )
+
+        self.assertEqual(self.attn.attn_impl.calls, 1)
+        torch.testing.assert_close(out, _sdpa(q, k, v, self.attn.softmax_scale))
+
+    def test_padding_mask_keeps_the_masked_path(self):
+        q, k, v = (torch.randn(1, 6, 2, 8) for _ in range(3))
+        mask = torch.ones(1, 6, dtype=torch.bool)
+        mask[:, 4:] = False
+
+        out = self._forward(
+            q, k, v, attn_mask=mask, attn_mask_meta=build_varlen_mask_meta(mask)
+        )
+
+        self.assertEqual(self.attn.attn_impl.calls, 0)

+        )
+
+    def test_segmented_prefix_reaches_the_backend_kernel_concatenated(self):

+
