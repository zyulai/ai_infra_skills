## 正文(PR 描述)

## Motivation

Restore Ascend/NPU packed Ring Attention, 2-NPU diffusion CI suite, fix NPU correctness, runtime, and CI regressions exposed by recent Ring, SRT-CLIP, residency, and MOVA changes.

After [#35004](https://github.com/sgl-project/sglang/pull/35004), diffusion can import SRT CLIP code and execute SRT `init_npu_backend()`. Importing `torch_npu.contrib.transfer_to_npu` inside a native NPU diffusion process globally rewrites CUDA-facing APIs/device arguments and can alter runtime feature detection and kernel selection. `allow_internal_format=True` is also known to regress unquantized diffusion performance; the earlier Wan regression in [#20533](https://github.com/sgl-project/sglang/issues/20533), fixed by [#20684](https://github.com/sgl-project/sglang/pull/20684), increased `DecodingStage` from **6.1889 s to 11.76 s (+90.0%, 1.90x slower)**.

The packed-attention implementation is extracted from the Ascend work in [#33569](https://github.com/sgl-project/sglang/pull/33569).

## Modifications

- **Packed varlen / Ring Attention.** [#33327](https://github.com/sgl-project/sglang/pull/33327) extended Qwen to tail-padded Ring and fixed `u=1, r>1` replicated-token semantics, exposing the shared packed `flash_attn_varlen_func` path on NPU. Add an Ascend implementation backed by `npu_fused_infer_attention_score` (`TND`) with independent Q/K packed lengths, boundary validation, empty/non-contiguous handling, LSE normalization, and `AscendFlashAttnImpl.forward_varlen`. Unsupported FlashAttention options fail explicitly.

- **Diffusion NPU runtime isolation.** Keep the SRT CUDA-compatibility layer out of diffusion: when `sglang.multimodal_gen` is loaded, do not import `torch_npu.contrib.transfer_to_npu` and do not enable `torch_npu.npu.config.allow_internal_format`. Preserve the existing `torch.cuda.is_available=False` re-mock on the SRT path after `transfer_to_npu`. `jit_compile=False` remains unchanged.

- **MOVA 2-NPU correctness.** [#31453](https://github.com/sgl-project/sglang/pull/31453) left a contiguous-layout assumption after attention. Multi-NPU attention may return a non-contiguous tensor, so use `reshape()` instead of `view()`.

- **Host-memory accounting.** [#35641](https://github.com/sgl-project/sglang/pull/35641) introduced storage-based module sizing for host-memory budgeting. Skip tensors whose storage access raises `RuntimeError` instead of failing memory planning; add focused unit coverage.

- **NPU CI / GT.**
  - Restore the 2-NPU diffusion suite on `linux-aarch64-a3-800t-16`.
  - Split both 1-NPU and 2-NPU suites into two partitions.
  - Run GT generation on the A3-800T runner families.
  - Make GT jobs check out the requested `workflow_dispatch` ref.
  - Retry transient HTTP/image-decoding failures while downloading GT.
  - Update the NPU GT revision to `8e3d717e65fb87339c2974382a092a731669f884`.

- **NPU dependencies.** Pin `sgl-kernel-npu` to `2026.8.13` and install the packaged `attentions` wheel in NPU CI/Docker; update release Docker pins accordingly.

- **Performance baselines.** Refresh affected FLUX.2 text-encoding, ERNIE timestep-preparation, and LTX-2 connector/decoding baselines plus partition-duration estimates for the current A3-800T / auto-residency environment. Related residency policy: [#34615](https://github.com/sgl-project/sglang/pull/34615). These are CI baseline updates, not algorithmic speedups.

## Accuracy Tests

- NPU diffusion GT was regenerated successfully after the Ring semantic changes and A3-800T CI migration: [Generate Diffusion CI Ground Truth #32478548704](https://github.com/sgl-project/sglang/actions/runs/32478548704).
- Qwen Ring keeps the corrected semantics from #33327; no consistency thresholds are relaxed.
- Runtime isolation changes backend initialization/dispatch only; #20684 reported no accuracy impact from disabling the problematic internal-format behavior.
- The restored 2-NPU suite exercises the packed Ring path.
- Invalid-storage host-memory handling has dedicated unit coverage.

## Speed Tests and Profiling

The runtime fix prevents diffusion from inheriting SRT's global CUDA-compatibility monkey patches and `allow_internal_format=True`.
