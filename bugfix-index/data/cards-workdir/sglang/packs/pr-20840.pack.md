## Motivation

<!-- Describe the purpose and goals of this pull request. -->

DeepSeek-V3.2 accuracy drops from ~95% to 0% on MI355. 
[nightly CI test](https://github.com/sgl-project/sglang/actions/runs/23227025664/job/67511792991)

Root Cause:
- [PR#19826](https://github.com/sgl-project/sglang/pull/19826) changed the fp8 block-scaled gemm dispatch on gfx950 — for shapes not in the triton tuned list, it now falls back to the ck kernel.
- For shape (N=7168, K=2304), the ck kernel produces incorrect output, causing accuracy to collapse.

## Modifications

<!-- Detail the changes made in this pull request. -->

A quick workaround which adds (7168, 2304) to the list. Force to use triton kernel with this shape.
May remove later.
