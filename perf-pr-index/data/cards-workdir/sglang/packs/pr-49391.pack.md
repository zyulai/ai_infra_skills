## Change

Joy Image Edit uses `torch.addcmul` for image and text residual updates. The separate model profile shows 9,600 such calls per request. This change uses the existing `residual_gate_fp32` primitive for the 4,800 large image updates, retaining the FP32 product until the final BF16 cast. A per-signature `BitExactFusionGate` checks the actual native reference before retaining the fast path.

Eligibility is limited to contiguous BF16 `[B,S,D]` inputs with at least 16,777,216 elements on SM103. Small text updates, unsupported shapes/layouts/devices, autograd and compilation retain the native path. This three-file change adds no kernel, flag or model-level BCG support. The fused-kernel documentation and focused regression tests are updated.

- Frozen SGLang main: `5325cfabd757819e2e01bb7eb3b28c5b39b8cec9`.
- Tested PR head: `0b6e7007013da1b50a6030cbc408b60173e5e2e8`.
- Native vLLM-Omni: `725c1c9acd108d9f5248bd937489f19a2c560205`.
- Joy checkpoint: `jdopensource/JoyAI-Image-Edit-Diffusers@4b41fb25d961f37668750178ccbb380da326201c`.
