## Motivation

In deterministic mode on ROCm every custom all-reduce runs the 1-stage kernel: each GPU reads every peer's whole input and sums the ranks in the order 0..n-1. That order is what makes the result independent of the input size, but each GPU reads n times the data, so at TP4/TP8 the all-reduce takes a large share of the step: on MI350X, Qwen3-8B deterministic decode/prefill spends 48% of GPU time in it at TP4 and 63% at TP8 (8k-token inputs), and deterministic throughput at TP8 was about half of normal mode. The 2-stage kernel (reduce-scatter + all-gather) reads far less, but it cannot be used as is: each owner starts its sum at its own rank, so an element's result depends on which rank owns it, which changes with the input size. This PR adds a fixed-order option to the 2-stage kernel that sums the ranks in the same order as the 1-stage kernel, so the two give the same bits for every element at every size, and uses it for large inputs at 4 and 8 ranks. Results do not change; on MI350X deterministic throughput rises 16-24% at TP4 and 29-57% at TP8 on Qwen3-8B, and 28-54% at TP8 on Qwen3.8-27B, with every determinism check passing.

## Modifications

- `custom_all_reduce_hip.cuh`: `cross_device_reduce_2stage` gets a template parameter `kFixedOrder` (default `false`, so normal mode is unchanged). With it, stage 1 reads the ranks in the order 0..n-1 instead of starting at its own rank; stage 2 (the gather) is unchanged.
- `deterministic_all_reduce.hip`: one templated launcher instead of three copies per dtype. Inputs copied into the registered buffer (`deterministic_all_reduce_unreg`, which every deterministic call of `CustomAllreduce` uses for inputs that fit the buffer, including in CUDA graphs and the pieces of larger inputs) take the fixed-order 2-stage kernel with 32 blocks at or above 512 KiB at 4 ranks and 256 KiB at 8 ranks (the thresholds `CustomAllreduce::allreduce` uses); everything else keeps the 1-stage kernel with 16 blocks: smaller inputs, 2 and 6 ranks, and `deterministic_all_reduce_reg` (its inputs can be larger than the IPC buffer that the 2-stage kernel stages 1/n of the input in).
- New test `test/registered/kernels/ops/communication/test_amd_deterministic_allreduce_fixed_order.py` (`stage-c-test-large-8-gpu-amd-mi35x`): at 4 and 8 ranks, bf16 and fp16, sizes on both sides of the thresholds, eager and CUDA graphs, the all-reduce output must equal, bit for bit, the sum of the ranks' inputs computed in torch in the order 0..n-1 (float32 accumulation). The data is chosen so its float32 sum depends on the order of the ranks.

+"""The deterministic custom all-reduce on ROCm must sum every element over the ranks in
+the order 0..world_size-1, whatever the input size: it switches from the 1-stage to the
+2-stage kernel above a size threshold, and both must give exactly that sum. Checked bit
+for bit against the same sum computed with torch, at 4 and 8 ranks, in eager mode and in
+CUDA graphs, with data whose float32 sum depends on the order of the ranks.
+"""
+
+import multiprocessing as mp
+import os
+import socket
+import sys
+import traceback
+
+import pytest
+import torch
+import torch.distributed as dist
+
+from sglang.srt.utils import is_hip
+from sglang.test.ci.ci_register import register_amd_ci
+
+register_amd_ci(est_time=120, suite="stage-c-test-large-8-gpu-amd-mi35x")
+
+HIDDEN = 4096
+# Rows of HIDDEN bf16 values; 32 rows (256 KiB) and 64 rows (512 KiB) are the 2-stage
+# thresholds at 8 and 4 ranks. The largest size stays under the 16 MiB buffer.
+EAGER_ROWS = (1, 7, 31, 32, 33, 63, 64, 65, 128, 500, 1024, 2047)
+GRAPH_ROWS = (1, 16, 32, 64, 256)
+
+
+def _open_port():
+    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
+        s.bind(("127.0.0.1", 0))
+        return s.getsockname()[1]
+
+
+def _order_sensitive(rows, dtype, rank):
+    # Values of magnitude 2^12, 1 and 2^-12 with random signs: their float32 sum over the
+    # ranks rounds differently in a different order (randn data would hide that).
+    g = torch.Generator().manual_seed(1000 * rank + rows)
+    exp = torch.tensor([12.0, 0.0, -12.0])[
+        torch.randint(0, 3, (rows, HIDDEN), generator=g)
+    ]
+    sign = torch.randint(0, 2, (rows, HIDDEN), generator=g) * 2 - 1
+    return (sign * exp.exp2() * (1 + torch.rand(rows, HIDDEN, generator=g))).to(dtype)
+
+
+def _fixed_order_sum(x, world_size):
+    parts = [torch.empty_like(x) for _ in range(world_size)]
+    dist.all_gather(parts, x)
+    acc = parts[0].float()
+    for p in parts[1:]:
+        acc = acc + p.float()
+    return acc.to(x.dtype)
+
+
+def _worker(world_size, rank, port, failures):
+    try:
+        os.environ["SGLANG_USE_1STAGE_ALLREDUCE"] = (
+            "1"  # selects the deterministic path
+        )
+        torch.cuda.set_device(rank)
+        dist.init_process_group(
+            "nccl",
+            init_method=f"tcp://127.0.0.1:{port}",
+            rank=rank,
+            world_size=world_size,
+        )
+        from sglang.srt.distributed.device_communicators.custom_all_reduce import (
+            CustomAllreduce,
+        )
+
+        car = CustomAllreduce(
+            dist.new_group(backend="gloo"), torch.device("cuda", rank)
+        )
+        assert not car.disabled and car.use_amd_deterministic_impl
+        for dtype in (torch.bfloat16, torch.float16):
+            for rows in EAGER_ROWS:
+                x = _order_sensitive(rows, dtype, rank).cuda()
+                out = car.custom_all_reduce(x)
+                ref = _fixed_order_sum(x, world_size)
+                if not torch.equal(out, ref):
+                    failures.put(
+                        f"{world_size} ranks, rank {rank}, {dtype}, eager, {rows} rows"
+                    )
+            with car.capture():
+                graphs = {}
+                for rows in GRAPH_ROWS:
+                    static_in = torch.zeros(rows, HIDDEN, dtype=dtype, device="cuda")
+                    graph = torch.cuda.CUDAGraph()
+                    with torch.cuda.graph(graph):
+                        static_out = car.custom_all_reduce(static_in)
+                    graphs[rows] = (graph, static_in, static_out)
+            for rows, (graph, static_in, static_out) in graphs.items():
+                x = _order_sensitive(rows, dtype, rank).cuda()
+                static_in.copy_(x)
+                graph.replay()
+                torch.cuda.synchronize()
+                if not torch.equal(static_out, _fixed_order_sum(x, world_size)):
+                    failures.put(
+                        f"{world_size} ranks, rank {rank}, {dtype}, graph, {rows} rows"
+                    )
+        car.close()
+        dist.destroy_process_group()
+    except Exception:
+        failures.put(f"rank {rank}: {traceback.format_exc()}")
+

+@pytest.mark.parametrize("world_size", [4, 8])

+        for rank in range(world_size)
+    ]

+    for p in procs:
+        p.join(timeout=600)
+    found = []

+        found.append(failures.get())
+    assert all(p.exitcode == 0 for p in procs), found
