## Overview

ROCm support for [stepfun-ai/Step-5-Preview](https://huggingface.co/stepfun-ai/Step-5-Preview), complementing the NVIDIA support added in #61727. This PR adds a self-contained amd/ implementation under vllm/models/step5/ and moves the platform-independent Step-5 sparse-attention code from nvidia/ to common/.

The primary support and validation target is **MI300X/MI325X (gfx942)**. **MI355X (gfx950)** is also supported and has secondary validation from [@jamesETsmith](https://github.com/jamesETsmith).

## Claims

- Step-5-Preview FP8 weights serve at TP8 on ROCm with text and image input.
- Compressed sparse attention (CSA) runs on the 23 sparse layers for prefill, chunked prefill, decode, and MTP verification.
- The main paged K/V cache uses ROCm AITER unified attention. The sparse summary cache, speculative tail ring, region scoring, and split-K decode code are shared with the NVIDIA Step-5 path.
- Sparse layers support the default BF16 K/V cache and FP8 E4M3 K/V. FP8 K/V requires `--block-size 32`.
- Three-token MTP works through the Step-3.5 MTP proposer with comparable accuracy and about 2.3x speedup in the earlier GSM8K run.
- Prefix caching and P/D disaggregation are supported. NIXL and Mooncake keep compressed summary pages whole and reject unsupported page splitting.
- CSA uses the existing KV-cache lifecycle and does not require scheduler changes or GPU-to-CPU synchronization.

### Serving command (ROCm, MTP enabled)

<details>
<summary>Serve Step-5-Preview on 8x MI300X</summary>

```bash
VLLM_ROCM_USE_AITER=1 vllm serve stepfun-ai/Step-5-Preview \
  --tensor-parallel-size 8 \
  --max-model-len 32768 \
  --gpu-memory-utilization 0.90 \
  --moe-backend triton \
  --mm-encoder-attn-backend ROCM_AITER_FA \
  --mm-encoder-tp-mode data \
  --mm-processor-cache-type shm \
  --limit-mm-per-prompt '{"image":1,"video":0}' \
  --reasoning-parser step5 \
  --tool-call-parser step5 \
  --enable-auto-tool-choice \
  --speculative-config '{"method":"mtp","num_speculative_tokens":3}'

| Default K/V dtype | BF16 sparse K/V. |
| `--kv-cache-dtype fp8 --block-size 32` | Optional FP8 E4M3 sparse K/V. |

## Details

- **Layout:** `vllm/models/step5/{common,nvidia,amd}` with platform dispatch from `vllm/models/step5/__init__.py`. ROCm code lives only in `amd/`
- **Main K/V:** written by `unified_kv_cache_update` and consumed directly from the AITER unified paged layout.
- **Sparse state:** an FP8 summary cache plus a tail ring for incomplete and speculative regions, both attached to the existing KV-cache lifecycle.
- **Decode and MTP:** summary scoring, per-row top-k, and split-K paged attention support ordinary decode and four-row MTP verification, including the head-wise attention gate.
- **Scored prefill:** histories longer than `topk * region_size` use packed summary scoring. Startup warmup now covers this path  on ROCm it dispatches to `amd/warmup.py`
- **Indexer sharding:** Q and W are `ColumnParallelLinear` sharded by provider group; K and Z stay replicated.
- **P/D:** NIXL and Mooncake preserve compressed pages for compatible layouts and fail early if a layer-outer transfer would split one compressed state page. This check applies to every compressed-cache model.
- **MoE:** the shared expert runs inside FusedMoE, and the combined output is all-reduced once in the model dtype.
- **Graphs:** the CSA op is a graph-splitting op and uses real per-step metadata. Piecewise CUDA graphs are supported.

### Limitations

| Limitation | Follow-up |
|---|---|
| Piecewise CUDA graphs only | Make CSA metadata safe for full graphs |
| `--moe-backend triton` required | Add the post-SiLU clamp to AITER block-FP8 MoE |
| Sparse top-k still has unfused work | Fuse and optimize region selection |

+def _paged(
+    seqs: list[torch.Tensor], rows_per_page: int
+) -> tuple[torch.Tensor, torch.Tensor]:
+    """Scatter each request's rows into shared pages behind its own row of a
+    shuffled ``[requests, pages]`` block table."""
+    pages = [-(-x.shape[0] // rows_per_page) for x in seqs]
+    perm = torch.randperm(sum(pages) + 3, device=DEVICE).int()
+    table = torch.zeros(len(seqs), max(pages), dtype=torch.int32, device=DEVICE)
+    cache = torch.zeros(
+        (sum(pages) + 3, rows_per_page, *seqs[0].shape[1:]),
+        dtype=seqs[0].dtype,
+        device=DEVICE,
+    )
+    start = 0
+    for r, (x, n) in enumerate(zip(seqs, pages)):
+        table[r, :n] = perm[start : start + n]
+        start += n
+        idx = torch.arange(x.shape[0], device=DEVICE)
+        cache[table[r, idx // rows_per_page].long(), idx % rows_per_page] = x
+    return cache, table

+def ref_select(scores: torch.Tensor, positions: torch.Tensor, topk: int):
+    tokens, groups, _ = scores.shape
+    out = torch.full((tokens, groups, topk + 1), -1, dtype=torch.int32)
+    for t in range(tokens):
+        own = int(positions[t]) // REGION
+        for g in range(groups):
+            order = torch.argsort(-scores[t, g, :own].cpu(), stable=True)[:topk]
+            row = torch.cat([torch.sort(order).values, torch.tensor([own])])
+            out[t, g, -row.numel() :] = row.to(torch.int32)
+    return out

+def ref_attention(q, k, v, regions, req, positions, scale):
+    tokens, heads, _ = q.shape
+    groups = k.shape[2]
+    per_group = heads // groups
+    out = torch.zeros(q.shape, dtype=torch.float32)
+    for t in range(tokens):
+        kr, vr = k[int(req[t])], v[int(req[t])]
+        for g in range(groups):
+            ids = regions[t, g]
+            ids = ids[ids >= 0].long().cpu()
+            cols = (ids[:, None] * REGION + torch.arange(REGION)).flatten()
+            cols = cols[cols <= int(positions[t])]
+            hs = slice(g * per_group, (g + 1) * per_group)
+            p = torch.softmax(
+                q[t, hs].float().cpu() @ kr[cols, g].float().cpu().T * scale, -1
+            )
+            out[t, hs] = p @ vr[cols, g].float().cpu()
+    return out

+def _quant_kv(k, v, kv_dtype):
+    """KV as stored (FP8 with per-tensor scales, or BF16) and as the reference

+    scales = [torch.tensor([x], dtype=torch.float32, device=DEVICE) for x in (k_s, v_s)]
+    return kq, vq, kq.float() * k_s, vq.float() * v_s, *scales

+def verify_kv_transfer_compatibility(vllm_config: VllmConfig) -> None:
+    config = vllm_config.kv_transfer_config
+    if config is None or not config.is_kv_transfer_instance:
+        return
+    configs = [config]
+    if config.kv_connector == "MultiConnector":
+        children = config.kv_connector_extra_config["connectors"]
+        configs = [KVTransferConfig(**child) for child in children]
+    if not all(
+        c.kv_connector == "MooncakeStoreConnector"
+        or (c.kv_connector == "NixlConnector" and c.kv_buffer_device == "cuda")
+        for c in configs
+    ):
+        raise ValueError(
+            "Step5 sparse summaries are only transferred by "
+            "MooncakeStoreConnector, or by NixlConnector with device buffers, "
+            "directly or under a MultiConnector."
+        )

+
+def _groups_per_rank(total_groups: int, tp_size: int) -> int:
+    if total_groups % tp_size == 0:
+        return total_groups // tp_size
+    if tp_size % total_groups == 0:
+        return 1
+    raise ValueError(
+        f"Step5 tensor parallel size {tp_size} is incompatible with "
+        f"group count {total_groups}: one must divide the other."
+    )
+
+
+def validate_parallel_geometry(
+    *,
+    total_num_heads: int,
+    total_num_kv_heads: int,
+    indexer_num_heads: int,
+    index_tp_size: int,
+    tp_size: int,
+) -> None:
+    """The indexer scores regions per provider group and attention reads the
+    matching KV group, so both partitions must agree globally and per rank."""
+    if index_tp_size != total_num_kv_heads:
+        raise ValueError(
+            "Step5 sparse provider groups must match attention KV groups: "
+            f"{index_tp_size} != {total_num_kv_heads}"
+        )
+    if indexer_num_heads % index_tp_size:
+        raise ValueError(
+            f"{indexer_num_heads} sparse indexer heads do not divide into "
+            f"{index_tp_size} provider groups."
+        )
+    if total_num_heads % tp_size:
+        raise ValueError(
+            f"Step5 attention heads ({total_num_heads}) must be divisible by "
+            f"the tensor parallel size ({tp_size})."
+        )

+        raise ValueError(

+        )
