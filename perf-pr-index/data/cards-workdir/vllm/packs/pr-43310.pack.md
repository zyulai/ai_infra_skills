## PR body
```markdown
### Summary

Expose the existing opt-in per-request speculative decoding metrics in the token-in/token-out `/inference/v1/generate` API through the same `metrics.speculative_decoding` response shape used by the OpenAI-compatible endpoints.

Full responses include metrics for single-sequence requests. Streaming follows Chat/Completion: metrics are returned once in the final usage chunk (`choices=[]`) when `stream_options.include_usage=true`; token chunks are unchanged. Chat and Completion derendering preserve the metrics object. Python suppresses request-level metrics for `n>1`; Rust rejects parallel sampling.

Requires `--per-request-spec-decode-metrics`; collection remains disabled by default. Python and Rust frontends are covered. This does not change model execution or sampling.

### Why this is not duplicate work

#48915 provides the shared metrics pipeline and OpenAI API exposure. This PR exposes that same pipeline through the separate token-in/token-out API without another scheduler accumulator or a second public schema.

### Validation

- Python spec-metrics tests: 6 passed, covering full/stream responses, terminal usage placement, and `n>1` suppression.
- Streaming derender metrics passthrough test passed.
- Rust `vllm-server` generate tests: 62 passed, including streaming and non-streaming metrics propagation and JSON serialization.
- Changed-file pre-commit passed, including mypy, ruff, markdownlint, and Rust format.
- GB200 E2E: Qwen3-0.6B with n-gram speculation returned identical metrics in the full response and final streaming usage chunk; token chunks contained no metrics.

### AI assistance

Codex assisted with implementation and tests. Claude performed multiple read-only adversarial review rounds. Human review remains required.
```

```diff
+impl From<RequestSpecDecodeMetrics> for SpeculativeDecodingMetrics {
+    fn from(raw: RequestSpecDecodeMetrics) -> Self {
+        let num_spec_steps: u64 = raw.histogram.iter().sum();
+        let num_accepted_draft_tokens: u64 =
+            (0u64..).zip(&raw.histogram).map(|(accepted, count)| accepted * count).sum();
+        let ratio = |num: u64, den: u64| {
+            if den == 0 {
+                0.0
+            } else {
+                num as f64 / den as f64
+            }
+        };
+        let detailed = !raw.per_step_accepted.is_empty();
+        Self {
+            mean_acceptance_length: if num_spec_steps == 0 {
+                1.0
+            } else {
+                1.0 + ratio(num_accepted_draft_tokens, num_spec_steps)
+            },
+            draft_acceptance_rate: ratio(num_accepted_draft_tokens, raw.num_draft_tokens),
+            acceptance_histogram: raw.histogram,
+            num_spec_steps,
+            num_accepted_draft_tokens,
+            num_draft_tokens: raw.num_draft_tokens,
+            num_spec_tokens: raw.num_spec_tokens,
+            per_step_accepted: detailed.then_some(raw.per_step_accepted),
```
