## 正文(PR 描述)

PR #34127 added attention mask propagation through the shared `Idefics2VisionTransformer` encoder to fix MiniCPM-o 4.5. However, this encoder is also used by Aria (and Phi4MM), which do not apply masking in their vision attention layers, they only use `patch_attention_mask` at the embedding stage. This caused output divergence for Aria, breaking `test_multi_image_models[aria-test_case95]`.

## Fix

Add an `apply_encoder_attention_mask` flag (default `False`) to `Idefics2VisionTransformer`. Only MiniCPM model classes opt in by passing `apply_encoder_attention_mask=True` when constructing the vision module. All other consumers (Aria, Phi4MM) retain the previous no-mask behavior.

## Changes

- `idefics2_vision_model.py`: Add `apply_encoder_attention_mask` param, gate the additive mask construction on it
- `minicpmv.py`: Pass `apply_encoder_attention_mask=True` in `init_vision_module` for v2.5, v2.6, v4.0, and v4.5

No changes to `aria.py` or `phi4mm.py`, they inherit the default.
