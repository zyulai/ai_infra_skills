## Motivation

HiCache NIXL storage backend in python/sglang/srt/mem_cache/storage/nixl/hicache_nixl.py, does not honor storage_config from engine. The backend has no idea about tp_rank and tp_size, so differen workers write to the same file/object repeatly , if tp size is more than 1. Such overwrite will cause corruption when cache data is loaded and reused.

## Modifications

Updated hicache_nixl.py to align its file and object naming scheme with the naming scheme used in the HiCacheFile class
Updated cache_controller.py and test_hicache_nixl_storage.py accordingly
