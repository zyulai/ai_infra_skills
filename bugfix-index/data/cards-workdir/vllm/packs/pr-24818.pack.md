## 正文(PR 描述)

- Changed `layer.moe` to `layer` in AWQ MoE method
- Changed `layer.moe` to `layer` in GPTQ MoE method
- FusedMoE object doesn't have .moe attribute, should use layer directly

This fixes AttributeError: 'FusedMoE' object has no attribute 'moe' when using "auto_round" quantization with FusedMoE layers."
