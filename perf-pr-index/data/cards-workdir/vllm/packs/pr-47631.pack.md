## Purpose
This PR supports fusing Minimax M3's MoE layers' allreduce with next's layer's input norm.

## Performance

  --tensor-parallel-size 2 \
  --kv-cache-dtype fp8 \

  --block-size 128 \
  --language-model-only \
  --max-cudagraph-capture-size 2048 \
  --max-num-batched-tokens 16384 \
  --stream-interval 20 \
  --no-enable-prefix-caching \
  --trust-remote-code
