## Motivation

Cherry-pick of upstream PR #22911 ([perf] support return_routed_experts with overlap scheduling, commit `c5603268`) onto the `sglang-miles` branch.

Previously, the routed-experts capture path issued a synchronous device-to-host copy inside the forward step (`out_cache_loc.cpu()` + `device_cache.buffer[...].cpu()`), which forced the GPU to drain and broke the overlap scheduler. This made `--return-routed-experts` unusable in overlap mode.

## Modifications

- Add `RoutedExpertsOutput` dataclass that holds GPU tensors plus a reference to the host cache, with `copy_to_cpu()` (called inside the forward stream before `copy_done.record()`) and `finalize()` (called after `copy_done.synchronize()`).
- Refactor `_RoutedExpertsCapturerReal` to extract `_get_local_range` and add `_prepare_routed_experts_output`; `on_forward_end` now takes `no_copy_to_cpu=False` and returns an `Optional[RoutedExpertsOutput]`.
- In `model_runner.py`, set `no_copy_to_cpu = not server_args.disable_overlap_schedule` so the deferred path is used whenever overlap is enabled, and surface the result on `ModelRunnerOutput.routed_experts_output`.
- Plumb `routed_experts_output` through `GenerationBatchResult`, `TpModelWorker`, and both `EAGLEWorkerV2` / `MultiLayerEagleWorkerV2`.
- In `SchedulerOutputProcessorMixin`, after `copy_done.synchronize()`, call `routed_experts_output.finalize()` and clear the field.

### Conflict resolution

Resolved conflicts in `routed_experts_capturer.py` and `model_runner.py` to keep the following miles-side changes on top of upstream's `_get_local_range` / `no_copy_to_cpu` refactor:
- Draft-worker guard around `on_forward_end` (`if not self.is_draft_worker:`).
- `bs * num_tokens_per_bs` cuda_graph token-count fix for spec decoding.
- DeepEP all-gather path: skip DP-rank slicing when DeepEP is enabled (the `is_dp_attention_enabled() and not get_moe_a2a_backend().is_deepep()` guard).

## Accuracy Tests

Router replay accuracy test (`test_return_routed_experts`) passes 3/3 with **0 mismatches across ~26.7M expert IDs**.

## Speed Tests and Profiling

H200 TP=4, Qwen3-30B-A3B, batch=64, in=1024, out=512:

| Mode | Output throughput |
|---|---|
| Before (sync DtoH inside forward) | 7453.48 tok/s |
| After (deferred copy via `RoutedExpertsOutput`) | **8609.21 tok/s** |

→ **+15.5%** end-to-end output throughput with `--return-routed-experts` enabled in overlap mode.
