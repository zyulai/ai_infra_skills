## PR body
```markdown
## Purpose

Extend generation-side watermark context deduplication to speculative decoding.

- Build target verification contexts from committed and proposed draft tokens.
- Detect repeated contexts in committed history and earlier positions of the same speculative block while respecting `deduplicate_contexts_max_history`.
- Use the ordinary draft proposal at repeated contexts before running the unchanged acceptance test.
- Use the ordinary draw from the existing residual or target distribution for repeated rejection-recovery and bonus contexts.
- Leave disabled and greedy requests on their existing paths.
- Fuse committed-history and speculative-local context checks to avoid launch-heavy PyTorch bookkeeping.
- Fuse ordinary and watermarked draft sampling into one vocabulary reduction while preserving the pre-temperature draft-logit cache.

This keeps the standard `min(1, q/p)` acceptance rule and does not force rejection at repeated contexts.

## Test Plan

- Run the focused CPU watermark/configuration tests.
- Run all pre-commit hooks applicable to the changed files.
- Run the watermark suite and CPU/Triton parity tests on an H100.
- Microbenchmark draft, target-mask, rejection-resampling, and fused draft-sampling overhead separately.

## Test Result

- `python -m pytest -q tests/watermarking/test_watermarking.py`: 51 passed, 18 skipped locally.
- Watermarking and Gumbel suites on an H100: 95 passed.
- Fused draft sampling exactly matches the previous ordinary/watermarked selection, including draft-specific RNG streams and bit-exact pre-temperature logits caching.
- Applicable Ruff, formatting, syntax, mypy, configuration, accelerator API, and sign-off checks: passed.

### H100 microbenchmark

The new fused draft-sampling path was compared with the previous sequence—ordinary draft sampling with cache write, watermarked sampling, then `torch.where`. Both paths include temperature preprocessing and draft-logit cache writes, use float16 logits with vocabulary size 32768, and report the median of five 1000-iteration measurements.

| Batch size | Previous two-pass path | Fused mixed path | Time saved per draft step | Sampling-section speedup |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 91.31 us | 57.40 us | 33.91 us | 1.59x |
| 8 | 92.96 us | 58.14 us | 34.82 us | 1.60x |
| 32 | 92.62 us | 58.13 us | 34.49 us | 1.59x |

These are isolated eager-execution microbenchmark timings, not end-to-end inference throughput measurements.
```
