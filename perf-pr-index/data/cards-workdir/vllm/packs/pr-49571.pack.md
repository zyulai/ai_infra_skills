## Purpose
Optimize `expf` computation on PowerPC CPUs via VSX vectorization (`DEFINE_FAST_EXP`). 
## Test Plan

1. **CPU Attention Microbenchmark**  
   Run `benchmark_cpu_attn.py`.
   ```bash
   python benchmarks/kernels/cpu/benchmark_cpu_attn.py
   ```

2. **End-to-End Throughput Benchmark**  
   Run `benchmark_throughput.py` to measure the overall token generation speedup.
   ```bash
    vllm bench throughput \
       --model ibm-granite/granite-3.1-8b-instruct \
       --dataset ShareGPT_V3_unfiltered_cleaned_split.json \
       --num-prompts 100 \
       --dtype bfloat16
   ```
