## 正文(PR 描述)

## Summary

- keep `fastsafetensors` enabled for the target model, where every pipeline stage participates in its WORLD-group collectives;
- fall back to the standard safetensors loader only for an external draft model when PP > 1;
- apply the PP-safe draft load configuration to EAGLE/EAGLE3, DFlash, and DSpark without changing PP=1 or other load formats.

Fixes #50959.

## Why a draft-only fallback

With speculative decoding under pipeline parallelism, the external draft model is instantiated only on the last PP stage. `fastsafetensors` currently uses WORLD-group broadcasts, so ranks on that stage wait for ranks that never enter the draft loader.

Using the stage's TP subgroup is not yet a safe workaround: the installed `fastsafetensors` PyTorch adapter passes subgroup-local source ranks to `torch.distributed` as global ranks. On the second PP stage this fails immediately with `ValueError: Global rank 0 is not part of group`.

The draft checkpoint is much smaller than the target checkpoint, so this PR preserves the fast target load while selecting the existing, collective-free loader for only the draft. The `LoadConfig` is copied, leaving the target configuration unchanged.
