## PR body
```markdown
## Purpose
On ROCm's DeepSeek-V4.1's path each mHC seam runs today as a chain of separate aiter kernels, with the RMSNorm as one more standalone pass over the collapse. Aiter ships a fused kernel for the whole seam now https://github.com/ROCm/aiter/pull/5824, a split-K main kernel (post-mix, bf16 residual write, gate projection, square sums) plus a per-token reduce (gates including the Sinkhorn loop, RMSNorm applied in place to the collapse): two launches per seam. This PR wires vLLM to it on gfx950.
