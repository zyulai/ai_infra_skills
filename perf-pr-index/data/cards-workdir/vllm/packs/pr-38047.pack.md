## Purpose

This PR switches to CPU boolean masks and fixes the `output_size` in `repeat_interleave`  to remove GPU/CPU syncs in `GDNAttentionMetadata.build` during speculative decoding. Indexing with a boolean mask on GPU can't be done asynchronously. Since https://github.com/pytorch/pytorch/pull/156384 if the boolean mask is on CPU this can be done async. 

## Test Plan
I verified in the torch profile that the syncs are gone and ran a quick benchmark showing 7% improved throughput and 20% lower TTFT.

```
vllm serve Qwen/Qwen3.5-2B --limit-mm-per-prompt.video 0 --speculative-config '{"method": "mtp", "num_speculative_tokens": 1}'

vllm bench serve --backend openai-chat --model Qwen/Qwen3.5-2B --endpoint /v1/chat/completions --dataset-name sharegpt --dataset-path ./ShareGPT_V3_unfiltered_cleaned_split.json --num-prompts 1000
```
