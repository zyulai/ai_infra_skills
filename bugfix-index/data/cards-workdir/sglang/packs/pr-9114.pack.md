## Motivation

Fix accuracy test.

Root cause: Llama3.1-8B-Instruct's [chat_template](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct?chat_template=default#L24-L29) has a field called `builtin_tools`. It works in conflict with `tools`. In #9043 , we passed this field as `[]` to `tokenizer.apply_chat_template` for gpt-oss. However this field doesn't need to be set for gpt-oss either.

<!-- Describe the purpose and goals of this pull request. -->

## Modifications

Remove `builtin_tools=[]`. This won't affect gpt-oss models. It checks if `builtin_tools` is set. As long as we don't set it, it is fine.
