## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Reduce preparation overhead for GDN multi-item scoring (MIS), building on #48585.
Each query/item segment already has a map to its original token rows. The
baseline gathers the corresponding `a` and `b` gate rows, splits/normalizes
post-convolution QKV, then launches standalone gating.

This PR reads gate rows directly through that map inside QKV preparation:

| Per query/item segment | Baseline | This PR |
| --- | --- | --- |
| QKV split and Q/K normalization | One preparation kernel | Same preparation kernel, extended with gate computation |
| Select `a` and `b` rows | Two gathered temporary tensors | Direct mapped loads |
| Compute `g` and `beta` | Separate gating kernel | Included in preparation |
| Convolution, recurrence, state updates | Existing MIS behavior | Unchanged |

On the tested H200/Qwen3.5-0.8B BF16 workload, median serving throughput improves
**1.1-5.5%**. Canonical preparation alone is **2.75x faster at 198 tokens** and
**1.82x faster at 4096 tokens**; these microkernel factors are not end-to-end
speedup claims.

## Modifications

<!-- Detail the changes made in this pull request. -->

- **Preparation:** Add `fused_qkv_gating_gdn_prefill`, sharing the existing split
  launcher and Q/K normalization. It returns contiguous Q/K/V and FP32 gates;
  the existing `fused_qkv_split_gdn_prefill` signature/three-output contract stays
  unchanged.
- **Numerics/layouts:** Share the standalone softplus/sigmoid expression,
  including sigmoid rounding through `b.dtype` before FP32 storage. Support
  strided inputs/parameters and contiguous int32/int64 maps, with address
  arithmetic widened before stride multiplication. Map contents are not read
  on the host; callers supply in-range source rows.
- **MIS dispatch:** Pass original gates plus the segment map on CUDA/HIP when
  packed QKV width is at most 8192. The existing shape/device fallback still
  gathers gates and uses standalone gating. Query/item state ownership,
  output mapping, padding and normalization ownership remain unchanged.
- **Tests:** Cover mapped gates, layouts, large strides and fallback behavior.
  Keep the inherited normalization-composition test with its original seeded
  inputs/FP16 bound, and separately require exact mapped-gating composition
  parity against the same inherited normalization plus standalone gating.

Standalone gating/split callers, FLA normalization and FlashInfer's separate
preparation contract are retained. No serving flag, recurrent algorithm,
recommended deployment, decode/verification behavior or backport changes.
This change is developed with GitHub Copilot assistance.

```python
import argparse
import asyncio
import json
import time

import aiohttp
import numpy as np

parser = argparse.ArgumentParser()
parser.add_argument("--kind", choices=("pointwise", "setwise"), default="pointwise")
parser.add_argument("--length", choices=("short", "long"), default="short")
parser.add_argument("--items", type=int, choices=(1, 2, 8), default=2)
parser.add_argument("--concurrency", type=int, choices=(1, 8), default=1)
args = parser.parse_args()

query = "Judge the statements. " * (8 if args.length == "short" else 256)
items = []
for i in range(args.items):
    repeats = 1 + i % 3 if args.length == "short" else 16 + i * 3
    item = f"Candidate {i}. " + "The sky is blue. " * repeats
    if args.kind == "setwise":
        item += "<|object_ref_start|>"
        item += "Water freezes. <|object_ref_start|>" * (i % 3)
    items.append(item)
if args.items == 1:
    query, items = "Judge the statement.", ["The sky is blue."]

payload = dict(
    query=query, items=items, label_token_ids=[9175, 2665], apply_softmax=False
)
if args.kind == "setwise":
    payload["score_extraction_token"] = "<|object_ref_start|>"

async def trial():
    limit = asyncio.Semaphore(args.concurrency)
    timeout = aiohttp.ClientTimeout(total=180)
    async with aiohttp.ClientSession(timeout=timeout) as session:
        async def one():
            async with limit:
                start = time.perf_counter()
                async with session.post(
                    "http://127.0.0.1:31249/v1/score", json=payload
                ) as response:
                    text = await response.text()
                    if response.status != 200:
                        raise RuntimeError(f"HTTP {response.status}: {text}")
                    result = json.loads(text)
                    if not result["scores"]:
                        raise RuntimeError("Empty scores")
                    return time.perf_counter() - start, result
        start = time.perf_counter()
        rows = await asyncio.gather(
            *(one() for _ in range(10 * args.concurrency))
        )
        elapsed = time.perf_counter() - start
    return elapsed, rows

async def main():
    await trial()  # Matched-concurrency warmup; not included in measurements.
    elapsed, rows = await trial()
    print(json.dumps({
        "payload": payload,
        "requests": len(rows),
        "requests_per_s": len(rows) / elapsed,
        "p50_p95_p99_ms": np.quantile(
            [row[0] * 1000 for row in rows], [0.50, 0.95, 0.99]
        ).tolist(),
        "responses": [row[1] for row in rows],
    }))

asyncio.run(main())
```
