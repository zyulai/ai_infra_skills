## 正文(PR 描述)

## Motivation

The default value for `--flashinfer-mxfp4-moe-precision` should be `default` instead of "mxfp4". The previous version will cause problem if use the `ServerArgs.add_cli_args` function to add argument.

## Modifications

Only the choice of `--flashinfer-mxfp4-moe-precision` has been modified.
