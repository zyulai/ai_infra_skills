## PR body
```markdown
## Changes

- Adds `vllm:prompt_tokens_cached_by_source_total{source}` with five values: `device`, `host`, `p2p`, `disk`, `external_unspecified`.
- Counts cache hits at admission. Source counts sum to local and external prefix-cache hits. Existing prompt-token counters are unchanged.
- Records attribution through the existing `PrefixCacheStats` path. Connectors return typed counts through `get_external_cache_hit_sources`. Incorrect totals fall back to `external_unspecified` with a one-time warning.
- Simple offload reports `host` or `disk`. NIXL, Mooncake transfer and MoRIIO report `p2p`. Mooncake Store and uninstrumented connectors report `external_unspecified`. MultiConnector delegates to the selected connector.
- Native offload uses the keys selected for loading. Mixed KV-group dependencies use the outermost required tier, so host + disk reports `disk`. Missing attribution reports `external_unspecified`. Promotion preserves the initiating request's original tier.
- Supports Python and Rust frontends.

Closes vllm-project/vllm#53368.

## Validation

[Passed Run Sweep](https://github.com/SemiAnalysisAI/InferenceX/actions/runs/36272389390): DeepSeek-V4-Pro, one-hour AIPerf AgentX profiles, evaluations disabled. AIPerf scraped Prometheus. JSON/CSV source counts and accounting checks passed.
```
