## 正文(PR 描述)

## Motivation

Improve LTX-2 / LTX-2.3 diffusion accuracy against official-generated outputs, especially for multi-GPU CI cases and the LTX-2.3 HQ two-stage path.

The previous LTX-2.3 multi-GPU CI settings had weak consistency thresholds for some cases and could use parallelism modes that were either slower or less aligned with the official output. The HQ path also regressed on the PR #23366 SpongeBob repro.

Transformer fp8-cast is intentionally **not** included in this PR. It did not materially help this PR's target CI paths, and any future precision branch can keep or reintroduce it as a separate opt-in change.

## Modifications

- Tighten LTX consistency coverage:
  - switch selected LTX multi-GPU CI cases to the fastest verified TP/CFG-parallel settings instead of SP/Ulysses where those modes hurt accuracy or performance;
  - tighten thresholds for `ltx_2.3_one_stage_ti2v`, `ltx_2.3_two_stage_t2v_2gpus`, and `ltx_2_3_two_stage_ti2v_2gpus`.
- Improve LTX-2.3 HQ numerical alignment:
  - keep RoPE frequency generation on the target device to preserve the validated LTX-2.3 HQ rounding trajectory;
  - honor `frequencies_precision="float64"` from LTX/Diffusers configs;
  - restore the HQ res2s noise dtype boundary and stage-2 sigma-space res2s math.
- Fix two-stage / parallel runtime details:
  - let secondary components such as `transformer_2` inherit the base component attention backend unless explicitly overridden;
  - use the CFG process group's global source rank when broadcasting pipeline batches;
  - handle older FA3 varlen kernels that do not accept an `out=` keyword.
- Preserve explicit transformer quantization semantics:
  - explicit `--quantization` now takes precedence over checkpoint metadata when resolving transformer quant configs.

## Accuracy Tests

Remote validation collected during this PR series:

- PR #23366 LTX-2.3 HQ repro, 1 GPU, `LTX2TwoStageHQPipeline`, 768x512, 241 frames, 30 steps, seed 10:
  - old PR attachment vs official: `PSNR=20.707109`
  - fixed branch vs official: `PSNR=20.722057`
- `ltx_2.3_one_stage_ti2v`, 2 GPUs, CFG parallel:
  - `clip=0.9396`, `SSIM=0.8254`, `PSNR=22.2667`, `mean_abs_diff=8.3209`
- `ltx_2.3_two_stage_t2v_2gpus`, 2 GPUs, CFG parallel + resident:
  - `clip=0.9545`, `PSNR=16.4739`, `mean_abs_diff=26.4187`

Final CI remains the source of truth for per-machine variance.
