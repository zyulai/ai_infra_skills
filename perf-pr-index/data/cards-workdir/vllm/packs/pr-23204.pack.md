## PR body
```markdown
## Purpose

The original marlin integration was tied to a new "marlin" checkpoint format that was optional in AutoGPTQ. Since most users continued to make gptq-format checkpoints, we developed out "gptq_marlin" support much more and expanded it into awq_marlin, fp8, nvfp4, mxfp4. So let's remove the original kernels and format that are unused at this point.

Same for QQQ, which is a w4a8 format that hasn't seen much adoption. It only has 11 models on HF https://huggingface.co/models?other=qqq
<img width="1305" height="855" alt="Screenshot 2025-08-19 at 5 47 27 PM" src="https://github.com/user-attachments/assets/0a146a99-5781-426a-9d4d-821e7624eee8" />

I found that Machete was building kernels for w4a8 but they weren't used anywhere, so just commented out those configs for now.
```
