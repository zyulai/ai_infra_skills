## Motivation

<!-- Explain the purpose of this PR and the goals it aims to achieve. -->

The previous PR had memory leak issue. This PR makes the following changes:

1. Remove transfer failed requests
2. Add `DISAGGREGATION_TEST_FAILURE_PROB` to simulate failure for testing
3. In chunk_cache, properly adjust num kv indices to free
4. Refactor: extract `ScheduleBatchDisaggregationDecodeMixin`
