## Motivation

Add Pi0.5 checkpoint calibration and native FP8 inference using SGLang’s existing ModelOpt FP8 linear backend.

The quantization coverage and synthetic calibration recipe follow https://jetson-ai-lab.com/tutorials/openpi\_on\_thor/.

## Modifications

- Add a calibration/export tool supporting observation datasets and explicitly selected synthetic inputs.
- Quantize PaliGemma and action-expert fused projections, SigLIP encoder projections, the multimodal projector, and action input/output heads using per-tensor E4M3 weights and static activation scales.
- Preserve existing tensor/tuple interfaces and output dtypes. Keep embeddings, convolutions, norms, AdaRMS dense layers, and time MLPs unquantized.
- Add checkpoint validation, projection replacement, and FP8 weight finalization.
- Support resident BF16 inference on a single SM89+ NVIDIA GPU; reject TP/SP and component offload.
- Add CPU contract tests and a CUDA calibration, checkpoint-loading, and graph-replay test.

## Accuracy Tests

Validated on RTX 4090 D with PyTorch 2.13.0+cu130, ModelOpt 0.47.0, and Transformers 5.12.1.

- Full Pi0.5 Libero checkpoint: calibrated all five supported components using one synthetic observation, then validated on four separate synthetic observations.

Consistency metrics use only the **10 predicted steps and 7 returned action dimensions**:

| Comparison | Mean absolute difference | Maximum absolute difference | Cosine similarity |
|---|---:|---:|---:|
| BF16 vs native FP8 | 0\.008364 | 0\.100873 | 0\.999526 |
| Fake quant vs native FP8 | 0\.006177 | 0\.059110 | — |

Cosine similarity flattens the four observations into one vector. Per-observation BF16/FP8 cosine similarities range from **0\.999384 to 0.999659**.

All returned actions were finite. Eager and CUDA Graph outputs matched exactly for both BF16 and FP8 across the four observations, including changed inputs.

These results validate numerical behavior on synthetic observations. Real robot task accuracy and success rates have not been evaluated.

## Speed Tests and Profiling

Measured full Pi0.5 Libero model inference on one RTX 4090 D, batch size 1, three 224×224 camera inputs, 200 tokens, and 10 denoising steps, using `torch_sdpa`.

Each mode uses 5 warmup runs and 30 timed runs with CUDA synchronization. Timing includes prefix encoding and action sampling from preprocessed inputs, without prefix-cache reuse. It excludes preprocessing, network overhead, checkpoint loading, and initial graph capture.

| Mode | BF16 median latency | FP8 median latency | BF16/FP8 speedup | BF16 peak allocated memory | FP8 peak allocated memory |
|---|---:|---:|---:|---:|---:|
| Eager | 248\.44 ms | 360\.67 ms | 0\.69× | 6\.71 GiB | 4\.22 GiB |
| CUDA Graph | 70\.97 ms | 55\.53 ms | 1\.28× | 6\.72 GiB | 4\.22 GiB |

CUDA Graph latency decreased by **21\.8%**, with **37\.2% lower peak allocated memory**. Eager latency increased by **45\.2%**; the measured speed improvement applies to CUDA Graph execution.

+def _is_selected_projection(name: str, component: str) -> bool:
+    prefix = _COMPONENT_PREFIXES[component]
+    if not name.startswith(prefix):
+        return False
+    suffix = name[len(prefix) :]
+    if component == "vision":
+        return bool(_VISION_PROJECTION.fullmatch(suffix))
+    if component == "projector":
+        return suffix == "linear"
+    if component == "action_heads":
+        return suffix in ("in_proj", "out_proj")
+    return bool(_PROJECTION.fullmatch(suffix))

+def _wrap_tuple_output(module, inputs, output):
+    """Forward hook preserving SigLIP's (output, bias) interface during calibration.
+
+    ModelOpt calibration replaces SGLang linears with nn.Linear, which returns
+    only a tensor. Wrap that tensor so existing callers can still unpack it.
+    nn.Linear already adds the bias to output, so no separate bias is returned.
+    """
+    return output, None

+class Pi05Fp8Linear(ReplicatedLinear):
+    """Preserve each caller's tensor/tuple interface and high-precision output."""

+        self.out_features = self.output_size

+        output = output.to(self.output_dtype)
+        return output if self.tensor_output else (output, bias)

+def _validate_components(components: list[str]) -> list[str]:

+    if selected - _COMPONENT_PREFIXES.keys():

+    return components
