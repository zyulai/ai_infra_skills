## Motivation

TestGLM41VPPAccuracy is very flaky: UT mmmu acc ranges from 0.3 to 0.5 which makes it very hard to pass the test

There are two issues:
- GLM4+ models return answer in a specific format `"<\|begin_of_box\|>some_answer<\|end_of_box\|>"` which cannot be easily recognized by current SGLang mmmu answer extraction regex engine. Thus, we need to manually tune the regex to extract the answer correctly specifically for GLM4+ models
- reasoning-parser is needed - otherwise reasoning content will be filled into regular content and pollute there

## Accuracy Tests

Got 3 local consistent success run with mmmu score 0.50 > 0.45 (hard threshold defined in the CI)
