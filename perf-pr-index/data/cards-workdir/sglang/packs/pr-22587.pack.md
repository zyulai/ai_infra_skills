## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The current EPD (Encoder-Prefill-Decode) disaggregation architecture with the Mooncake backend transfers vision embeddings from the Encoder server to the Prefill server through a **CPU-staged** path: after ViT forward on the Encoder GPU, the embedding tensor is moved to CPU (`new_embeddings.cpu()`), then transferred via Mooncake to a CPU buffer on the Prefill side, and finally copied back to GPU for LLM prefill. This CPU round-trip (D2H → RDMA → H2D) introduces unnecessary latency and memory bandwidth overhead, especially for large multimodal inputs (e.g., multi-image MMMU tasks).

This PR optimizes the Mooncake backend to enable **GPU-to-GPU zero-copy RDMA transfer** by:
1. Keeping ViT embeddings on GPU after forward pass (no `.cpu()` call).
2. Pre-allocating GPU-side receive buffers on the Prefill server and registering them with the Mooncake engine.
3. Using GPUDirect RDMA to transfer embeddings directly from Encoder GPU memory to Prefill GPU memory.
4. This approach decouples VIT inference from metadata return, enabling overlapped computation and communication for better end-to-end performance.

## Modifications

<!-- Detail the changes made in this pull request. -->

### `python/sglang/srt/disaggregation/encode_receiver.py`
- **New class `WaitingImageRDMARequest`**: Extends `WaitingImageRequest` to support GPU-to-GPU RDMA transfers. Implements:
  - A two-phase encode flow: `POST /encode` (returns metadata incl. `embedding_size`) → pre-allocate GPU buffer → `POST /send` (triggers RDMA write).
  - GPU buffer lifecycle management: allocation on `cuda:<gpu_id>`, Mooncake engine registration/deregistration, and cleanup on error/timeout.
  - `_try_recv_mm_data()` override that reconstructs embedding tensors directly from the GPU buffer (zero-copy, no deserialization of ZMQ data parts).
- **`MMReceiverBase.__init__`**: For `mooncake` backend, initializes scheduler-side properties (pp_rank, tp_rank, hostname, mm_processor, waiting_list, etc.) previously only set for `zmq_to_scheduler`.
- **`_send_encode_request`**: For `mooncake` backend, saves `mm_data` (extracted URL list) onto the request object as `mm_data_mooncake` and returns early — no tokenizer-side encoding thread is spawned.
- **`_process_waiting_requests`**: Accepts `**extra_kwargs` to forward `embeddings_engine`, `dtype`, and `gpu_id` to `WaitingImageRDMARequest` constructor.
- **`process_waiting_requests`** in `MMReceiverHTTP`: Routes to `WaitingImageRDMARequest` class (with RDMA kwargs) instead of base `WaitingImageRequest`.
- **`allocate_embedding_buffer`**: Changed from CPU tensor to GPU tensor (`device=self.scheduler.gpu_id`) for zero-copy RDMA receive.
- **Timeout handling**: Added `_cleanup_gpu_buffer()` and socket close on timeout for RDMA requests.

### `python/sglang/srt/disaggregation/encode_server.py`
- **Pre-computed embedding metadata**: On init, Mooncake backend pre-computes `_embedding_dims`, `_embedding_dtype`, and `_element_size` so metadata can be returned before VIT forward completes.
- **New async encode methods**:
  - `encode_with_mooncake()`: For non-cache mode — returns metadata immediately, launches VIT forward as a background `asyncio.Task`.
  - `encode_with_global_cache_mooncake()`: For global-cache mode — same async pattern with cache check, VIT forward, prefetch, and fallback all running as background tasks.
- **Async forward synchronization**: Added `_forward_ready_events` (dict of `asyncio.Event`) and `_forward_results` (dict storing embedding or error) to coordinate between `/encode` (returns metadata) and `/send` (waits for forward completion before RDMA transfer).
- **`_send` method**: Before RDMA transfer, waits for VIT forward completion via the event mechanism; validates embedding availability.
- **`run_encoder` / `launch_server`**: Routes to the appropriate encode method based on `encoder_transfer_backend == "mooncake"`.
- **Logger configuration**: Added `configure_logger(server_args)` call in `launch_server`.

### `python/sglang/srt/managers/scheduler.py`
- Extended `init_disaggregation` and `recv_requests` to handle `mooncake` backend alongside `zmq_to_scheduler` (previously only `zmq_to_scheduler` triggered mm_receiver initialization and waiting request processing).
- Passes `dtype=self.model_config.dtype` to `create_mm_receiver` for GPU buffer allocation.

### `python/sglang/srt/managers/tokenizer_manager.py`
- Removed `mooncake` from the tokenizer-side mm_data receiving path — Mooncake now uses the scheduler-side path (`zmq_to_scheduler` style) instead of the tokenizer-side path.
- Forwards `mm_data_mooncake` attribute through `TokenizedGenerateReqInput` so the scheduler-side `WaitingImageRDMARequest` can access the original image URLs.
- Updated `_handle_epd_disaggregation_encode_request` to route `mooncake` backend through the scheduler-side dispatch path.

### `test/registered/distributed/test_epd_disaggregation.py`
- **New test class `TestEPDDisaggregationMooncake`**: End-to-end test for the Mooncake GPU RDMA zero-copy pipeline.
  - Skipped in CI (requires RDMA hardware).
  - Launches encode, prefill, and decode servers with `--encoder-transfer-backend mooncake`.
  - Runs MMMU evaluation (50 samples) and asserts accuracy > 0.40 (matching baseline for Qwen2.5-VL-3B-Instruct).

+class MooncakeEmbeddingPool:
+    """Persistent GPU buffer pool registered once with the Mooncake engine.
+
+    Allocator: first-fit on a free-segment list with 256-byte alignment.
+    `alloc()` blocks on a Condition when the pool is full and resumes once
+    a peer `release()`s a slot. Each successful alloc returns a slot_id
+    that must be passed back to release() when the consumer is done with
+    the buffer (after RDMA write completes and the data has been read).
+    """
+
+    _ALIGN = 256
+
+    def __init__(self, engine, gpu_id: int, size_bytes: int):
+        self.engine = engine
+        self.gpu_id = gpu_id
+        self.size_bytes = size_bytes
+        self.buffer = torch.empty(
+            size_bytes, dtype=torch.uint8, device=f"cuda:{gpu_id}"
+        )
+        self.base = self.buffer.data_ptr()
+        self.engine.register(self.base, self.buffer.nbytes)
+        self._segments_free: List[Tuple[int, int]] = [(0, size_bytes)]
+        self._inflight: Dict[int, Tuple[int, int]] = {}
+        self._next_slot_id = 0
+        self._total_inflight = 0
+        self._lock = threading.Lock()
+        self._cond = threading.Condition(self._lock)
+        logger.info(
+            f"MooncakeEmbeddingPool registered: gpu={gpu_id}, "
+            f"size={size_bytes // (1024 * 1024)}MB, base=0x{self.base:x}"
+        )
+
+    def alloc(
+        self, nbytes: int, timeout: float = 60.0
+    ) -> Optional[Tuple[torch.Tensor, int, int]]:
+        """Allocate `nbytes` from the pool.
+
+        Returns ``(tensor_view, gpu_addr, slot_id)`` on success, or ``None``
+        when (a) the request is bigger than the pool itself or (b) the wait
+        for a free slot exceeds ``timeout`` seconds.
+
+        When the pool is full of in-flight slots, this call blocks the
+        calling thread on a Condition until a peer ``release()`` opens
+        enough contiguous space.
+
+        NOTE: no ordering guarantee — notify_all + lock race means
+        large requests can starve behind small ones, plus thundering-herd.
+        """
+        if nbytes > self.size_bytes:
+            logger.error(
+                f"MooncakeEmbeddingPool: requested {nbytes // (1024 * 1024)}MB "
+                f"exceeds pool capacity {self.size_bytes // (1024 * 1024)}MB. "
+                f"Raise SGLANG_EMBEDDING_POOL_SIZE_MB."
+            )
+            return None
+        aligned = (nbytes + self._ALIGN - 1) & ~(self._ALIGN - 1)
+        deadline = time.monotonic() + timeout
+        warned = False
+        with self._cond:
+            while True:
+                slot = self._try_alloc_locked(nbytes, aligned)
+                if slot is not None:
+                    return slot
+                if not warned:
+                    inflight_mb = self._total_inflight // (1024 * 1024)
+                    cap_mb = self.size_bytes // (1024 * 1024)
+                    logger.warning(
+                        f"MooncakeEmbeddingPool full: "
+                        f"{inflight_mb}/{cap_mb}MB in-flight across "
+                        f"{len(self._inflight)} requests; queueing a "
+                        f"{nbytes // (1024 * 1024)}MB request. Raise "
+                        f"SGLANG_EMBEDDING_POOL_SIZE_MB if this is frequent."
+                    )
+                    warned = True
+                remaining = deadline - time.monotonic()
+                if remaining <= 0:
+                    logger.error(
+                        f"MooncakeEmbeddingPool alloc timed out after "
+                        f"{timeout}s waiting for {nbytes // (1024 * 1024)}MB."
+                    )
+                    return None
+                self._cond.wait(timeout=remaining)
+
+    def _try_alloc_locked(
+        self, nbytes: int, aligned: int
+    ) -> Optional[Tuple[torch.Tensor, int, int]]:
+        for i, (off, length) in enumerate(self._segments_free):
+            if length >= aligned:
+                if length == aligned:
+                    self._segments_free.pop(i)
+                else:
+                    self._segments_free[i] = (off + aligned, length - aligned)
+                slot_id = self._next_slot_id
+                self._next_slot_id += 1
+                self._inflight[slot_id] = (off, aligned)
+                self._total_inflight += aligned
+                view = self.buffer[off : off + nbytes]
+                return view, self.base + off, slot_id
+        return None
+
+    def release(self, slot_id: int) -> None:
+        """Return a previously-allocated slot to the free list and wake any
+        blocked alloc() waiters."""
+        with self._cond:
+            seg = self._inflight.pop(slot_id, None)
+            if seg is None:
+                return
+            off, aligned = seg
+            self._total_inflight -= aligned
+            self._coalesce_free_locked(off, aligned)
+            self._cond.notify_all()
+
+    def _coalesce_free_locked(self, off: int, length: int) -> None:
+        self._segments_free.append((off, length))
+        self._segments_free.sort()
+        merged: List[Tuple[int, int]] = []
+        for s_off, s_len in self._segments_free:
+            if merged and merged[-1][0] + merged[-1][1] == s_off:
+                p_off, p_len = merged[-1]
+                merged[-1] = (p_off, p_len + s_len)
+            else:
+                merged.append((s_off, s_len))
+        self._segments_free = merged
