## Motivation

Regarding the zero expert proposed by longcat_flash, we found that there may be an optimization when masking the expert. The original masking of the ID to 0 may cause confusion with the expert whose ID was originally 0. We modified this and found that the throughput of our model in the prefill phase increased by 10%.

## Modifications

modify the expert mask in function `zero_experts_compute_triton` in sglang/python/srt/layer/moe/ep_moe/kernel.py.
```
#expert_indices[normal_expert_mask] = 0
expert_indices[normal_expert_mask] = -1
```
