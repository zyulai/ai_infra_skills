## 正文(PR 描述)

## Purpose
Close #43851

When sending 'argument: "null"', json.loads("null") returns None which gets stored in the message and crashes Jinja templates (e.g. GLM 5.1). 
This PR adds a None check to the __postprocess_messages argument parsing step, making the previously untrue comment " if arguments is None or empty string, set to {}" true.
