## Purpose

This PR adds tuned fused MoE config for MiniMaxAI/MiniMax-M2 model. This was generated by running the MoE tuning benchmark script to optimize Triton kernel configurations for better performance.

## Test Plan

Benchmarking with vLLM bench serve tool:

```bash
vllm bench serve \
  --backend vllm \
  --model MiniMaxAI/MiniMax-M2 \
  --endpoint /v1/completions \
  --dataset-name random \
  --random-input 2048 \
  --random-output 1024 \
  --max-concurrency 10 \
  --num-prompt 100
```
