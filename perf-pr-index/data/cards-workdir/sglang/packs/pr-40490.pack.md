## Summary

Fuse the packed single-stream Q/K copies, RMSNorm and interleaved RoPE in FLUX.2 Klein Base4B on Hopper. The native profile identifies this remaining split chain after the existing AdaLN and SwiGLU fusions.

On **1× H200**, native eager **1024×1024 / 50 steps / BF16 / lossless**, the two fixed full-request-warmed ABBA groups reduce worker E2E by **2.53–2.60%** and client E2E including PNG saving by **2.43–3.41%**. Every valid lossless PNG is byte-identical. Initial one-step-warmup groups, including slower candidate observations, remain reported below.

## Modifications

- Add a Triton kernel that reads strided Q/K directly from the packed QKV/MLP projection and writes contiguous normalized/rotated Q/K. Adjacent V/MLP values are untouched.
- Preserve the native tiled RMSNorm reduction and its BF16 output rounding, followed by FlashInfer's interleaved RoPE cosine-FMA ordering. Explicit sign-bit negation preserves negative zero.
- Keep rotary pairs in registers: the initial gather implementation used 90 registers/thread; the NCU-driven pair layout uses 34, with no spills.
- Scope dispatch to Hopper, BF16, 24 heads ×128, supported dense outer strides, FP32 rotary cache and the actual native RMSNorm dispatch. Verify each new signature outside graph capture; mismatch/exception disables the path. Other layouts/devices, deterministic/native norm dispatch, compilation and unverified capture retain the original shared helper. The existing `SGLANG_ENABLE_FUSED_QKNORM_ROPE=0` switch is respected.
- Keep two focused tests for packed-input exactness, unchanged V/MLP storage, signed zeros and changed-input/weight/cache graph replay; document the numerical and hardware contract.

This follows the guarded lossless approach in #34616 and the packed-input handling in #34617. Those existing fusions are already in the baseline. #37112 targets a different Blackwell D6144 gated-residual chain. [Source and prior-art review](https://github.com/BBuf/sglang/blob/75e46a28aa3aa2d8a8fccd2e9ba006dbb00abc53/diffusion-prs/flux2-klein-base4b-strided-qk-rope-h200/klein-qk-source-review.md).

+"""Packed FLUX.2 Q/K RMSNorm and interleaved RoPE with native rounding."""
+
+import torch
+import triton
+import triton.language as tl
+
+
+def can_use_flux2_strided_qknorm_rope(q, k, q_weight, k_weight, cache) -> bool:
+    if (
+        torch.compiler.is_compiling()
+        or torch.is_grad_enabled()
+        or torch.version.hip is not None
+        or not q.is_cuda
+        or torch.cuda.get_device_capability(q.device) != (9, 0)
+        or q.ndim != 4
+        or q.shape[-2:] != (24, 128)
+        or q.numel() == 0
+        or q.is_contiguous()
+        or k.shape != q.shape
+        or k.stride() != q.stride()
+        or q.stride(-1) != 1
+        or q.stride(-2) != 128
+        or q.stride(0) != q.shape[1] * q.stride(1)
+        or q.stride(1) < 24 * 128
+    ):
+        return False
+    if any(
+        t.device != q.device or t.dtype != torch.bfloat16
+        for t in (q, k, q_weight, k_weight)
+    ):
+        return False
+    if any(t.shape != (128,) or not t.is_contiguous() for t in (q_weight, k_weight)):
+        return False
+    return (
+        isinstance(cache, torch.Tensor)
+        and cache.device == q.device
+        and cache.dtype == torch.float32
+        and cache.ndim == 2
+        and cache.shape[0] >= q.shape[1]
+        and cache.shape[1] == 128
+        and cache.is_contiguous()
+    )
+
+
+@triton.jit
+def _flux2_strided_qknorm_rope_kernel(
+    q_ptr,
+    k_ptr,
+    qw_ptr,
+    kw_ptr,
+    cache_ptr,
+    qo_ptr,
+    ko_ptr,
+    ROWS: tl.constexpr,
+    TOKENS: tl.constexpr,
+    HEADS: tl.constexpr,
+    TOKEN_STRIDE: tl.constexpr,
+    CACHE_STRIDE: tl.constexpr,
+    EPS: tl.constexpr,
+    BLOCK_ROWS: tl.constexpr,
+):
+    rows = tl.program_id(0) * BLOCK_ROWS + tl.arange(0, BLOCK_ROWS)[:, None]
+    dims = tl.arange(0, 128)[None, :]
+    if tl.program_id(1) == 0:
+        x_ptr, w_ptr, y_ptr = q_ptr, qw_ptr, qo_ptr
+    else:
