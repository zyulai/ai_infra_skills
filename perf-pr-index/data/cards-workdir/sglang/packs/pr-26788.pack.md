## Motivation

The DeepSeek-V4 DSA indexer selects the top-k KV positions per query for sparse
attention and maps the selected indices through a page table. This fused top-k +
page-table transform sits on the decode critical path, especially for long context.
This PR provides an optimized JIT kernel for it.

## Feature

- **Runtime top-k — `k = 512`, `1024`, and `2048` are all supported** (`k` is a
  runtime argument, so a single module serves every `k`).
- Ragged per-batch sequence lengths.
- Arbitrary (power-of-two) page size.
- Optional raw (pre-transform) top-k index output.

## Performance

Benchmarked on B200 against flashinfer's `top_k_page_table_transform`
(apples-to-apples: both do top-k **and** the page-table transform), `k=512`:

- Faster in nearly all `(batch, seq)` configurations; up to ~1.5× at large batch /
  long context.
- Sustains ~3.0–3.6 TB/s (near HBM peak) for `batch ≥ 2048` at `seq ≥ 64K`.

Correctness is validated against `torch.topk` across all dispatch paths
(172 unit-test cases).
