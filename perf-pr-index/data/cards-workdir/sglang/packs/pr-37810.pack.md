## Summary

Enable breakable CUDA graph (BCG) prefill for the ROCm DeepSeek-V4 HIP radix backend.

## Changes

- Add captured-metadata support for HIP radix prefill capture and replay.
- Refresh attention, unified-KV, indexer, compressor, and FP4 workspace metadata in place.
- Preserve the existing CUDA memory-pressure guard while allowing explicit HIP BCG selection.
- Keep ROCm DSV4 mixed prefill/decode batches eager under DP attention; pure TP and other backends retain their existing replay policy.
- Pass host-proven `repeat_interleave(output_size=...)` and `extend_start_loc` metadata to avoid implicit GPU-to-host scalar synchronizations.
- Add focused coverage for capture/replay metadata, DP admission, address stability, underfilled buckets, and the no-D2H guard.

BCG remains opt-in through `--cuda-graph-backend-prefill breakable`.

### AgentX validation: DSpark + HiCache, eager vs breakable prefill CUDA graph

#### Requirements

- **Depends on #39007.** It adds `record_stream_for_v2_verify` / `record_stream_each` to the DSpark verify path; without it the target-verify tensors are not stream-lifetime-safe.
- **ROCm requires `SGLANG_ENABLE_WAR_BARRIER=1`.** The scheduler sets `_war_barrier_enabled = is_cuda() or SGLANG_ENABLE_WAR_BARRIER`, and `is_cuda()` is False on ROCm builds (`torch.version.cuda is None`), so the WAR barrier is on by default on NVIDIA but **off by default on ROCm**. It must be set explicitly on MI355X.

#### Setup

1× MI355X TP8, DeepSeek-V4 DSpark (66-shard), SGLang `v0.5.19-rocm724-mi35x-20260913`. AgentX `inferencex-agentx-mvp`, dataset `semianalysis_cc_traces_weka_062126`, 3600 s/point, seed 42, HiCache ratio 2.75, `mem-fraction-static` 0.85.
Controlled variable: `--cuda-graph-backend-prefill disabled|breakable`.
