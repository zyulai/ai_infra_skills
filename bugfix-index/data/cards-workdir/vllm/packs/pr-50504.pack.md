## 正文(PR 描述)

## Purpose
Current CI failures occur during the Docker image build stage, where installing dependencies from vllm-ascend/requirements.txt fails for triton-ascend because the package cannot be found in the default PyPI cache. This PR adds the appropriate mirror source that hosts triton-ascend to resolve the installation error.
