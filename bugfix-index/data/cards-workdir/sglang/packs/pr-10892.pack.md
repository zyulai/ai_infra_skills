## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Fix CUDA illegal memory issues in EAGLE CUDA graph runners like:
#6309 #8296 #8336 #9888

This PR aims to fix the root cause of IMA issues, unlike #9687 which attempts to mitigate with padding.

## Modifications

<!-- Detail the changes made in this pull request. -->

Reset `self.positions` in EAGLE CUDA graph runners when `raw_bs` and `capture_bs` differ.
