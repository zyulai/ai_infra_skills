## PR body
```markdown
## Motivation

Split out from the Ling-3.1-flash day-0 support effort.

Block-FP8 decode on Hopper spends small-M linear work in GEMM kernels that are built for large batches, the KDA output normalization and FP8 quantization run as separate kernels, the 512-expert sigmoid router goes through a generic Triton top-k, and weights whose K dimension is not a multiple of the 128-wide quantization block cannot use the native Triton/DeepGEMM paths at all. This PR adds opt-in fast paths for each, with explicit dispatch contracts and no change to default behavior.

Measured on H200 with Ling-3.1-flash (FP8, TP8+EP8+NEXTN, fp32 router as on current main): batch-size-1 decode output throughput **+7.3%** (218.6 → 234.6 tok/s), median TPOT **−8.5%**, both environment flags on vs current main; throughput at concurrency 16 is unchanged. Accuracy on full GSM8K is unchanged (see below).

## Modifications

- **Hopper small-M GEMV** (`SGLANG_ENABLE_FP8_BLOCK_GEMV`, default off): CUDA block-FP8 GEMV for M≤8 with optional fused side projection, and a BF16 tiny GEMV (N≤64, M≤4, SM90 only) under `--bf16-gemm-backend gemv`. Dispatch checks device, dtype, layout, scale grid, and shape; anything else keeps the existing path. Also a CUDA router gate matvec (fp32/bf16 weight) for the Bailing-class gate shape, gated the same way.
- **Fused KDA output quant** (`SGLANG_ENABLE_FUSED_KDA_OUTPUT_QUANT`, default off): the gated RMSNorm at the KDA output fuses with FP8 quantization, emitting the `(q, scale)` tuple the FP8 o_proj consumes; requires target-verify batches and BF16, falls back otherwise.
- **CUDA grouped top-k** for the 512-expert / 8-group / group-top-4 / topk≤8 sigmoid routing shape. Dispatch is shape-driven (no model check): any model with the matching shape uses it, everything else keeps the Triton path. Shared-slot weighting follows the same contract as `moe_fused_gate` (incl. `renormalize=False` and zero-score semantics).
- **Partial-block FP8 support** (opt-in per layer): serialized block-FP8 weights whose K crosses a quantization block boundary — partial-block quant/GEMM in the native Triton MoE, a `prequant_k_tail` dispatcher for pre-quantized inputs (DeepGEMM only when the TMA alignment contract holds: contiguous operands, base pointer and K divisible by 16), and fused SwiGLU+quant for two-group K-tails. All admission is opt-in and default-off; no in-tree model enables it yet (the Ling3 model PR follows separately).

Traces on H200 (bs=1 decode, flags on): the 510 dense FP8 GEMM calls move from DeepGEMM `sm90_fp8_gemm_1d2d` to the GEMV kernel, the 189 KDA norm+quant pairs collapse into the fused kernel, and the router matvec runs its CUDA path. On GB300 (SM103) every SM90-gated path is a no-op — OFF/ON kernel sequences are identical — while the shape-driven top-k runs normally.

## Accuracy Tests

- H200 8x, Ling-3.1-flash FP8, TP8+EP8+NEXTN, full GSM8K (1319 questions, temp 1.0, top_p 0.95, 2 rounds per mode): OFF 96.89% / stop 99.92% vs ON 97.04% / stop 99.89% (within ±0.5pp run noise). GB300 4x TP4+EP4: OFF 96.82% vs ON 96.97%, stop 99.92% both.
- Kernel numerics (H200 + GB300): new GEMV/side-projection, router matvec, fused KDA quant, grouped top-k (incl. `renormalize=False` shared-slot and zero-score cases), block quant tail, Triton K-tail (incl. aligned-K non-fusion and explicit zero clamp vs `None`) suites all pass; partial-K linear matches a dequant-fp32 reference on both the DeepGEMM route (K=160, descriptor built) and the Triton fallback (K=161). On GB300 the SM90-only suites skip cleanly and the K160 selector rejects with bitwise-generic output.
- Kimi-Linear-48B BF16 smoke (KDA fallback path): 100-question GSM8K 93.0%, stop 100%.

## Speed Tests and Profiling

H200, Ling-3.1-flash TP8+EP8+NEXTN, 3 rounds bs=1 (2048/512) + 2 rounds conc16 (8192/1024), `--flush-cache`, seed 11:

| workload | main | this PR (env off) | this PR (flags on) |
|---|---|---|---|
| bs=1 output tok/s | 218.6 | 221.6 (+1.4%) | 234.6 (+7.3%) |
| bs=1 median TPOT (ms) | 4.351 | 4.191 (−3.7%) | 3.981 (−8.5%) |
| conc16 output tok/s | 1087.6 | 1087.8 | 1094.9 (+0.7%, within run noise) |

The +1.4% with flags off comes from the shape-driven grouped top-k; the flags-on gain comes from the GEMV and fused KDA quant. The CUDA router matvec is neutral at fp32/M=4 (1.41 vs 1.30 ms in trace) and is not claimed as a speedup. Concurrency-16 gains are diluted by MoE/attention compute; low-batch decode is where these kernels pay.

Note: the K160 large-M specialization (H20-3e) is intentionally **not** in this PR — it needs qualifying-hardware evidence and will follow separately.

+        }
+        const float s0 = wsc * sxs[(mg * 8 + 2 * t) * nkb + kb + u];
+        const float s1 = wsc * sxs[(mg * 8 + 2 * t + 1) * nkb + kb + u];
+        acc[mg][0] = fmaf(c[0], s0, acc[mg][0]);
+        acc[mg][1] = fmaf(c[1], s1, acc[mg][1]);
+        acc[mg][2] = fmaf(c[2], s0, acc[mg][2]);
+        acc[mg][3] = fmaf(c[3], s1, acc[mg][3]);
+      }
+    }
+  };
+
+  // Two-stage register pipeline: the next kUnroll blocks stream in while the
+  // current ones feed the MMAs.
+  for (uint32_t kb = kb_begin; kb < kb_end; kb += 2 * kUnroll) {
+    const bool has_b = kb + kUnroll < kb_end;
+    if (has_b) load(buf_b, kb + kUnroll);
+    compute(buf_a, kb);
+    if (has_b) {
+      if (kb + 2 * kUnroll < kb_end) load(buf_a, kb + 2 * kUnroll);
+      compute(buf_b, kb + kUnroll);
+    }
+  }
+
+  if constexpr (kKSplit > 1) {
+    float* slot = sred + ((ks * kRowTiles + tile) * 32 + lane) * (4 * kMGroups);
+#pragma unroll
+    for (uint32_t mg = 0; mg < kMGroups; ++mg) {
+      slot[4 * mg + 0] = acc[mg][0];
+      slot[4 * mg + 1] = acc[mg][1];
+      slot[4 * mg + 2] = acc[mg][2];
+      slot[4 * mg + 3] = acc[mg][3];
+    }
+    __syncthreads();
+    if (ks != 0) {
+      return;
+    }
+#pragma unroll
+    for (uint32_t o = 1; o < kKSplit; ++o) {
+      const float* other = sred + ((o * kRowTiles + tile) * 32 + lane) * (4 * kMGroups);
+#pragma unroll
+      for (uint32_t mg = 0; mg < kMGroups; ++mg) {
+        acc[mg][0] += other[4 * mg + 0];
+        acc[mg][1] += other[4 * mg + 1];
+        acc[mg][2] += other[4 * mg + 2];
+        acc[mg][3] += other[4 * mg + 3];
+      }
+    }
+  }
+
+  const uint32_t row_lo = row_base + g;
+  const uint32_t row_hi = row_base + g + 8;
+#pragma unroll
+  for (uint32_t mg = 0; mg < kMGroups; ++mg) {
+    const uint32_t m0 = mg * 8 + 2 * t;
+    const uint32_t m1 = m0 + 1;
+    if (m0 < M) {
+      if (row_lo < N) out[static_cast<size_t>(m0) * N + row_lo] = cast<bf16_t>(acc[mg][0]);
+      if (row_hi < N) out[static_cast<size_t>(m0) * N + row_hi] = cast<bf16_t>(acc[mg][2]);
+    }
+    if (m1 < M) {
+      if (row_lo < N) out[static_cast<size_t>(m1) * N + row_lo] = cast<bf16_t>(acc[mg][1]);
+      if (row_hi < N) out[static_cast<size_t>(m1) * N + row_hi] = cast<bf16_t>(acc[mg][3]);
+    }
+  }
+}

+// The gate is read L2-cold every layer, so a block issues all its weight loads before the first FMA;
+// the fixed (kRows, kThreads) summation order gives identical logits on every TP rank.
+
+constexpr uint32_t kGateThreads = 256;
+
+template <typename WT>
+struct GateVec;
+
+template <>
+struct GateVec<fp32_t> {
+  static constexpr uint32_t kElems = 4;  // one 16-byte load
+  __device__ __forceinline__ static void load(const fp32_t* p, float (&v)[8]) {
+    const float4 f = __ldcs(reinterpret_cast<const float4*>(p));
+    v[0] = f.x;
+    v[1] = f.y;
+    v[2] = f.z;
+    v[3] = f.w;
+  }
+};
+
+template <>
+struct GateVec<bf16_t> {
+  static constexpr uint32_t kElems = 8;
+  __device__ __forceinline__ static void load(const bf16_t* p, float (&v)[8]) {
+    const uint4 u = __ldcs(reinterpret_cast<const uint4*>(p));
+    const bf16x2_t* h = reinterpret_cast<const bf16x2_t*>(&u);
+#pragma unroll
+    for (int i = 0; i < 4; ++i) {
+      const auto [a, b] = cast<fp32x2_t>(h[i]);
+      v[2 * i] = a;
+      v[2 * i + 1] = b;
+    }
+  }
+};
+
+template <typename WT, uint32_t kMaxM, uint32_t kRows>
+__global__ void __launch_bounds__(kGateThreads) router_gate_matvec_kernel(
+    float* __restrict__ out,
+    const bf16_t* __restrict__ x,
+    const WT* __restrict__ w,
+    const uint32_t M,
+    const uint32_t K,
+    const uint32_t E) {
+  constexpr uint32_t kWarps = kGateThreads / 32;
+  constexpr uint32_t kVec = GateVec<WT>::kElems;
+  __shared__ float sred[kWarps * kRows * kMaxM];
+
+  const uint32_t tid = threadIdx.x;
+  const uint32_t warp = tid / 32;
+  const uint32_t lane = tid % 32;
+  const uint32_t row0 = blockIdx.x * kRows;
+
+  const uint32_t chunks = K / kVec;  // host-checked multiple of kGateThreads
+  const uint32_t per_thread = chunks / kGateThreads;
+  float acc[kRows][kMaxM];
+#pragma unroll
+  for (uint32_t r = 0; r < kRows; ++r) {
+#pragma unroll
+    for (uint32_t m = 0; m < kMaxM; ++m) {
+      acc[r][m] = 0.0f;
+    }
+  }
+  // Every weight load of the block issued before the first FMA: the loop is
+  // fully unrolled for the shipped K, so the compiler hoists them.
+  for (uint32_t i = 0; i < per_thread; ++i) {
+    const uint32_t k = (tid + i * kGateThreads) * kVec;
+    float wv[kRows][8];
+#pragma unroll
+    for (uint32_t r = 0; r < kRows; ++r) {
+      const uint32_t row = min(row0 + r, E - 1);
+      GateVec<WT>::load(w + static_cast<size_t>(row) * K + k, wv[r]);
+    }
+#pragma unroll
+    for (uint32_t m = 0; m < kMaxM; ++m) {
+      float xv[8];
+      // Rows past M re-read the L2-resident row 0 and are dropped at the store,
+      // so every lane issues the same loads without a branch.
+      const bf16_t* xrow = x + static_cast<size_t>(min(m, M - 1)) * K + k;
+      if constexpr (kVec == 8) {
+        const uint4 u = __ldg(reinterpret_cast<const uint4*>(xrow));
+        const bf16x2_t* h = reinterpret_cast<const bf16x2_t*>(&u);
+#pragma unroll
+        for (int j = 0; j < 4; ++j) {
+          const auto [a, b] = cast<fp32x2_t>(h[j]);
+          xv[2 * j] = a;
+          xv[2 * j + 1] = b;
+        }
+      } else {
+        const uint2 u = __ldg(reinterpret_cast<const uint2*>(xrow));
+        const bf16x2_t* h = reinterpret_cast<const bf16x2_t*>(&u);
+#pragma unroll
+        for (int j = 0; j < 2; ++j) {
+          const auto [a, b] = cast<fp32x2_t>(h[j]);
+          xv[2 * j] = a;
+          xv[2 * j + 1] = b;
+        }
+      }
+#pragma unroll
+      for (uint32_t r = 0; r < kRows; ++r) {
+        float p = 0.0f;
+#pragma unroll
+        for (uint32_t j = 0; j < kVec; ++j) {
+          p = fmaf(wv[r][j], xv[j], p);
+        }
+        acc[r][m] += p;
+      }
+    }
+  }
+
+#pragma unroll
+  for (uint32_t r = 0; r < kRows; ++r) {
+#pragma unroll
+    for (uint32_t m = 0; m < kMaxM; ++m) {
+#pragma unroll
+      for (uint32_t off = 16; off > 0; off >>= 1) {
+        acc[r][m] += __shfl_xor_sync(0xffffffff, acc[r][m], off);
+      }
+    }
+  }
+  if (lane == 0) {
+#pragma unroll
+    for (uint32_t r = 0; r < kRows; ++r) {
+#pragma unroll
+      for (uint32_t m = 0; m < kMaxM; ++m) {
+        sred[(warp * kRows + r) * kMaxM + m] = acc[r][m];
+      }
+    }
+  }
+  __syncthreads();
+  if (tid < kRows * kMaxM) {
+    const uint32_t r = tid / kMaxM;
+    const uint32_t m = tid % kMaxM;
+    const uint32_t row = row0 + r;
+    if (m < M && row < E) {
+      float s = 0.0f;
+#pragma unroll
+      for (uint32_t wi = 0; wi < kWarps; ++wi) {
+        s += sred[(wi * kRows + r) * kMaxM + m];
+      }
+      out[static_cast<size_t>(m) * E + row] = s;
+    }
+  }
+}

+__device__ __forceinline__ uint32_t float_to_ordered_uint(float val) {
+  uint32_t bits = __float_as_uint(val);

+  uint32_t bits = ordered ^ ((ordered & 0x80000000u) ? 0x80000000u : 0xffffffffu);

+// Equal values resolve to the smaller expert index, the tie policy of the JIT
+// single-group top-k kernel.
+__device__ __forceinline__ uint64_t pack_val_idx(float val, int32_t idx) {
+  uint32_t val_bits = float_to_ordered_uint(val);
+  uint32_t idx_bits = static_cast<uint32_t>(65535 - idx);
+  return (static_cast<uint64_t>(val_bits) << 32) | idx_bits;

+__device__ __forceinline__ uint64_t warp_max_u64(uint64_t val) {
+#pragma unroll
+  for (int mask = WARP_SIZE / 2; mask > 0; mask >>= 1) {
+    uint64_t other = __shfl_xor_sync(0xffffffff, val, mask);
+    val = max(val, other);
+  }
+  return val;
+}

+#else
+#pragma unroll

+    const uint32_t other = __shfl_xor_sync(0xffffffff, ordered, mask);
+    ordered = max(ordered, other);
+  }

+#endif

+  return ordered_uint_to_float(best_ordered);

+  }

+  best_ordered = __reduce_max_sync(0xffffffff, ordered);
+  const uint32_t idx_for_best = (ordered == best_ordered) ? static_cast<uint32_t>(idx) : 0xffffffffu;
+  const uint32_t best_idx_u = __reduce_min_sync(0xffffffff, idx_for_best);
+  best_idx = static_cast<int32_t>(best_idx_u);
+#else

+  const uint64_t best = warp_max_u64(packed);
+  best_ordered = static_cast<uint32_t>(best >> 32);
