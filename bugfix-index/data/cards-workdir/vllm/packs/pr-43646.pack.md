## 正文(PR 描述)

## Problem
   Running fused MoE LoRA kernels on XPU crashes with:  AssertionError: Torch not compiled with CUDA enabled

   This is caused by direct calls to `torch.cuda.get_device_properties()` inside
   `_fused_moe_lora_grid` and `_run_fused_moe_lora_small_batch`.

## Changes
Replace the two `torch.cuda.get_device_properties(device).multi_processor_count` calls with `current_platform.num_compute_units(device)` , which already handles platform dispatch

## Test

  pytest tests/lora/test_fused_moe_lora_kernel.py
