## Motivation

The change at https://github.com/sgl-project/sglang/pull/19321 caused qwen3-next to fail in running the w8a8 model on NPU due to incorrect loading of the in_proj_qkvz quantization parameters.

## Modifications

1. The w8a8 quantization parameters include weight, weight_scale, and weight_offset. For all these parameters, _weight_loader must be set to the new_loader method.
2. The fused_qkvzba_split_reshape_cat_npu method supports the prefill phase to prevent an error from being reported when the grid size of the Triton operator exceeds 65535.
