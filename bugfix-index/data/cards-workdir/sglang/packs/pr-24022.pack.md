## 正文(PR 描述)

## Summary

Improve LTX-2.3 one-stage TI2V reference alignment controls and update the CI consistency threshold for the regenerated faithful V2A-enabled GT.

## Changes

- Process LTX2 text connector positive and negative CFG branches independently to match official behavior more closely.
- Fix LTX2.3 audio cross-attention RoPE scale factors.
- Add explicit `skip_v2a_cross_attn_for_video_gt` sampling flag for reproducing legacy GT behavior only when needed.
- Preserve `--disable-autocast` when applying config dict overrides, with unit coverage.
- Update `ltx_2.3_one_stage_ti2v` consistency threshold for the regenerated faithful V2A-enabled GT in `sglang-ci-data`.

## Accuracy Notes

The regenerated GT is now in `sglang-ci-data/main` commit `03cba05fc35219f5e7407d6d1ac33ecee3819191` and keeps V2A cross-attention enabled by default.

Current code-only branch, without transformer fp8-cast and without legacy V2A skip, measured against the regenerated GT:

- min_clip `0.8053`
- min_ssim `0.7934`
- min_psnr `20.8080`
- max_mean_abs_diff `10.3797`

Thresholds are set with CI margin:

- clip `0.78`
- ssim `0.78`
- psnr `20.0`
- mean_abs_diff `11.0`

Alignment percentage by min SSIM: `79.34%`.

For comparison, the separate transformer fp8-cast branch (#24024) measured `min_ssim=0.8291` against the same regenerated GT, but that compatibility mode is intentionally not kept in this PR.

## Validation

- `git diff --check origin/main` passed.
- Local targeted pytest command was attempted: `python -m pytest python/sglang/multimodal_gen/test/unit/test_server_args.py -q`.
- Local pytest did not reach test assertions because the current shell environment imported another repo path and failed during collection on missing `triton.compiler`.
