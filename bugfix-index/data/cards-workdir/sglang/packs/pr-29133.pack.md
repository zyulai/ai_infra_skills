## 正文(PR 描述)

# Summary
Fix Mori decode-side `ABORT` notifications being treated as malformed bootstrap messages because `MORI_GUARD` frame validation.
This dispatches `ABORT` before guarded bootstrap payload validation, marks tracked rooms as failed, and avoids stale status/failure-record cleanup issues after abort.
