## PR body
```markdown
## Purpose
Enable Fbgemm FP4 on Dense models

We see 5.27% better end to end perf on Llama3.3-70B model on B200 GPU without any accuracy regressions (compared to vllm native gemm). Basically it's like free lunch. For accuracy tests I've included both logprob-based and normal instruction following to have a complete set of tests with ~146000 queries towards the model across the tasks.

Currently, the FBGemm kernel particularly favors lower batch sizes, with up to 60% improvement in some GEMM shapes. (please check the test results).
```
