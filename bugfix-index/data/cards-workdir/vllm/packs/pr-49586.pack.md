## 正文(PR 描述)

## Purpose

Linear layers that carry a `bias` are corrupted when loaded through the online quantization + layerwise-reload path (e.g. online FP8). After loading, `bias` holds uninitialized memory instead of the checkpoint values.

**Root cause.** The linear base class creates `bias` *after* `create_weights()`. Online quantization calls `initialize_online_processing()` from inside `create_weights()`, i.e. before `bias` exists, so:

1. `load_numel_total = get_layer_size(layer)` counts only `weight`, and
2. `bias`'s weight loader is never wrapped into `online_process_loader`, so it is never buffered into `info.loaded_weights`.

As soon as `weight` finishes loading, `load_numel >= load_numel_total` holds and `_layerwise_process()` runs. `materialize_layer()` re-allocates every non-skipped tensor of the layer via `empty_strided` — including the already-loaded, non-meta `bias` — replacing its real values with uninitialized memory. Since `bias` is absent from `loaded_weights`, the replay loop never writes it back, so the corruption is permanent.

**Fix.** Add `"bias"` to `SKIP_TENSORS`. `bias` is never quantized (FP8 only quantizes `weight`; `bias` stays bf16 and is added after the GEMM), it is tiny, and it is eager-loaded on the normal path, so it should never be moved to meta or re-materialized by the layerwise-reload path.

## Test Plan

Load a model with biased linear layers (Qwen3 vision tower `visual.blocks.*` qkv/proj/mlp) using online FP8 quantization + layerwise reload, then compare every `bias` parameter against the original bf16 checkpoint with `torch.allclose`.

## Test Result

- **Before:** all 110 vision-tower biases mismatch the checkpoint (`allclose` fails; values are uninitialized/zero).
- **After:** all 110 biases match the checkpoint exactly (`allclose` passes).

Tracing on `visual.blocks.0.attn.proj` confirms the mechanism: `load_numel_total=1327104` (weight only) while the recomputed layer size at trigger time is `1328256` — the 1152-element difference is exactly the bias (hidden dim). Before the fix the bias pointer changes and `absmax` drops from 3.578 to 0 across `materialize_layer()`; after the fix the pointer is unchanged and the values are preserved.
