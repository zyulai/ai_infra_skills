## PR body
```markdown
## Purpose

Replace the Gumbel sampler's Philox-based uniform generation with a manual Murmur3 x86_32 mixing path keyed by request seed, token position, and vocabulary offset. The goal is to preserve the target sampling distribution while improving RNG resolution and avoiding backend-specific math paths.

Related RFC: #54143.

This is not a duplicate of #47524. That PR keeps Philox and combines more of its output bits to improve uniform resolution; this PR evaluates a different RNG and a backend-independent logarithm path. The existing Philox helpers remain available for rejection sampling.

## Implementation

- Generate fp32 uniforms from the full 32-bit Murmur3 result through two exact 16-bit integer-to-float conversions, avoiding backend-dependent uint32-to-float behavior.
- Generate centered fp64 uniforms from 53 random bits and explicitly keep both endpoints open after fp64 rounding.
- Use a stable degree-8 approximation for `log1p(-u)` in the fp32 winning tail instead of a backend-specific libdevice call.
- Keep draft and target sampling on separate noise streams by salting the token position.
- Add Murmur3 known-answer and fp64 endpoint tests, retain the existing distribution tests, and make output-sensitive API tests deterministic where the RNG stream is not the behavior under test.
- Remove the API-level assumption that parallel completions must randomly finish at different lengths. Staggered child completion is already covered deterministically by the `ParentRequest` unit tests.

The current diff touches the sampler, its GPU tests, and three RNG-sensitive entrypoint tests.

## Compatibility Impact

Seeded non-greedy requests produce a different deterministic token sequence because the random-number stream changes. The intended categorical distribution, public API, logits-cache behavior, greedy path, and kernel launch structure are unchanged.

## Test Plan

- Validate Murmur3 outputs against fixed known answers and verify fp64 uniforms exclude both endpoints.
- Run the existing Gumbel distribution, drafting-stream, and edge-case tests on CUDA and ROCm.
- Run structured-output, reasoning, and parallel-completion entrypoint suites after removing assumptions about a particular seeded random sequence.
- Run repository formatting, lint, type, import, DCO, and policy checks.
- Compare Philox and Murmur3 kernel latency on NVIDIA and Ascend hardware.
```

```diff
+    pos = pos.to(tl.int64)
+    offset = offset.to(tl.uint32)

+@triton.jit

+    random32 = murmur3_hash32(seed, pos, offset)
```
