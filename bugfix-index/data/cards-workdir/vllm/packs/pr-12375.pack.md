# PR #12375: [Bugfix][Kernel] Fix CUDA 11.8 being broken by FA3 build

| 字段 | 值 |
| --- | --- |
| 仓库 | vllm-project/vllm |

| 分类 | Attention / Kernel |
| bug 类型 | regression |

## 正文(PR 描述)

Can build FA3 with CUDA version < 12.0 due to use of `__viaddmin_s32` and compute capability 9.0a, disable FA3 for 11.8 builds
