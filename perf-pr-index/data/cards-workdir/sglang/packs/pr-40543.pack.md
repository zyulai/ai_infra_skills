### Summary

Decode CUDA graph capture aligned batch sizes to `attn_cp_size`, even though prefill CP is inactive for `DECODE` and `TARGET_VERIFY`. DCP and `--enable-cp-decode-attn-tp` partition KV/head dimensions rather than token rows, so they do not require CP-width batch alignment.

Remove the CP factor while retaining the existing TBO and gathered-buffer attention-TP alignment.

## AgentX performance

This result requires the combined [#34200](https://github.com/sgl-project/sglang/pull/34200), [#39950](https://github.com/sgl-project/sglang/pull/39950), and [#40543](https://github.com/sgl-project/sglang/pull/40543) stack: HIP CP-v2 support, correct AITER B-preshuffled slicing, and removal of unnecessary CP decode-graph alignment.

Single-node DeepSeek-V4-Pro-0813 on 8×MI355X, TP8, DSpark gamma 6, static verify, 3,600 seconds per point. C4/C16 use GPU KV; C32/C48/C64 use HiCache. `PCP8 + DTP` enables `--enable-prefill-cp --attn-cp-size 8 --enable-cp-decode-attn-tp`.
