## PR body
```markdown
- Use `__getitem__` rather than `get` with `np.fromiter(map(...))` (~6% faster)
- Use `np.intp` for indexing types (avoids copy/type-conversion every time it's used)
- Use `torch.int64` for gpu tensor index mapping (same reason)

Idea came from this PR: https://github.com/vllm-project/vllm/pull/50532
```
