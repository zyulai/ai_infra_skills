## Motivation

Support Multi-Token Prediction (MTP) for MiMo-V2-Flash model on Ascend NPU (requires CANN 9.0).

## Modifications

- Adapt NPUMHATokenToKVPool and its set_kv_buffer method to support MTP inference, including FIA mode and PagedAttention KV cache writing for NPU.
- Modify NPUGraphRunner to support NPU Graph capture/replay for MiMo-V2-Flash MTP workflow.
- Update the forward_mtp attention forward function to match MTP inference logic and NPU fused attention kernel.
- Adjust CUDA/NPU Graph metadata initialization and replay functions to support block tables, sequence lengths management for MTP.
