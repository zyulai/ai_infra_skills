## Motivation

This PR adds mixed-dtype support for DeepSeek-V4 compress-state. When `SGLANG_DSV4_COMPRESS_STATE_DTYPE=bf16` is set, DeepSeek-V4 C4/C128 compress state buffers can be allocated and updated in BF16; when the environment variable is not set, the original FP32 path remains the default.

The goal is to reduce compress-state memory bandwidth and storage overhead in the DeepSeek-V4 sparse attention path. The single-kernel benchmark shows clear gains when compress-state memory traffic dominates, especially on large-batch C128 decode shapes, with smaller gains on selected prefill/runtime replay shapes.

## Modifications

- Add dtype-aware implementations for DeepSeek-V4 C4/C128 compress kernels.
- Add runtime configuration plumbing for `SGLANG_DSV4_COMPRESS_STATE_DTYPE`.
- Keep FP32 behavior unchanged when the environment variable is not set.
- Add tests for C4/C128.
