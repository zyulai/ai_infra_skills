## Motivation

Bench eagle with mmlu will hang:
```
python3 -m sglang.launch_server --model meta-llama/Llama-2-7b-chat-hf  --speculative-algo EAGLE --speculative-draft lmsys/sglang-EAGLE-llama2-chat-7B --speculative-num-steps 2 --speculative-eagle-topk 4 --speculative-num-draft-tokens 4 --mem-fraction 0.7

python3 benchmark/mmlu/bench_sglang.py --nsub 100 --ntrain 5 --parallel 2000
```

For mmlu benchmark, it set max_new_tokens=1. In this case, it will only have target extend stage. While the batch_is_full is not updated after extend, which will prevent new prefilled batch from being taken from the waiting queue.
