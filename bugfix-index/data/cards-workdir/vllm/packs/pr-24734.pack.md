## Purpose
* This PR fixes https://github.com/vllm-project/vllm/issues/22180, and can solve many cases of illegal memory access when using flashinfer sampling.
* Just treat greedy temperature (0.0 now instead of -1.0) as 1.0 when performing apply_temperature is enough.
