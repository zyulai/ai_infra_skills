## Motivation

<!-- Describe the purpose and goals of this pull request. -->
On ROCm, the DSV4.1 low-ratio indexer still uses the older AOT kernels for its top-k. On MI355X, v2 is 1.4-2.6x faster at decode shapes and selects exactly the same indices.

Two AOT kernels are replaced:
- `deepseek_v4_topk_transform_512`, which picks the top 512 positions, both over the full row and inside the candidate blocks;
- `fast_topk`, which picks the top 2048 candidate blocks.

The AOT top-512 kernel also sorts each row by position. This sort is not needed, because the attention kernels that read the selection do not care about its order:
- decode attention reads the first `lengths[t]` entries and skips -1;
- prefill (`combine_topk_swa_indices`) only requires unused entries to be -1.

The CUDA path already passes the selection through unsorted, so this PR drops the sort as well.
