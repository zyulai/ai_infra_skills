## Purpose

Eagle3 checkpoints from NVIDIA (GPT-OSS series) store `norm_before_fc` inside the nested `eagle_config` dict rather than as a top-level config field. We currently only check the top-level, so the RMSNorm before FC gets silently skipped for these checkpoints, causing degraded acceptance rate.

Fix: read `norm_before_fc` from `eagle_config` first, fall back to top-level attr. Same pattern already used for `use_aux_hidden_state` in the same block.

## Test Plan

```bash
export TARGET=/path/to/Qwen3-32B
export DRAFT=/path/to/Qwen3-32B_eagle3

# 1. correctness — greedy match between baseline and eagle3
CUDA_VISIBLE_DEVICES=0 python3 -c "
import torch, gc
from vllm import LLM, SamplingParams
PROMPTS = ['What is the capital of France?', 'Explain gradient descent in two sentences.', 'Write a Python factorial function.', 'The theory of relativity states that']
P = SamplingParams(temperature=0, max_tokens=64)
llm = LLM(model='${TARGET}', dtype='bfloat16', gpu_memory_utilization=0.9, max_model_len=2048, trust_remote_code=True)
base = [o.outputs[0].text for o in llm.generate(PROMPTS, P)]
del llm; gc.collect(); torch.cuda.empty_cache()
llm = LLM(model='${TARGET}', speculative_config={'method':'eagle3','model':'${DRAFT}','num_speculative_tokens':3}, dtype='bfloat16', gpu_memory_utilization=0.9, max_model_len=2048, trust_remote_code=True)
eagle = [o.outputs[0].text for o in llm.generate(PROMPTS, P)]
for i,(b,e) in enumerate(zip(base,eagle)): assert b==e, f'mismatch at {i}'
print('PASS')
"
