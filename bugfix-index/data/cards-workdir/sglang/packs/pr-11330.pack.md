## 正文(PR 描述)

## Motivation
Previously qwen2_5_VL would crash as described in #10623 in reshaping the query and key. The reason is a mismatch between q,k and position. If a batch is mixed, `mrope_positions` in `mm_input` was only prepared for prefilling so decoding requests in a batch got empty position vectors which leads to a dimension mismatch between query, key and positions.

## Modifications

Change `forward_batch_info.py` to use `mrope_position_deltas` for decode requests in a mixed batch.
