## Purpose

Add a faster exp routine for lower precision dtypes on NEON hardware. Observed a 3-4% speedup on neoverse V1.

## Test Plan

Run
`LD_PRELOAD="/usr/lib/aarch64-linux-gnu/libtcmalloc_minimal.so.4:/usr/lib/aarch64-linux-gnu/libgomp.so.1" taskset -c 20-27 python benchmark_attention_minimal.py`

Where benchmark_attention_minimal.py copies https://github.com/neuralmagic/vllm/blob/main/benchmarks/kernels/cpu/benchmark_cpu_attn.py with:
```
    batch_size = 64
    isa = "neon"
    seq_len = 512
    iters = 50
    dtype = torch.bfloat16
    seq_lens = [(seq_len, seq_len)] * batch_size
    num_heads = (32, 8)
    head_size = 128
```

## Test Result
baseline mean (ms) / faster exp = 1.04
