## Purpose
The current implementation for the middleware that handles authentication (--api-key) and X-Request-Id headers (--enable-request-id-headers) uses a high level abstraction provided by FastAPI that allows middleware to be written as functions with access to the Request object.
This causes an unacceptable performance hit when the middleware is installed.
This PR re-implements the same functionality using pure ASGI middleware which causes almost zero overhead.
Fixes: #11529

## Test Plan
Create a new test file that verifies that the middleware actually works as expected since currently no tests exist for this.
Benchmark the performance improvement before and after the update.

## Test Result
All the correctness tests pass as expected.

+class AuthenticationMiddleware:
+    """
+    Pure ASGI middleware that authenticates each request by checking
+    if the Authorization header exists and equals "Bearer {api_key}".
+
+    Notes
+    -----
+    There are two cases in which authentication is skipped:
+        1. The HTTP method is OPTIONS.
+        2. The request path doesn't start with /v1 (e.g. /health).
+    """
+
+    def __init__(self, app: ASGIApp, api_token: str) -> None:
+        self.app = app
+        self.api_token = api_token
+
+    def __call__(self, scope: Scope, receive: Receive,
+                 send: Send) -> Awaitable[None]:
+        if scope["type"] not in ("http",
+                                 "websocket") or scope["method"] == "OPTIONS":
+            # scope["type"] can be "lifespan" or "startup" for example,
+            # in which case we don't need to do anything
+            return self.app(scope, receive, send)
+        root_path = scope.get("root_path", "")
+        url_path = URL(scope=scope).path.removeprefix(root_path)
+        headers = Headers(scope=scope)
+        # Type narrow to satisfy mypy.
+        if url_path.startswith("/v1") and headers.get(
+                "Authorization") != f"Bearer {self.api_token}":
+            response = JSONResponse(content={"error": "Unauthorized"},
+                                    status_code=401)
+            return response(scope, receive, send)
+        return self.app(scope, receive, send)
+
