## 正文(PR 描述)

Hi @zhuohan123 ,

I noticed that the scheduler may get stuck due to a long prompt.

The scheduler stops adding seq_group from waiting list when it find the allocation can not be performed.
If seq_group was smaller than limitation but larger than all GPU blocks, this seq_group can never be removed from waiting list and blocks all the request after it.

We can put such seq_group into ignored_seq_groups and remove it from waiting list.
