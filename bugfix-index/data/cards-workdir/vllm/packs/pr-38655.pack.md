## 正文(PR 描述)

Fixes two recent Nano Nemotron VL regressions:

1. Stop deep-copying `VllmConfig` in the mamba state helpers. Since #37467, `get_mamba_state_shape_from_config()` runs during worker startup, and deep-copying the full config can now fail on live parameters with a `BasevLLMParameter.__new__` / `torch.nn.Parameter.__deepcopy__` mismatch.
2. Avoid `get_hf_processor()` in metadata hot paths, which avoids tokenizer `RuntimeError: Already borrowed`, likely exposed by #34789.
3. Remove hacky `feature_size_cache`, replace with `num_tokens_per_image`

Also adds `nano-nemotron-vl` to HF_EXAMPLE_MODELS registry for future regression testing.
