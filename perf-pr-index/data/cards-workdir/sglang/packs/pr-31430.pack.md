## PR body
```markdown
## Summary

- Remove the unused top-k computation from draft-extend CUDA Graph capture.
- Keep selected-row top-k calculation in the worker unchanged.
- Remove the runner state and imports that are no longer needed.

The graph currently computes top-k for every draft-extend output row, but replay returns only logits and hidden states. After selecting the relevant row with `select_index`, [`EagleDraftWorker` already computes the required top-k](https://github.com/sgl-project/sglang/blob/62751145484b137d02995b53c9d1d92eee7ea5c9/python/sglang/srt/speculative/eagle_worker_v2.py#L943-L972), so the captured top-k results are never consumed.

## Validation

GSM8K, 100 samples:

- Baseline: strict 99/100, flexible 99/100.
- This PR: strict 99/100, flexible 99/100.
- Both runs missed the same sample and produced the same answer.
```
