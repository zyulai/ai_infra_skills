## 正文(PRD / 提案全文)

Based on the current quota:

(40−28.4)×1024/(535.6+626.6)≈10

The remaining quota for the sgl-kernel project is 40 − 28.4 = 11.6 GB.
The current wheel sizes are:

x86 wheel: 535.6 MB

aarch64 wheel: 626.6 MB

This means we can only publish fewer than ~10 additional releases of sgl-kernel under the current limit.

We have already attempted to increase the total quota, but the request was rejected.

Given this constraint, a more sustainable approach would be to prioritize updating kernels via JIT first, while continuing to reuse the existing AOT wheels. This is especially important since the current AOT wheels are dependencies for a wide range of existing sglang versions, and replacing them would have significant downstream impact.
