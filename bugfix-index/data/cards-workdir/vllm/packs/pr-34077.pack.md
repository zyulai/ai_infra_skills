## 正文(PR 描述)

Qwen3-Next MTP+CG had accuracy loss. The loss was hidden: if run `lm_eval` with high `num_concurrent` the accuracy was ok because for high concurrence CG isn't used. 

All problems was in accurate processing of padded part of batch. 
 - before counted zero len as prefill
 -  state_indices didn't take padded elems in account 
 - copy to persistent place had shape mistmach
