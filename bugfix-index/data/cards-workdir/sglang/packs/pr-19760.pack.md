## Motivation

  - Fix ValueError: input tensor must be the same size as output size times world size when launching with --enable-dp-attention and dp_size < tp_size (e.g., --tp 8, --dp 4)
  - The _dummy_run warmup path was missing attn_tp_size alignment for num_tokens, which is already done in forward_batch_info.py (inference) and cuda_graph_runner.py
