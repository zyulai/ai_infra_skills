## PR body
```markdown
**Depends on [ROCm/aiter](https://github.com/ROCm/aiter/pull/5993)**. Without that AITER build this PR changes nothing: the path is gated on `aiter.ops.flydsl.hc_mix` being importable.

## Motivation

`GatedResidual`'s input mix is a low-rank gate over the `[M, 4·2560]` hyper-state. It runs in every Qwen3.8 decode step, and at decode sizes (M ≤ 16) it is bound by reading the weights.

On gfx950, AITER's FlyDSL `hc_mix` is 1.7–2.4x faster than the persistent Triton `fused_hc_mix` SGLang uses today.

## Modifications

**`python/sglang/srt/layers/hc_mix_flydsl.py`** (new)

`flydsl_hc_mix_supported(...)` accepts a call only when all of these hold:
- HIP, gfx950, BF16, contiguous inputs;
- 1 ≤ M ≤ 16, hc = 4;
- the shape constraints of the AITER kernel;
- AITER and FlyDSL are importable.

The checks are ordered so NVIDIA and disabled paths never import FlyDSL. `weight_cache_key(...)` gives the packed-weight cache a key from the weights' data pointer and version.

**`python/sglang/srt/layers/hyperconnection.py`**

- `GatedResidual` tries FlyDSL `hc_mix` before `fused_hc_mix`.
- Weights are packed once with `pack_hc_weights`, cached on the layer, and repacked only if the weight key changes.

**Benchmark and tests**

- `benchmark/kernels/bench_hc_mix_flydsl.py` compares FlyDSL, persistent Triton and `torch.compile`. It uses CUDA-graph replay with rotating weights, so the weights are cold in L2.
- `test/registered/kernels/ops/hyperconnection/test_hc_mix_flydsl.py` is registered in the AMD `stage-b-test-1-gpu-small-amd` suite. It checks:
  - the gate rejects inputs when disabled or given unsupported shapes;
  - `GatedResidual` dispatches to FlyDSL and matches the reference (`atol=4e-3`);
  - the packed-weight cache reuses packed weights and repacks after a weight change;
  - inference-tensor weights get a key with no version.

## Accuracy Tests

The FlyDSL output matches the float64 reference within `atol=4e-3, rtol=1e-2`, in both the AITER op test and this PR's dispatch test.

## Speed Tests and Profiling

Command: `python benchmark/kernels/bench_hc_mix_flydsl.py --rows 1 2 4 8 16 --weights 64`
```

```diff
+from functools import lru_cache
+from importlib.util import find_spec

+import torch

+# AITER's kernel limit; it stays ahead of the torch.compile fallback up to it
+# (K=10240, R=320, cold weights: 26 vs 42 us at 128 rows).
+_MAX_ROWS = 128
+
+
+@lru_cache(maxsize=1)
+def _aiter_hc_mix_available():
+    # Check only after device/shape guards; optional packages stay lazy.
+    try:
+        return (
+            find_spec("flydsl") is not None
+            and find_spec("aiter.ops.flydsl.hc_mix") is not None
+        )
+    except ModuleNotFoundError:
+        return False

+def flydsl_hc_mix_weights_supported(down, up, hc):
+    """Device and weight-shape half of the check.
+
+    None of it changes after the weights are loaded, so callers evaluate it
+    once per layer and pass the result to ``flydsl_hc_mix_supported``.
+    """
+    # Keep FlyDSL/AITER imports off the NVIDIA path.
+    if torch.version.hip is None:
+        return False
+    r, k = down.shape
+    # pack_hc_weights tiles K by 64 and R by 32, and makes its own contiguous
+    # copies, so the source weights' layout does not matter.
+    return (
+        hc == 4
+        and r > 0
+        and r % 32 == 0
+        and k > 0
+        and k % 64 == 0
+        and up.shape == (k, r)
+        and down.dtype == up.dtype == torch.bfloat16
+        and down.is_cuda
+        and up.device == down.device
+        and torch.cuda.get_device_properties(down.device).gcnArchName.split(":")[0]
+        == "gfx950"
+        and _aiter_hc_mix_available()
+    )
+
+
+def flydsl_hc_mix_supported(x, weights_supported):
+    """Per-call half: the activation's dtype, row count and layout.
+
+    ``x`` is the [rows, HC*HS] normed input, which the caller has already
+    matched to the weights' K.
+    """
+    return (
+        weights_supported
+        and x.dtype == torch.bfloat16
+        and x.ndim == 2
+        and 1 <= x.shape[0] <= _MAX_ROWS
+        and x.is_contiguous()
+        and x.data_ptr() % 16 == 0
+    )
+
+
+def weight_cache_key(down, up):
+    # Inference tensors do not have version counters. As in the CuTe weight
+    # cache, in-place updates of those tensors require reinitializing the cache.
+    def version(w):
+        return None if w.is_inference() else w._version
+
+    return (down.data_ptr(), version(down), up.data_ptr(), version(up))
```
