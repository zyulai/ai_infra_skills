## 一句话结论
把 SGLang 发版节奏标准化为每两周一个常规版本,紧急情况另行加发。

## 提案动机
SGLang 团队经过彻底的内部讨论,决定将发布周期标准化。(pack 正文较短,正文即公布该决定及其细则,未展开更多背景。)

## 提出的方案
- 正常情况下每两周发布一个新版本(如 v0.4.8、v0.4.9)。
- 两次常规发布之间如出现紧急问题或高优先级特性,可按需发布 patch release 或额外的 stable 版本。
- 双周发布通常落在每月月中与月末附近。
- 每次发布尽量包含一组 planned features,通常由 SGLang 团队提前讨论确定。
