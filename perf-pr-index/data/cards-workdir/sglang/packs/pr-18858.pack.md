## Motivation

Reduce gpt-oss MXFP4  MoE load-time preprocessing latency on Blackwell GPUs by replacing per-expert shuffle preprocessing with cached FlashInfer permute-index preprocessing and removing per-layer shuffle logs.

## Modifications

- Replaced legacy per-expert shuffle ops with cached FlashInfer permute-index based preprocessing.
- Added permute-index caching and device-resident index caching to avoid repeated recomputation and transfers.
- Used `nvfp4_block_scale_interleave` for required kernel-ready scale layout.
- Removed noisy per-layer shuffle logging during model load.
- Used `get_w2_permute_indices_with_cache` in tensor-specific mode: default mode for weight/bias tensors, and `num_elts_per_sf=16` for MXFP4 scale tensors in this FlashInfer path.
