## Motivation

In Python-frontend mode the launcher posts `/freeze_gc` once the startup warmup finishes (or at once when `--skip-server-warmup` is set): the tokenizer manager turns it into a `FreezeGCReq` carrying `--gc-threshold`, and every scheduler rank applies the thresholds and calls `gc.freeze()`, so the objects allocated during startup stay out of every later full collection.

The Rust frontend never ran that step. `--gc-threshold` reaches the scheduler only through `FreezeGCReq`, so in Rust mode the flag was silently ignored and every full collection in the scheduler walked the whole startup heap.

## Modifications

- `ServerArgs` (Rust) gains `gc_threshold`, filled from `--gc-threshold` by `_build_server_args`.
- Each listener's `startup_warmup` sends `FreezeGCReq` once its warmup generation succeeds, immediately when the warmup is skipped, and after the disaggregation exception that keeps the server up on a failed warmup. A failed or timed-out warmup sends nothing, as in Python.
- The scheduler sends no reply to `FreezeGCReq`, so it leaves through a new one-way intake event (`TmEvent::OneWay`) instead of the awaited control path, which would hang. The intake pushes it on the reserved lane that aborts already use, so a full request ring cannot drop it, and reports back whether it was queued; a failure is logged as an error.
- `Scheduler.handle_freeze_gc` forwards the request to the detokenizer socket only when no Rust server is embedded: in Rust mode the detokenizer runs inside the scheduler process, which the freeze already covers, and nothing reads that socket.
- Propagation follows Python: without local control broadcast, the DP0 listener's message is broadcast to the TP group and the other listeners' copies are dropped; with `--enable-dp-attention-local-control-broadcast` each DP group freezes its own ranks; PP stages receive it through the normal forwarding.

No `/freeze_gc` HTTP route is added to the Rust server: in Python mode its only production caller is the launcher's own post-warmup request, which the Rust server now makes internally.
