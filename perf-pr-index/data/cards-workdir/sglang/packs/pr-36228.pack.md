## PR body
```markdown
## Summary

- Remove generic prefill CP v1 branches and the DSA v1 in-seq-split indexer/backend path; remove the obsolete single-request scheduling restriction.
- Keep generic input sharding and token-ID layout handoff at the runner/strategy boundary.
- Remove unnecessary distributed-layout, projection-cache-write, and communicator-factory wrappers. DeepSeek V4 attention and decoder layers retain their baseline implementation, including HIP KV-score prelaunch.
- Preserve HIP/NPU/MUSA CP callers and their shared metadata, splitting, gather, cache-write, and runtime-argument dependencies. Generic CUDA does not enter these legacy platform paths.
- Remove the newly added architecture/runner regression tests requested in review; retain the existing CP suite.

## Stack

1. #36222 — switch CP tests from v1 to v2 (merged)
2. #36223 — remove generic CP v1 server-argument compatibility (merged)
3. **this PR** — remove generic CP v1 runtime
4. #36229 — rename CP v2 APIs and round-robin terminology
5. #36230 — update documentation

Platform source files under hardware_backend remain unchanged from the main baseline, including both MUSA files restored during review. AMD/NPU registered-test trees are unchanged.

- layers/utils/cp_utils.py: platform metadata, token split/reorder, gather, and KV cache-write helpers.
- DeepseekV2AttentionMLA.rebuild_cp_kv_cache: direct NPU/ROCm model call contract.
- materialize_full_kv_cp: generic strategy path plus an explicitly HIP-only legacy DSA fallback.
- should_defer_dsa_cp_kv_gather: unchanged ROCm call contract.
- HIP/NPU/MUSA model-side boundaries; HIP DSV4 CP+TBO and KV-score prelaunch.
- Protected-platform legacy argument projection; it is disabled on generic CUDA.
```
