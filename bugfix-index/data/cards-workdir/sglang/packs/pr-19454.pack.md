## 正文(PR 描述)

## Motivation

Fixes #19449.

When serving `FLUX.2-klein-9B` with `--num-gpus 8`, image editing (`/v1/images/edits`) produces **completely corrupted output** (grey noise / colored blobs, **SEE BELOW**), while text-to-image generation works correctly. The server reports no errors — the corruption is entirely silent.

Three independent bugs in the Sequence Parallelism (SP) path cause this:

1. **`image_latent` not sharded for SP.** In `_preprocess_sp_latents`, noise latents are correctly sharded across SP ranks, but condition image latents (`batch.image_latent`) remain full-sized. When concatenated in the denoising loop (`torch.cat([latents, batch.image_latent], dim=1)`), the shapes mismatch: `[B, 128, D] + [B, 1024, D]` instead of `[B, 128, D] + [B, 128, D]`.

2. **RoPE positions sharded incorrectly.** `get_freqs_cis` in `Flux2KleinPipelineConfig` concatenates `latent_ids` (1024) with `condition_image_latent_ids` (1024) into a 2048-length sequence *before* sharding. Rank 0 receives positions 0–255 (all noise positions), but its actual local tokens are noise[0:128] + image[0:128]. The image tokens get noise positional embeddings.

3. **Text tokens duplicated SP-times in Ulysses all-to-all.** In FLUX joint attention, text tokens (`encoder_hidden_states`) are replicated across all SP ranks but are concatenated with image tokens and passed through `USPAttention`'s all-to-all. The gathered sequence contains `txt_len × SP` text tokens instead of `txt_len`. With SP=8, each text key appears 8 times, inflating text attention weights by ~8× and shifting the balance between text conditioning and input image fidelity. This causes structural artifacts — e.g., a guitar grows two necks.

Text-to-image generation is less affected because bugs 1 and 2 don't apply (`batch.image_latent` is `None`), and bug 3 only strengthens text conditioning without structural artifacts since there is no competing input image signal.

### 3. `python/sglang/multimodal_gen/runtime/layers/attention/layer.py`

Implement `_forward_with_replicated_prefix` in `USPAttention`. When a replicated prefix (text tokens) is present, the method:

1. Splits q/k/v into replicated prefix and SP-sharded suffix.
2. All-to-all only the sharded suffix (gathers sequence across ranks, shards heads).
3. Locally slices the replicated prefix to the same head shard `H_local`.
4. Concatenates `[text_h_local, image_gathered]` — text appears exactly once.
5. Runs attention. Each rank computes `H_local` heads over the full `txt_len + img_global` sequence.
6. Splits output, all-to-all back the image suffix, all-gather the text prefix heads.

This is correct Ulysses head-parallel attention with 3 distributed communication primitives per layer (2× all-to-all for images + 1× all-gather for text), not a fallback to single-GPU.

### 4. `python/sglang/multimodal_gen/runtime/models/dits/flux_2.py`

Pass `num_replicated_prefix` through the FLUX attention blocks so `USPAttention` knows which tokens are replicated:

- `Flux2Attention.forward()`: passes `num_replicated_prefix=txt_len`
- `Flux2ParallelSelfAttention.forward()`: accepts and forwards `num_replicated_prefix`
- `Flux2SingleTransformerBlock.forward()`: passes `text_seq_len` to attention
- `Flux2Transformer2DModel.forward()`: passes `text_seq_len=num_txt_tokens` to single-stream blocks
