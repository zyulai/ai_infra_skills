## Overview

Run the FlashInfer DCP prefill context pass on the trtllm-gen context kernel (non-causal, with LSE) instead of the native FlashInfer kernel, under the same conditions in which non-DCP prefill auto-selects trtllm-gen. No existing PR switches this kernel; #58519 is complementary (it reduces overhead around the same pass).

## Claims

- On 8×B200 (TP8, DCP2), 100k input / 512 output: mean TTFT −39–48% and output throughput 1.23–1.79× across concurrency 1–32.
- On 4×B200 (TP4, DCP2) with GLM-4-9B, same workload: mean TTFT −37–44% and output throughput 1.26–1.68× across concurrency 1–32.
- Accuracy matches the native path (MRCR, GSM8K), and a new kernel test checks the pass against the native one.
- Applies on SM100/SM103 when trtllm-gen prefill is available (`--attention-config.use_trtllm_attention` not 0) with an unquantized KV cache, to layers without a sliding window or soft-capping. Other layers keep the native kernel.

## Details

- **Kernel.** `trtllm_batch_context_with_kv_cache(causal=False, return_lse=True)` over the DCP-local paged KV. Its LSE is base 2 like the native kernel's, so the combine and merge are unchanged. Non-causal mode and LSE output (flashinfer-ai/flashinfer#3020, #3116) postdate the original FlashInfer DCP support (#25438). The native context wrapper is not planned when this kernel runs.
- **Requests with no local context.** The kernel's LSE for these rows is unspecified: FlashInfer computes it from softmax stats in the reused workspace, which the kernel never writes for `kv_len == 0`. Stale values corrupted the merge intermittently. These rows are masked as empty shards in the combine (`seq_lens` / `query_start_loc`), as on the trtllm DCP decode path, and the output is zero-initialized because the all-gather combine multiplies it by a zero weight.
- **Test.** `test_flashinfer_dcp_prefill_trtllm_context` compares the pass with the native one, including requests with no local context, and runs in the "(B200) Kernels" CI job. The GQA DCP end-to-end test in `tests/distributed/test_context_parallel.py` needs 4 GPUs and only runs on SM90, so it does not cover Blackwell.
- **Limitations.** FP8 KV keeps the native kernel; FlashInfer DCP with FP8 KV currently fails at startup on SM100 independently of this PR, to be fixed separately. `use_trtllm_attention=0` disables this together with trtllm-gen decode, as it does for non-DCP prefill.
