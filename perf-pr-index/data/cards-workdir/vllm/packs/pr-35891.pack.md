## Purpose
This PR enables fp8 kv cache for Flashinfer MLA Sparse attention backend (tracked by #35805).

## Test Plan
Added fp8 unit tests for flashinfer to `tests/v1/attention/test_sparse_mla_backends.py`

For deepseek v3.2 nvfp4, see **14% speedup** in throughput using flashinfer backend compared to flashMLA under DEP8 and concurrency 256.
