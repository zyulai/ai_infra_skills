## 正文(PR 描述)

AMD CI build [#12250](https://buildkite.com/vllm/amd-ci/builds/12250#01a01b85-79bd-4cb8-9287-e5af327ff2ca) exposed a latent lifecycle race between the sequential normal and cross-layer test layouts. The first layout left its proxy on port 8192 while the API servers were still shutting down, so the next layout reused stale processes and the replacement proxy failed to bind. Readiness also used `curl -s` against a POST-only endpoint, allowing an HTTP 405 response to count as success.

- Launch and track each API server and proxy in a harness-owned process group.
- Require the launched process to remain alive and probe real `/health` and `/healthcheck` endpoints with HTTP failure handling.
- Gracefully terminate and reap only owned process leaders and groups, with a 30-second timeout before forced cleanup.
- Wait for ROCm GPU memory to settle before starting the next layout.
