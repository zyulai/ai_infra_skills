## Purpose

Part of #48255.

Only activated under uniform batches and on the **DP process group** (not TP). **Enabled by default when using DP attention + TP experts**.

**Note**: this does not touch any collectives on the TP or EP groups, so EP a2a's or TP AR's or sequence parallel a2a (it uses the EP group) is not affected.

Disable with `VLLM_ROCM_USE_AITER_CUSTOM_AR=0`.

**Perf gain:** **~3% improved TPOT on 1k/1k** (1-256 conc)

### Technical details

- AG: Runs as 3 separate calls for hidden, topk_weights, and topk_ids. AITER doesn't have a grouped AG unfortunately.
